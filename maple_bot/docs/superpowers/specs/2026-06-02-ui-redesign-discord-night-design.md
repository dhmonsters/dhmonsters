# UI/UX 재설계 — Discord Night 게이머 테마 설계

> 기존 Linear 스타일 → 게이머 타겟(Discord/Spotify/Razer 벤치마킹) 소비자 앱 수준 재설계.
> 브레인스토밍에서 무드보드·와이어프레임을 거쳐 **C·Discord Night + 상단 내비 + 캡슐 체인 캔버스**로 승인됨.
> 세부 수치(점 크기/색 미세조정)는 실게임 테스트하며 튜닝 — 이 문서는 방향·토큰·구조를 고정한다.

**목표:** 다크 + 네온 강조 + 둥글고 부드러운 카드 + 상단 내비 + 하단 컨트롤바 + Figma식 미니맵 캔버스. 모든 컴포넌트를 디자인 토큰으로 일관되게, 호버/클릭 마이크로인터랙션 포함.

**범위:** **시각 재설계만**(동작/기능 변경 없음). 토큰(`theme.py`) 교체 + 셸 레이아웃(`shell.py`) 재구성 + 캔버스 동선 렌더(`minimap_canvas`) 스타일 + 페이지 컴포넌트 QSS. 폰트(Pretendard)·한글·기존 기능은 유지.

---

## 1. 디자인 토큰 (Discord Night)

**색 (`TOKENS` 교체)**
| 역할 | 토큰 | 값 |
|------|------|----|
| 배경(앱) | canvas | `#1a1b1e` |
| 표면1(패널/내비) | surface_1 | `#202125` |
| 표면2(카드) | surface_2 | `#2b2d31` |
| 표면3(입력/호버) | surface_3 | `#34363c` |
| 경계 | hairline | `#2c2e33` / strong `#3a3c42` |
| 본문 | ink | `#f2f3f5` / muted `#b5bac1` / subtle `#80848e` |
| **주 강조(블러플)** | primary | `#5865f2` / hover `#7c6bff` |
| 보조 강조(바이올렛) | accent | `#a855f7` |
| 성공/상태 | success | `#3ada85` |
| 위험/HP | danger | `#f23f43` |
| MP | info | `#4d7cff` |
| 캐릭터 | char | `#ffd33d` |

**블록 타입 네온색**(캔버스/리스트 공유, 기존 `BLOCK_COLORS` 갱신): move `#3ada85` · attack `#ff6b81` · ladder `#e3b341` · jump `#5ab0e3` · teleport `#b06bff`.

**반경(RADIUS):** sm 8 · md 11 · lg 14 · pill 999. (기존보다 둥글게)
**그림자/글로우:** 강조 요소는 `0 0 16px <색>66` 네온 글로우. 카드는 `0 1px 0 rgba(0,0,0,.3)` 부드러운 깊이.
**타이포:** Pretendard 유지. h1 20/700, 카드제목 14/600, 본문 13/400, 캡션 11/400.
**간격(SPACING):** 기존 토큰 유지(xxs4~xl32).

## 2. 레이아웃 (shell.py 재구성)
- **상단 내비(가로, ~52px):** 로고(블러플→바이올렛 그라데이션) + 6카테고리 탭. 활성 탭 = 하단 네온 언더라인(`inset 0 -2px 0 primary`) + 하이라이트. 우측 끝에 사냥상태 칩(● 사냥중 · N층).
- **본문:** 중앙 = (블록 툴바 + 미니맵 캔버스), 우측 = 블록 리스트 패널. 비-동선 페이지는 중앙에 폼.
- **하단 컨트롤바(~58px):** ▶시작(F1, 그라데이션+글로우) · ■정지(F2) · (우측) HP/MP 실시간 네온 바 + %.
- 기존 좌측 사이드바 + 우측 로그도크 → 상단 내비 + 하단 컨트롤바로 대체. (로그는 별도 토글/시스템 탭으로 이동)

## 3. 미니맵 캔버스 — 캡슐·체인 동선
- **이동 블록 = 길쭉한 둥근 캡슐 바**(start_x→end_x 폭, 타입색 그린, 라운드 pill + 외곽 글로우).
- **사다리/공격/점프/텔포 = 둥근 점**(타입색 + glow, 반경 ~13).
- **커넥터 = 굵은 라운드 바**(블러플, `stroke-linecap=round`, width~9, 부드러운 글로우) — 실행 순서대로 앵커를 잇는다.
- 점선 제거. 선택/드래그 중 요소는 흰 테두리 강조.
- 노란 내 위치 + 공격(빨강)/사냥(파랑) 범위는 그대로 위에 겹침.
- 우측 리스트는 이동=`▬`(바)·액션=`●`(점)으로 캔버스와 시각 일치.

## 4. 마이크로인터랙션 (QSS)
- **호버:** 버튼/탭/카드 배경 한 단계 밝게(surface_2→surface_3) + 강조 요소는 글로우 강화. `QPushButton:hover`.
- **클릭/press:** 살짝 어둡게 + 1px 눌림 느낌(`:pressed`).
- **활성/선택:** primary 테두리 + 글로우(`:checked`).
- **상태 점:** 사냥중 success 점 글로우, 정지 시 subtle.
- (PyQt는 CSS transition 미지원 → 상태별 정적 스타일로 즉각 피드백. 캔버스 노드 호버는 paintEvent에서 hover idx 강조.)

## 5. 구현 접근 (재스킨)
- `theme.py`: `TOKENS`/`RADIUS`/`build_qss()`를 Discord Night로 교체. 기존 함수 시그니처(`build_qss`,`apply_font`,`TOKENS`,`SPACING`,`RADIUS`) 유지 → 나머지 코드 영향 최소.
- `shell.py`: 좌측 사이드바/우측 도크 → 상단 내비 + 하단 컨트롤바. 페이지 스택은 유지.
- `minimap_canvas.RouteCanvas.paintEvent`: 점/선 → 캡슐+둥근점+굵은 라운드 커넥터.
- `minimap_geom.BLOCK_COLORS`: 네온 팔레트로 갱신.
- 페이지/위젯(StatusField/필드들)은 토큰 QSS로 자동 반영 — 개별 수정 최소.

## 6. 범위 밖 / 후속
- 점 크기·색·글로우 강도 미세조정 → 실게임 테스트하며.
- CSS 트랜지션 애니메이션(PyQt 한계) → 필요 시 QPropertyAnimation 후속.
- 로그 패널 위치 최종 결정(시스템 탭 vs 토글 드로어).
