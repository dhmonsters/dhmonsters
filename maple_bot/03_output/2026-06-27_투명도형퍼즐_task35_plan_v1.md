# Task 35 계획

## 목표
- 16GT 성능을 1분 안에 확인할 수 있는 경량 GT 러너를 만든다.

## 범위
- JSONL에 이미 기록된 `track`, `engine.track`, `cands`만 사용한다.
- 영상 재생, local-box family 폭발, selector shadow backfill은 이번 경량 러너에서 제외한다.
- 결과는 Markdown 표와 JSON raw summary로 출력한다.

## 지표
- `track`: 기록된 기본 추적점.
- `engine`: 기록된 engine track.
- `raw_center_oracle`: GT를 아는 상태에서 후보 중심 중 가장 가까운 후보.
- `raw_box_oracle`: GT를 아는 상태에서 후보 박스 내부 최적점.

## 성공 기준
- 순수 함수 테스트가 통과한다.
- 실제 16GT 전체 실행이 1분 이내에 끝난다.
- 전체 puzzle 테스트와 문법 검사가 통과한다.
