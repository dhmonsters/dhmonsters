# 투명도형퍼즐 첫 인게임 테스트 체크리스트

## 테스트 목적

첫 인게임 테스트는 자동 해결률 확정이 아니라 live capture, ROI, 녹화, trace, 후보 흐름을 검증하는 라운드다.

## 실행 전 확인

- 게임 창은 메인 모니터에 둔다.
- 퍼즐이 뜨기 전에 `puzzle.py`를 실행한다.
- `capture check`로 board crop이 퍼즐 영역만 잡히는지 확인한다.
- 녹화는 solver 정지와 분리되어 있어야 한다.
- F3은 녹화 종료 버튼으로 사용한다.

## 권장 실행 순서

1. `puzzle.py --live-capture-check --output-root 03_output`을 실행한다.
2. 생성된 `capture_check.png`가 퍼즐 ROI만 담는지 확인한다.
3. GUI에서 녹화를 시작한다.
4. 퍼즐이 시작되면 solver 상태와 trace 로그를 본다.
5. solver가 타겟을 놓치면 solver만 멈추고 녹화는 유지한다.
6. 직접 플레이를 끝낸 뒤 F3으로 녹화를 종료한다.
7. 생성된 session 폴더의 `raw_cctv.mkv`, `board_crop.mkv`, `overlay.mkv`, `trace.jsonl`, `report.md`를 보관한다.

## 현재 자동 검증 결과

- headless 기본 replay는 실행된다.
- companion JSONL 후보 로그가 자동 연결된다.
- 기본 테스트 2프레임에서 후보 count 19가 기록됐다.
- identity 상태가 `TRACK_CONFIDENT`로 기록됐다.
- consensus gate는 offline score 경로에 opt-in으로 연결됐다.

## 아직 주의할 점

- live detector와 consensus gate가 `puzzle.py`의 실시간 solver 루프에 완전히 결합된 상태는 아니다.
- 첫 인게임 테스트는 자동 성공률 측정보다 capture와 기록 품질 검증을 우선한다.
- 실패 영상과 trace가 다음 성능 개선의 입력 데이터가 된다.
