# Task 17 Implementation Plan

## 목표
Replay 완료 후 생성된 `trace.jsonl`을 UI가 자동으로 읽어 마지막 분석 상태를 반영한다.

## 설계
`PuzzleConsoleWindow.run_replay_input()`은 replay runner가 반환한 report 경로를 기준으로 같은 폴더의 `trace.jsonl`을 찾는다. trace 파일이 있으면 순서대로 이벤트를 적용하고, 없으면 기존 replay 완료 로그만 남긴다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- Replay runner가 `report.md`를 반환하면 UI가 `trace.jsonl`을 읽는다.
- trace의 마지막 `IDENTITY_STATE`가 상태, confidence, hold, reason에 반영된다.
- trace 파일이 없어도 replay 완료 상태는 유지된다.
