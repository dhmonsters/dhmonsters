# 2026-06-30 puzzle alarm sound v1 plan

## Goal

퍼즐이 감지됐을 때 사용자가 즉시 알아차릴 수 있도록 소리 알람을 실제 `PUZZLE_ACTIVATED` 이벤트에 연결한다.

## Scope

- `퍼즐 감지 알람` 체크박스가 켜져 있을 때만 소리를 낸다.
- 같은 세션의 감지 이벤트는 중복으로 계속 울리지 않는다.
- UI 로그에 소리 재생, 중복 생략, 비활성 상태를 명확히 남긴다.
- Solver 판단, ROI, CCTV 캡처 로직은 변경하지 않는다.

## Verification

- 알람 핸들러 호출 여부를 테스트한다.
- 체크박스가 꺼졌을 때 소리가 나지 않는지 테스트한다.
- 콘솔 및 live 관련 회귀 테스트를 실행한다.
