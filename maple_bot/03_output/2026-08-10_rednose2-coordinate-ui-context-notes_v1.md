# 빨코2 좌표 설정 UI 설계 작업 기록

## 확인된 현재 구조

- 빨코2 좌표 일부는 config.json에 있지만 `config_adapter.py`가 실행 시 고정 프로필을 새로 만들어 사용자 저장값을 반영하지 않는다.
- F1 시작 경로는 `to_runtime_config()`를 다시 호출하고 빨코 전용 러너를 재구성한다.
- 빨코2 러너는 프로필의 X 값과 비율 값을 소비하며 실제 미니맵 크기에 맞춰 환산한다.
- 현재 동선·이동 탭에는 사냥터 프리셋 카드가 있으나 빨코2 전용 좌표 편집 UI는 없다.

## 사용자 결정

- 빨코2만 대상으로 한다.
- 2층 범위와 회수 경로의 X 좌표만 수정한다.
- 숫자 입력만 제공하고 현재 좌표 가져오기는 제공하지 않는다.
- 실행 중 즉시 반영하지 않고 다음 F1 시작부터 적용한다.
- 기본값 복원 버튼을 제공한다.
- 사냥터 프리셋에 섞지 않고 빨코2 전용 카드로 구현한다.

## 설계 원칙

- 기존 검증된 좌표는 기본값으로 유지한다.
- UI에 공개한 허용 키만 사용자 값으로 덮어쓴다.
- 잘못된 범위는 전부 저장하지 않고 기존 설정을 보존한다.
- 빨코2 사냥 알고리즘과 빨코3 설정은 유지하되, 공개 좌표가 올바른 기존 접근자로 연결되도록 최소 수정한다.

## 설계 검토 이후

- 2026-08-10. 사용자가 설계 문서를 검토하고 구현 계획 진행을 승인했다.
- 2026-08-10. 테스트 우선 순서로 어댑터 병합, 전용 카드, 페이지 연결, 통합 검증의 네 작업으로 구현 계획을 나눴다.

## 구현 및 검증 결과

- 2026-08-10. 빨코2 이동·회수 X 좌표 15개를 저장 설정에서 읽고, 기준 미니맵 너비 172에 맞춘 비율을 다시 생성하도록 런타임 어댑터를 변경했다.
- 2026-08-10. 관계가 있는 좌표 묶음이 잘못된 경우 해당 묶음만 기본값으로 되돌리고, 다른 정상 좌표는 그대로 적용하도록 검증했다.
- 2026-08-10. 동선·이동 탭의 사냥터 프리셋 카드 아래에 빨코2 좌표 전용 카드를 추가했다.
- 2026-08-10. 기본값 복원은 화면 입력값만 바꾸며 저장 버튼을 누르기 전에는 설정 파일을 변경하지 않는 동작을 테스트로 확인했다.
- 2026-08-10. 저장 시 빨코2의 다른 설정을 보존하고 허용된 X 좌표만 갱신하며, 다음 F1 시작에서 `to_runtime_config()`를 통해 새 좌표가 적용되는 기존 경로를 유지했다.
- 2026-08-10. 관련 테스트 32개가 모두 통과했다. 경고 8개는 `core_ui/pages.py`의 기존 `mss.mss` 사용 중단 예정 경고이며 이번 변경에서 새 경고는 발생하지 않았다.
- 2026-08-10. 변경된 Python 파일의 `compileall` 문법 검사가 출력 없이 종료 코드 0으로 통과했다.
- 2026-08-10. 기능 브랜치 전체 변경에 공백 오류가 없고, 변경 범위가 빨코2 좌표 UI와 관련 테스트 및 작업 문서로 한정된 것을 확인했다.
- 2026-08-10. 승인된 구현 범위에 따라 EXE 빌드, 설치본 생성, 배포는 수행하지 않았다.
- 2026-08-10. 일반 2층 사냥은 `floor2_right_x`, 회수 우측 끝 이동은 `floor2_right_safe_x`를 소비하도록 기존 접근자 연결을 바로잡고 회귀 테스트로 확인했다.
- 2026-08-10. bool과 0~171 범위를 벗어난 외부 손상값은 UI에 1/0이나 경계값으로 표시하지 않고 해당 좌표의 기본값으로 복구하도록 회귀 테스트로 확인했다.
- 2026-08-10. 최종 전체 리뷰에서 Critical, Important, Minor 발견 사항이 없었으며 통합 준비 상태를 Ready로 판정했다.
