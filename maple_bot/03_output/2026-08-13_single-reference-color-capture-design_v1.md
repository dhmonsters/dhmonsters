# 단일 캐릭터 기준색 캡처 설계

## 목적

연결·인식 화면의 기준색 설정을 HSV 범위 네 개에서 대표 색상 한 개로 단순화한다. 사용자는 게임 화면에서 캐릭터 마커를 드래그하고, 프로그램은 선택 영역의 평균 색상 하나를 저장해 캐릭터 색상 검출에 사용한다.

## 사용자 흐름

1. 사용자가 `기준색 캡처`를 누른다.
2. 프로그램이 게임창의 정지 화면을 표시한다.
3. 사용자가 원하는 노란색 영역을 왼쪽 버튼으로 드래그하고 버튼을 놓는다.
4. 버튼 해제가 정상 이벤트로 들어오거나 해제 상태 감시에서 확인되면 마지막 드래그 영역을 한 번만 확정한다.
5. 선택 창이 자동으로 닫히고 선택 영역의 평균 RGB 색상 한 개를 저장한다.
6. UI에는 저장된 색상 견본과 `#RRGGBB · RGB(R, G, B)` 값이 표시된다.
7. 실행 중인 봇에는 정지 후 다음 F1 시작 시 새 색상이 적용된다.

X 버튼 또는 ESC로 선택 창을 닫은 경우에만 취소로 처리한다. 정상 드래그 후에는 사용자가 X를 추가로 누를 필요가 없다.

## 설정 형식과 호환

새 설정은 `minimap.reference_color_rgb` 한 항목에 `[R, G, B]` 형식으로 저장한다. UI에서는 이 값을 기준색 한 개로 표현한다.

새 값이 없으면 기존 `char_r`, `char_g`, `char_b` 값을 한 번 읽어 호환한다. 새 값이 존재하면 기존 `hsv_h_low`, `hsv_h_high`, `hsv_s_low`, `hsv_v_low` 값은 캐릭터 색상 검출에 사용하지 않는다. 기존 키를 즉시 삭제하지는 않아 이전 버전으로 되돌릴 때 설정 파일이 손상되지 않게 한다.

## 평균 색상 계산

선택 영역의 모든 BGR 픽셀을 채널별 산술 평균하고 반올림한 뒤 RGB 순서로 저장한다. 이는 사용자가 요청한 드래그 영역 전체 색상의 평균값에 해당한다.

선택 영역이 원본 이미지 기준 2×2보다 작으면 저장하지 않고 선택 창에 `영역이 너무 작습니다`를 표시한다. 사용자는 같은 창에서 다시 드래그할 수 있다.

## 자동 검출 범위

저장된 대표 RGB를 HSV로 변환한 뒤 프로그램이 아래 허용 범위를 자동 계산한다.

- 색상 H는 대표 H 기준 ±10.
- 채도 S 하한은 대표 S에서 40을 뺀 값이며 최소 0.
- 밝기 V 하한은 대표 V에서 40을 뺀 값이며 최소 0.
- S와 V 상한은 255.

UI에는 자동 범위를 노출하지 않는다. 점 크기 최소·최대 설정은 기존과 같이 유지한다.

## UI 변경

다음 네 슬라이더를 제거한다.

- 색상 시작 H.
- 색상 끝 H.
- 채도 최소 S.
- 밝기 최소 V.

대신 `저장된 기준색` 행에 색상 견본, HEX/RGB 값, `기준색 캡처` 버튼을 표시한다. 캐릭터 템플릿 캡처 버튼과 점 크기 최소·최대는 유지한다.

## 드래그 확정 안정화

캔버스는 드래그 시작 시 마우스를 고정하고 마지막 이동 좌표를 저장한다. 정상 `mouseReleaseEvent`와 왼쪽 버튼 해제 상태 감시는 동일한 단일 완료 함수로 연결한다. 완료 함수는 드래그 상태를 먼저 종료해 중복 호출을 차단한 뒤 영역을 한 번만 발행한다.

해제 이벤트가 누락돼도 왼쪽 버튼이 풀린 것이 확인되면 마지막 좌표로 확정한다. 이 보완은 같은 선택기를 사용하는 기준색과 캐릭터 템플릿 캡처에 함께 적용한다.

## 템플릿 동작

캐릭터 템플릿은 기존 설계대로 `player/y_p.png` 하나만 사용한다. 새 캡처는 임시 PNG 저장 성공 후 기존 파일을 교체하며 파일을 누적하지 않는다.

## 오류 처리

- 캡처 실패 시 기존 기준색을 유지하고 오류 메시지를 표시한다.
- 너무 작은 영역은 저장하지 않고 같은 선택 창에서 재시도한다.
- 설정 저장 실패 시 기존 메모리 값을 적용 완료로 표시하지 않는다.
- X 또는 ESC로 닫은 경우에만 `기준색 선택을 취소했습니다`를 표시한다.

## 테스트 기준

- 해제 이벤트가 누락돼도 버튼 해제 감시로 영역이 한 번만 확정된다.
- 정상 해제 이벤트와 감시 완료가 중복 저장을 만들지 않는다.
- 선택 영역의 픽셀 평균이 `[R, G, B]` 한 값으로 저장된다.
- 기존 HSV 네 값이 있어도 새 대표 색상이 우선한다.
- 새 대표 색상이 없으면 기존 RGB 설정으로 호환된다.
- 기준색 UI에서 HSV 네 슬라이더가 사라지고 색상 견본 하나가 표시된다.
- 점 크기 최소·최대와 템플릿 캡처 기능은 유지된다.
- 기존 `y_p.png`는 새 템플릿으로 덮어써지고 누적 파일이 생기지 않는다.

## 제외 범위

EXE 빌드, 설치본 생성, 배포는 이번 구현에 포함하지 않는다.
