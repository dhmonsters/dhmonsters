# 이동 블럭 무동작 진단 계획

## 목표

빨코2와 빨코3을 제외한 일반 맵에서 UI 이동 블럭 동선이 실행되지 않는 원인을 코드와 테스트 증거로 특정한다.

## 조사 순서

1. UI 이동 블럭 저장 형식과 설정 키를 확인한다.
2. 설정이 런타임 생성 단계까지 전달되는지 추적한다.
3. 일반 맵에서 이동 실행 스레드와 실행권 소유 조건을 확인한다.
4. 빨코2·빨코3 전용 러너와 일반 블럭 러너의 분기 차이를 비교한다.
5. 기존 테스트 또는 최소 재현 테스트로 원인 가설을 검증한다.

## 제한

- 이번 단계에서는 제품 코드를 수정하지 않는다.
- 원인과 최소 수정 범위를 보고한 뒤 별도 승인을 받는다.
