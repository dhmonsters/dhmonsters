# 투명도형퍼즐 Task 19 계획

## 목표
Replay trace의 `FRAME_REPLAYED` 이벤트가 원본 프레임 경로를 포함하고, UI가 현재 CCTV 프레임 출처를 알 수 있게 한다.

## 설계
`FramePacket`에 `source_path` 선택 필드를 추가한다. 이미지 시퀀스와 JSONL replay는 실제 이미지 경로를 넣고, 영상 replay는 `video_path#frame=N` 형태의 출처 문자열을 넣는다.

`puzzle.py`는 `FRAME_REPLAYED` payload에 `source_frame_path`를 기록한다. `PuzzleConsoleWindow.apply_trace_event()`는 `FRAME_REPLAYED` 이벤트를 받으면 frame index별 출처를 저장하고 CCTV 상태 라벨을 현재 프레임 출처로 갱신한다.

## 검증 기준
- 이미지 시퀀스 frame source가 `source_path`를 보존한다.
- JSONL replay frame source가 resolved `source_path`를 보존한다.
- headless replay의 `FRAME_REPLAYED` 이벤트가 `source_frame_path`를 포함한다.
- UI가 `FRAME_REPLAYED` 이벤트를 CCTV 상태와 frame source map에 반영한다.
