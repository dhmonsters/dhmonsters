# Puzzle2 라이브 SOT 검증 계획

## 목적

받은 V6497 추적 코어가 실제 게임창에서 타겟 신분을 얼마나 안정적으로 유지하는지 사용자가 즉시 확인할 수 있게 한다.

## 범위

- 새 진입점 `puzzle2.py`만 추가한다.
- 기존 `puzzle.py`와 기존 솔버 코드는 변경하지 않는다.
- 받은 폴더의 비밀번호, 설치, 다운로드, 자기삭제 실행기는 사용하지 않는다.
- 마우스 출력은 시작 시 OFF이며 UI 버튼으로 ON/OFF를 전환한다.
- CCTV에는 게임 퍼즐 ROI, 선택 표적, 후보 가지, 상태와 신뢰도를 표시한다.

## 성공 기준

1. `puzzle2.py`가 독립적으로 실행된다.
2. 실제 게임창을 찾고 1280x720 클라이언트의 퍼즐 ROI를 표시한다.
3. 솔버 시작과 종료가 UI에서 동작한다.
4. 마우스 ON/OFF가 실행 중 즉시 반영된다.
5. 마우스 OFF에서는 추적 계산과 시각화만 수행하고 입력을 보내지 않는다.
6. 종료 후 최소 로그와 요약만 저장한다.

## 검증 순서

1. 마우스 상태와 외부 코어 경로 검증 단위 테스트를 작성한다.
2. UI 스모크 테스트를 작성한다.
3. 외부 코어를 실행하지 않는 가짜 런타임으로 상태 전환을 검증한다.
4. 실제 창 캡처 스모크를 수행한다.
5. 사용자가 실제 퍼즐에서 마우스 OFF로 먼저 확인한 뒤 ON으로 전환한다.
