# Claude v2.4.0 릴리스 컨텍스트 노트

## 결정 사항

- 제품명과 설치파일 접두사는 `Claude`를 사용한다.
- 최종 설치파일 이름은 `Claude_v2.4.0_Setup.exe`다.
- 릴리스 설명에는 미니맵·캐릭터 좌표 정렬, 감지 좌표 조절 UI, F1 설정 갱신, 퍼즐·검증도구 연결 해제, 타임아웃 조정을 포함한다.
- 기존 Git 스테이징과 관련 없는 변경은 삭제하거나 초기화하지 않는다.

## 확인 내용

- `installer.iss`의 `OutputBaseFilename`은 `Claude_v{#AppVersion}_Setup`으로 이미 올바르다.
- 현재 버전은 2.3.11이며 네 개의 버전 관련 파일을 모두 갱신해야 한다.
- 저장소에는 이전 작업의 스테이징과 미추적 파일이 다수 존재한다. 릴리스 커밋은 명시적 경로만 대상으로 만든다.

## 검증 기록

- `compileall`로 `run_integrated.py`, `core`, `core_ui`, `ui` 문법 검사를 통과했다.
- F1 설정 갱신, 퍼즐 연결 해제, 타임아웃, 게임창 영역, 캐릭터 감지, UI 페이지 관련 핵심 테스트 51개가 통과했다.
- 넓은 관련 테스트 87개 중 8개는 이전 런타임 구조와 미니맵 자동 확대 동작을 기대해 실패했다. 이번 릴리스 기능의 핵심 테스트에는 실패가 없다.

## 배포 기록

- 과거 Git 이력에 있던 `Claude_v2.2.12_Setup.exe` 612MB 객체를 제외한 깨끗한 릴리스 브랜치를 재구성했다.
- 깨끗한 브랜치에서 핵심 회귀 테스트 51개와 전체 소스 문법 검사를 다시 통과했다.
- 누락된 안티몹 템플릿 10개와 `build_release_config.py`를 릴리스 브랜치에 포함했다.
- 최종 설치파일 이름은 `Claude_v2.4.0_Setup.exe`다.
- 최종 설치파일 크기는 638,840,027바이트다.
- SHA-256은 `B3C97CD3887BAAE32DCD0D1BB514894C0AB53239220B921BC3BA29D4FD04E647`이다.
