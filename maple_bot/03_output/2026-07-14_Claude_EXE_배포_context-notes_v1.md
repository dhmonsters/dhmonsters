# Claude EXE 배포 판단 기록

## 2026-07-14

- 다른 PC에는 Python이 없으므로 소스 압축본이 아닌 독립 실행형 EXE가 필요하다.
- 기존 빌드 설정은 `main.py`를 진입점으로 사용해 최신 B 맵핑 통합 기능이 누락될 수 있었다.
- 새 빌드는 `run_integrated.py`를 진입점으로 사용한다.
- 버전은 올리지 않고 현재 `2.1.5`를 유지한다.
- 실제 업데이트 저장소 경로는 기능 연결을 유지하기 위해 변경하지 않는다.
- 기존 산출물을 덮어쓰지 않도록 `03_output\Claude_v2.1.5_portable`을 새 대상으로 사용한다.
- 기존 제품명의 대문자 표기는 추적 파일에서 모두 제거했다.
- 소문자 표기는 실제 업데이트용 GitHub 저장소 주소에만 유지했다.
- B 맵핑 관련 회귀 테스트는 90개가 통과했고 기존 `mss.mss()` 폐기 예정 경고 2개가 발생했다.
- 포터블 `Claude.exe`는 관리자 권한 재실행 후 8초 이상 응답 상태를 유지했다.
- 포터블 폴더 크기는 725,253,611바이트다.
- 설치파일 크기는 375,680,713바이트다.
- 설치파일 SHA-256은 `565F639EFEEEECBE6F1CC5468C241959BEA89F574E4D8DD347F77659D7502318`이다.
- 설치형 EXE는 컴파일만 검증했으며 실제 설치는 다른 PC 인수 테스트에서 확인한다.
- 대용량 포터블 폴더와 설치파일은 Git 커밋에서 제외하고 `03_output` 산출물로 유지한다.
