# Claude v2.4.4 배포 계획

1. 버전 파일과 설치파일 이름을 2.4.4로 통일한다.
2. UTF-8 한글 문구와 버전 일치를 검사한다.
3. 빨코2 관련 테스트와 변경 파일 구문 검사를 실행한다.
4. 배포 준비 변경을 커밋하고 현재 소스 브랜치를 푸시한다.
5. PyArmor·PyInstaller와 Inno Setup으로 설치파일을 생성한다.
6. 빌드·설치 결과에서 신규 회수 코드와 UI 설정이 포함됐는지 검사한다.
7. 검증을 통과한 `Claude_v2.4.4_Setup.exe`만 GitHub Release에 게시한다.
8. main 브랜치 자동 업데이트 메타데이터를 2.4.4로 연결하고 공개 응답을 확인한다.
