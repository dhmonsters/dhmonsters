# 캡처 드래그 해제 초기화 수정 계획 v2

## 목적

- 첫 수정에서 남은 해제 좌표 1~2픽셀 오차 문제를 제거한다.

## 변경 범위

1. 드래그 후 해제 좌표가 시작점 근처로 돌아오는 경우를 재현한다.
2. 이동 기록이 있을 때는 마지막 드래그 위치를 유지한다.
3. 이동 기록이 없을 때만 해제 좌표를 사용한다.

## 성공 기준

- 시작점과 정확히 같거나 근처인 해제 좌표 모두 한 번의 드래그로 완료된다.
- 이동 이벤트 없는 기존 선택도 완료된다.
- 기준색과 캐릭터 템플릿 연결 테스트가 통과한다.
- EXE 빌드와 배포는 진행하지 않는다.
