# 캡처 드래그 해제 초기화 수정 작업 기록 v2

## 추가 확인

- 실행 중인 Claude 프로세스는 첫 수정 이후 재시작됐다.
- 첫 수정은 `마지막 위치가 시작점이거나 해제 좌표가 시작점과 다르면 덮어쓰기` 조건이었다.
- 이 조건은 해제 좌표가 시작점 근처로 돌아오는 실제 환경에서 마지막 위치를 다시 덮어쓴다.

## 결정

- 마지막 위치가 시작점인 경우에만 이동 이벤트가 없었다고 판단하고 해제 좌표를 사용한다.
- 마지막 위치가 시작점과 다르면 해제 좌표와 관계없이 마지막 위치를 보존한다.

- 시작점 `(10, 10)`, 마지막 이동 `(30, 25)`, 해제 `(11, 11)` 재현에서 선택 결과가 빈 값으로 실패했다.
- 조건식 수정 후 선택기와 전체 페이지 테스트는 `22 passed`다.
