# 빨코2 회수 연속 실행 및 공격시간 설정 작업 기록

- 현재 결함의 원인은 회수 전용 사다리 복귀가 실패한 다음 반복에서 일반 2층 이탈 복구가 먼저 실행되고, 성공 시 `_collection_stage`와 회수 타이머를 초기화하는 데 있다.
- 승인된 수정은 진행 중인 회수 단계를 일반 사냥보다 우선 재개하는 방식이다.
- 24번 하강 확인 뒤 오른쪽 텔레포트 2회를 실행하고 7번 사다리 목표 X 이동을 이어간다.
- UI에는 14/15번 발판 진입 확인 후 다음 윗텔포 전 공격 홀드시간과 27번 발판 진입 확인 후 공격 홀드시간만 추가한다.
- 체류시간 설정은 추가하지 않고 27번 마무리 공격 0.5초는 유지한다.
- 새 설정은 기존 빨코2 설정과 동일하게 저장 후 다음 F1 재시작부터 반영한다.
- 기존 사용자가 저장한 일반 공격·텔레포트 설정이 초기화되지 않도록 `timing_version=2`를 유지하고, 누락된 새 키만 0.50초 기본값으로 병합한다.
- 수정 전 선택 테스트는 의도한 차이로 8건 실패하고 기존 테스트 52건은 통과했다.
- 구현 후 빨코2 전체와 설정 변환 테스트 68건이 통과했다.
- 변경한 Python 파일의 `py_compile` 구문 검사가 통과했고 `git diff --check`에서 공백 오류가 없었다.
