# Task46 계획

## 목표

기본 시간축 selector에서 track hint를 정체성 선택 비용으로 직접 쓰지 않도록 바꿔 16GT 성공 개수를 6/16에서 7/16으로 올린다.

## 판단 근거

- `000_0615_022618`은 기본값에서 41.6px로 실패하지만 `track_hint_weight=0.0`에서는 20.7px로 성공한다.
- 같은 설정에서 기존 성공판 6개는 깨지지 않는다.
- track hint는 준비 구간 anchor와 target support 계산에는 쓸 수 있지만, 투명화 이후 후보 선택 비용에 직접 들어가면 배경/잔상 쪽으로 갈아타는 원인이 된다.

## 작업 순서

1. 기본 설정이 충돌하는 track hint를 정답 선택 근거로 쓰지 않는다는 실패 테스트를 추가한다.
2. RED 실패를 확인한다.
3. `TemporalIdentityConfig.track_hint_weight` 기본값을 `0.0`으로 낮춘다.
4. 기존 opt-in track hint 테스트가 명시적 설정으로 계속 통과하는지 확인한다.
5. 16GT를 다시 채점해 `temporal_identity 7/16`을 확인한다.

## 성공 기준

- temporal identity 단위 테스트가 통과한다.
- `_fast_gt_score.py` 기준 `temporal_identity`가 7/16 이상이다.
- 기존 성공판 중 `035137`을 포함한 6개가 깨지지 않는다.
