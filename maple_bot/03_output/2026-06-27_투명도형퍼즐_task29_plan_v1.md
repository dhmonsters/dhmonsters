# Task 29 계획

## 목표
- 사용자가 명령을 외우지 않아도 `run_puzzle_test.bat` 더블클릭으로 기본 투명도형 테스트를 실행할 수 있게 한다.

## 범위
- 프로젝트 루트에 `run_puzzle_test.bat`를 추가한다.
- 배치 파일은 프로젝트 폴더로 이동한 뒤 `puzzle.py --transparent-test --max-frames`를 실행한다.
- Python 3.14 고정 경로를 먼저 사용하고, 없으면 `python` 명령으로 fallback한다.
- `.codex_pydeps`를 `PYTHONPATH`에 포함해 OpenCV 같은 테스트 의존성을 찾을 수 있게 한다.

## 검증
- 배치 파일 존재와 핵심 명령 구성을 테스트한다.
- 기존 `puzzle.py --transparent-test` 경로가 깨지지 않는지 전체 puzzle 테스트로 확인한다.
