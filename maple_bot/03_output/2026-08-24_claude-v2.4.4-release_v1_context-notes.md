# Claude v2.4.4 배포 기록

- 배포 대상은 커밋 `c5dfcde`의 빨코2 회수 단계 연속 실행, 24번 하강 후 우측 텔레포트 2회, 14/15번·27번 공격 홀드시간 UI 설정이다.
- 설치파일 이름은 `Claude_v2.4.4_Setup.exe`로 고정한다.
- 자동 업데이트 주소는 GitHub Release의 `v2.4.4/Claude_v2.4.4_Setup.exe`를 사용한다.
- 기존 사용자의 빨코2 타이밍 설정을 보존하기 위해 설정 버전 2를 유지한다.
- 빌드나 설치 검증에서 오류가 발생하면 GitHub Release 게시 전에 중단한다.
- 배포 직전 빨코2 관련 테스트와 설정 변환 테스트 68개가 통과했다.
- 변경한 Python 파일의 `py_compile` 구문 검사가 통과했다.
- 버전 파일과 배포 스크립트는 UTF-8 엄격 디코딩과 2.4.4 버전·URL 일치 검사를 통과했다.
- 배포 준비 커밋 `2bc2669`를 원격 `codex/claude-v2.4.2-release` 브랜치에 푸시했다.
- PyArmor 9.2.4와 PyInstaller 6.20.0 빌드가 완료됐다.
- 빌드 폴더 `dist/Claude_2.4.4`의 버전, 회수 단계 우선 처리, 하강 후 우측 텔레포트 2회, 한글 공격시간 UI, 필수 리소스와 소스 해시가 일치했다.
- Inno Setup 6.7.2 컴파일이 완료됐다.
- 설치파일은 `03_output/Claude_v2.4.4_Setup.exe`, 크기 544,123,747바이트, SHA-256 `B7D3178FE32F78C9E63069C016D5AB16880670AA8BBE12185DD4F09404F93E08`이다.
- `03_output/verify_install_2.4.4_v1`에 선택 작업 없이 무인 설치했고 종료 코드 0과 설치 버전 2.4.4를 확인했다.
- 설치된 실행파일·신규 회수 코드·설정 UI·거탐 템플릿·미니맵·입력 DLL의 해시가 빌드 원본과 일치했다.
