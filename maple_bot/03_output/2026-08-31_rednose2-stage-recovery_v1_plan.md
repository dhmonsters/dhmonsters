# 빨코2 회수 단계 재선택 계획

## 목적

- 회수 중 현재 좌표가 검출되면 실제 위치에 맞는 다음 단계를 선택한다.
- 현재 좌표가 미검출되면 마지막으로 확정된 단계의 다음 단계를 유지한다.
- 기존 X 도착 판정과 텔레포트 전 조건은 변경하지 않는다.

## 구현 순서

1. 1층 추락 후 7번 복귀가 `right_edge`로 이어지는 실패 재현 테스트를 작성한다.
2. 14/15·16·27·2층 위치별 단계 재선택 테스트를 작성한다.
3. 미검출 시 이전 확정 단계의 다음 단계를 유지하는 테스트를 작성한다.
4. `rednose2_runner.py`의 회수 실패 처리만 최소 수정한다.
5. 빨코2 관련 테스트와 Python 컴파일을 실행한다.

## 완료 기준

- 27번 진행 중 1층 추락 시 7번 복귀 후 `right_edge`에서 재개한다.
- 실제 위치가 14/15·16·27이면 각각 16·27·마무리 단계로 이동한다.
- 미검출이면 이전 확정 단계에서 계산한 다음 단계를 유지한다.
- 24번이나 7번 단계로 임의 초기화하지 않는다.
