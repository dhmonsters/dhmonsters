# 캡처 드래그 해제 고정 작업 기록

## 확정된 사용 방식

사용자는 마우스 왼쪽 버튼을 누른 채 원하는 영역까지 이동한 뒤 버튼을 놓아 선택을 완료한다.

## 관찰된 증상

드래그 후 버튼을 놓아도 선택 상태가 풀리지 않는다. 그 상태에서 한 번 더 누르면 새로운 시작점이 잡혀 1×1로 초기화된다.

## 결정

해제 좌표 보정만으로는 해결되지 않았다. 이번 수정은 마우스 입력 고정과 명시적인 드래그 상태를 추가해 해제 이벤트 전달 자체를 보장하는 방향으로 제한한다.

## 재현 근거

수정 전 테스트에서 마우스 고정 호출 누락과 무효 선택 뒤 시작점 잔존이 각각 실제 실패했다. 구현 후 선택기 테스트는 10개 모두 통과했다.

## 회귀 검증

`tests/test_shot_selector.py`와 `tests/test_pages.py`를 함께 실행해 24개 테스트가 통과했다. 경고 9개는 기존 `mss.mss` 폐기 예정 경고다.

## 배포 범위

이번 작업에서는 EXE 빌드, 설치본 생성, 배포를 수행하지 않는다.
