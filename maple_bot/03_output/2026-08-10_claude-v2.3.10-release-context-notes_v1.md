# Claude v2.3.10 릴리스 작업 기록

## 확정 사항

- 제품명은 Claude이다.
- 실행 진입점은 run_integrated.py이며 활성 UI는 core_ui이다.
- v2.3.10에는 빨코2 이동·회수 X 좌표 15개 편집, 다음 F1 적용, 일반 사냥과 회수 우측 끝 좌표 분리, 손상 설정 기본값 복구를 포함한다.
- 구형 UI와 구형 main.py 코드는 다시 연결하지 않는다.
- Interception 연결 실패 시 다른 입력 방식으로 폴백하지 않는다.
- 로컬 config.json의 개인 값은 배포에 포함하지 않고 정제된 설정만 사용한다.
- 현재 공유 작업 트리의 다른 변경은 릴리스에 섞지 않는다.
- 설치 파일이 GitHub Release에 올라간 뒤 main의 version.json을 2.3.10으로 병합한다.
- 코드 서명 인증서는 없으므로 설치 파일은 서명되지 않는다.
