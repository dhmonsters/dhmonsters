# 일반 동선 실행 및 설정 경로 수정 계획

## 목적

- 사용자 맵에 저장된 좌표 동선 블록이 `route_mode` 누락과 관계없이 실행되게 한다.
- 빨코2와 빨코3은 기존 전용 실행기를 계속 우선 사용하게 한다.
- 관리자 권한 재실행 뒤에도 개발 실행의 설정 파일이 프로젝트 폴더에 저장되게 한다.

## 변경 범위

1. `core/runtime.py`의 일반 동선 실행기 선택 조건을 저장된 블록 존재 여부에 맞춘다.
2. `core/admin_util.py`가 관리자 재실행의 작업 폴더를 명시하도록 한다.
3. 일반 맵, 빨코2·빨코3 우선순위, 관리자 재실행 작업 폴더를 회귀 테스트한다.

## 성공 기준

- `route_mode=False`여도 일반 사용자 맵의 `route_steps`가 `RouteStateRunner`에 연결된다.
- 빨코2·빨코3에서는 일반 블록보다 전용 실행기가 우선한다.
- 관리자 재실행 호출의 작업 폴더가 실행 파일 또는 진입 스크립트가 있는 폴더다.
- 관련 테스트와 파이썬 컴파일 검사가 통과한다.

## 제외 범위

- 기존 설정 파일 삭제 또는 자동 병합은 하지 않는다.
- EXE 빌드와 배포는 하지 않는다.
