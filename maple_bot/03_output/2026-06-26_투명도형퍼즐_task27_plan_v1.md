# Task 27 계획

## 목표
- `puzzle.py --headless --replay <frames>` 실행 시 세션 산출물 폴더 생성에서 막히지 않게 한다.
- 날짜별 세션 폴더 이름을 Windows와 sandbox에서 안정적인 ASCII 이름으로 고정한다.

## 범위
- `SessionManager`의 날짜별 세션 폴더 suffix를 `transparent_puzzle_sessions`로 바꾼다.
- 기존 세션 테스트의 기대 경로를 새 suffix로 맞춘다.
- 실제 `_record_debug` 이미지 폴더로 headless replay를 실행해 산출물이 생성되는지 확인한다.

## 제외
- 라이브 화면 입력, 자동 마우스 입력, 실제 게임 조작은 이번 범위에 넣지 않는다.
