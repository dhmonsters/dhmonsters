# 런타임 설정과 빨코2 복구 작업 기록

## 확정된 결정

- 하단 저장 버튼은 전체 설정 저장 및 적용으로 사용한다.
- 동선·이동 프리셋 버튼은 현재 맵 설정 저장으로 표시한다.
- 전체 저장과 F1은 버프, HP/MP 물약, 펫 먹이를 포함해 갱신한다.
- 중앙 미검출은 마지막 이동 방향을 최대 0.8초 유지한다.
- 포탈 인접 좌우 끝 미검출은 맵 안쪽 방향으로 전환한다.
- 미검출 직전 Y가 1층이면 재검출 전까지 위·아래 텔레포트를 금지한다.
- 1층에서는 14/15, 16, 27 발판 X 이동을 실행하지 않는다.
- 16번 선행 도착은 14/15 성공으로, 27번 선행 도착은 return_floor2 진입으로 처리한다.
- 자동판매는 회수 종료 후 2층 일반 사냥 상태에서만 시작한다.
- 자동판매 상태를 작업 스레드 시작 전에 설정하고 빨코2 입력 해제 후 안전지대 이동을 시작한다.
- 자동판매가 2층 외 위치를 만나면 회수 복구 루틴을 호출하지 않고 보류한다.

## 진행 기록

- 기존 미검출 복구가 마지막 방향을 0.8초 유지하지만 포탈 끝부분을 구분하지 않는 것을 확인했다.
- 기존 F1 갱신이 공격 연속기와 픽업만 갱신하고 버프, 물약, 펫을 누락하는 것을 확인했다.
- 구현 전 실패 테스트 작성 단계로 진행한다.

## 구현 결과

- 하단 버튼은 전체 설정 저장 및 적용 신호를 보내고 동선 프리셋 버튼은 현재 맵 설정 저장으로 구분했다.
- 전체 저장과 F1이 공격 연속기, 픽업, HP/MP 물약, 버프, 펫 먹이를 같은 경로로 다시 적용한다.
- 빨코2 러너가 마지막 정상 X/Y를 보존한다.
- 미검출 위치가 좌우 포탈 인접 구간이면 맵 안쪽으로 이동하고 중앙이면 마지막 방향을 최대 0.8초 유지한다.
- 미검출 직전 Y가 1층이면 재검출 전까지 위·아래 텔레포트를 차단한다.
- 14/15, 16, 27 발판 X 이동 전 1층 여부를 확인한다.
- 이미 14/15, 16, 27에 도착한 Y가 확인되면 완료된 앞 단계를 건너뛴다.
- 16과 27 진입 실패 시 해당 단계를 보존해 24번부터 다시 시작하지 않는다.
- 자동판매는 회수 단계가 없고 빨코2 입력 소유가 해제된 2층 일반 사냥 상태에서만 시작한다.
- 자동판매 상태를 작업 스레드 생성 전에 설정하고 상태 전환 직후 조건을 재확인한다.
- 1층이나 회수 발판에서 자동판매 요청이 발생하면 24번·7번 복구나 아랫텔포를 실행하지 않고 보류한다.

## 검증 결과

- 모든 빨코2 관련 테스트와 자동판매·F1 테스트 47개 통과.
- 변경한 Python 파일 문법 검사 통과.
- 더 넓은 런타임 테스트에서는 이번 변경과 무관한 기존 구형 테스트 6개가 실패했다.
- 전체 셸 테스트에서는 로그 배치 처리와 테마 색상 변경을 반영하지 못한 기존 테스트 2개가 실패했다.
