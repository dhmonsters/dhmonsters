# 런타임 설정과 빨코2 복구 수정 계획

## 목표

- 전체 설정 저장과 F1 시작 시 버프, HP/MP 물약, 펫 먹이 설정을 실행 객체에 반영한다.
- 빨코2 미검출 시 중앙에서는 진행 방향을 잠시 유지하고 포탈 인접 구간에서는 맵 안쪽으로 복구한다.
- 미검출 직전 위치가 1층이면 재검출 전까지 수직 텔레포트를 차단한다.
- 회수 단계가 실제 Y와 선행 도착 발판을 우선 판단하고 자동판매와 동시에 실행되지 않게 한다.

## 검증 기준

- 두 저장 버튼의 역할이 UI에서 구분된다.
- 전체 저장과 F1이 전투 지원 객체를 최신 설정으로 다시 구성한다.
- 중앙·좌측 끝·우측 끝 미검출 방향이 각각 설계대로 결정된다.
- 1층 미검출 중 위·아래 텔레포트가 실행되지 않는다.
- 1층에서 14/15·16·27 X 이동을 시작하지 않는다.
- 16번과 27번 선행 도착 시 적절한 다음 단계로 승급한다.
- 자동판매는 2층 일반 사냥 및 회수 종료 후에만 시작한다.
