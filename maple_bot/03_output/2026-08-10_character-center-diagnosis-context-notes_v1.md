# 캐릭터 중심 좌표 오차 진단 기록

- v2.3.8 배포본에서 발판처럼 허용 범위가 좁은 위치의 정렬 오차가 보고됐다.
- 첨부 화면에서는 노란 표식 중심보다 좌표 기준선이 왼쪽으로 치우쳐 보인다.
- 색상 후보 자체의 중심, 후보 선택, 좌표 변환 중 어느 단계가 원인인지 확인 전에는 보정값을 추가하지 않는다.
- 이번 작업에서는 소스 수정과 테스트까지만 수행하고 새 빌드·배포는 하지 않는다.
- 첨부 마커의 HSV 마스크는 150픽셀, 윤곽 면적은 130이며 중심은 X=28.5, Y=12.0이다.
- v2.3.8의 char_area_max=100 때문에 실제 마커가 후보에서 탈락했다.
- 미검출 뒤 저장된 좌표의 나이를 BlockRunner가 계산만 하고 거부하지 않아 이전 위치가 재사용됐다.
- 기본 최대 면적을 160으로 조정해 실제 마커는 허용하고 반지름 10의 큰 원형 배경 물체는 계속 제외했다.
- 윤곽 중심의 int 버림을 일반 반올림으로 바꿔 X=28.5가 항상 왼쪽 28로 편향되지 않게 했다.
- 허용 시간을 넘긴 위치 샘플은 이동 러너에 None으로 전달되도록 했다.
- 최종 첨부 원본 판독 결과는 (29, 12)이며 확대 회귀 테스트 63개가 통과했다.
