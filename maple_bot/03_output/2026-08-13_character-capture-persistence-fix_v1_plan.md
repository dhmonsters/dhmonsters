# 캐릭터 캡처 저장 수정 계획

## 목표

기준색과 캐릭터 템플릿 캡처 결과를 영구 저장하고 다음 F1 실행에서 스캐너가 새 값을 사용하게 한다.

## 구현 범위

1. 기준색 HSV 네 값을 명시적으로 설정한 뒤 설정 파일을 저장한다.
2. 캐릭터 템플릿은 `player/y_p.png` 하나만 사용하고 새 캡처로 덮어쓴다.
3. 템플릿은 임시 PNG를 먼저 만든 뒤 원본 파일로 교체한다.
4. 설치본에서는 AppData 사용자 템플릿을 우선 로드하고 내장 템플릿은 예비로 사용한다.
5. 저장과 우선 로드 동작을 회귀 테스트한다.

## 제외 범위

EXE 빌드, 설치본 생성, 배포는 수행하지 않는다.
