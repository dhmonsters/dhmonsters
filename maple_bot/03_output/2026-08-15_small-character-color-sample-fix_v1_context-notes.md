# 작은 캐릭터 색상 샘플 수정 기록

- 사용자는 노란 원 밖의 배경이 매번 바뀌므로 원 내부만 작게 캡처해야 한다고 설명했다.
- 8×8 최소 크기 제한은 제거한다.
- 작은 캡처는 형태 템플릿으로 비교하지 않고 노란색 HSV 범위를 만드는 샘플로 사용한다.
- 실제 위치는 전체 노란 원의 면적, 종횡비, 원형도와 이전 위치를 이용해 선택한다.
- 이전 위치 주변 템플릿 탐색과 전체 영역 후보 3회 확인은 유지한다.
- 작은 파일 로드와 배경 변화 테스트는 기존 8×8 제한 코드에서 모두 실패했다.
- 작은 파일 픽셀의 BGR 중앙값으로 HSV 범위를 만들고, 형태 템플릿 목록과 분리했다.
- 탁한 노란 배경 재현에서 S/V 여유값 80은 배경까지 포함해 실패했으며, 여유값 40으로 좁힌 뒤 원 중심을 유지했다.
- 현재 3×2 `y_p.png`는 형태 템플릿 0개, 색상 샘플 1개로 분류된다.
- 실제 3×2 파일에서 계산된 HSV 범위는 `(20,89,213)~(40,255,255)`다.
- staged 삭제 상태인 `tests/test_char_scanner_template_reload.py`는 이미지 대신 `object()`를 반환하는 오래된 테스트 더블 1개가 실패했다. 사용자 삭제 상태를 보존하기 위해 해당 파일은 수정 범위에서 제외했다.
