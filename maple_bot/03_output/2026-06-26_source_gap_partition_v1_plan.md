# Source Gap Partition 계획

## 목표

16개 GT에서 남은 실패를 “후보가 있는데 못 고르는 문제”와 “후보 중심 자체가 틀린 문제”로 나눈다.

## 순서

1. 현재 live source family의 local-box 상한을 clip별로 다시 계산한다.
2. 같은 GT 프레임에서 raw 후보 중심 oracle과 raw 후보 박스 oracle을 계산한다.
3. clip을 네 종류로 분류한다.
   - 현재 source 상한으로 이미 풀리는 판.
   - raw 후보 중심은 맞는데 현재 source가 못 만드는 판.
   - 후보 중심은 틀리지만 후보 박스 안에는 정답이 있는 판.
   - 후보/박스 모두 부족해서 시각 복원이나 검출 보강이 필요한 판.
4. 결과를 `03_output`에 표로 저장한다.

## 성공 기준

- 분류 함수와 raw oracle 계산 테스트가 통과한다.
- 16개 GT 전체에 대해 분류 리포트가 생성된다.
- 다음 구현 방향을 clip별 원인에 맞춰 결정할 수 있다.
