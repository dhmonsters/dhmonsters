# 2026-06-29 라이브 경로 게이트 계획

## 목표

GT 16/16을 만든 selector 계열이 실제 `puzzle.py` 라이브 실행 경로에서도 쓰이는지 확인하고, 인게임 첫 테스트 전에 캡처, ROI, 녹화, 단축키, 마우스 비활성 dry-run을 잠근다.

## 고정 기준

“프레임별 정답 선택기가 아니라, 처음 타겟의 신분을 보류하고 복원할 수 있는 시간축 판별기를 만든다.”

## 범위

1. 16/16 기준선을 문서와 재검증 결과로 고정한다.
2. `puzzle.py` 라이브 경로가 오프라인 전용 꼼수가 아니라 라이브 입력 후보만으로 같은 selector 계열을 호출하는지 테스트로 고정한다.
3. 메인 모니터 캡처, 상대 ROI, 퍼즐 감지 후 녹화 시작, F1/F2/F3 흐름을 확인한다.
4. 실제 마우스 이동 없이 solver 판단과 기록만 도는 dry-run 상태를 검증한다.

## 성공 기준

- GT 기준선 채점이 16/16으로 유지된다.
- 라이브 solver 기본 경로에서 `LiveTemporalSelector`와 scoreboard 연결 runtime이 사용된다.
- F1은 감시만 켜고, 퍼즐 감지 전에는 녹화를 시작하지 않는다.
- F2는 solver만 정지하고 녹화는 유지한다.
- F3은 녹화를 종료한다.
- dry-run에서는 분석 결과가 나오더라도 마우스 클릭 또는 이동이 발생하지 않는다.
