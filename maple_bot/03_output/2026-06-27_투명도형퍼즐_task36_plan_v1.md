# Task 36 계획

## 목표
- 프레임별 즉시 선택기가 아니라, 타겟 신분을 시간축에서 보류하고 복원하는 selector 본체를 구현한다.

## 범위
- 입력은 JSONL에 기록된 `track`, `cands`와 같은 기존 후보 데이터로 제한한다.
- GT는 selector 입력에 쓰지 않고 채점에만 사용한다.
- 마우스 자동화나 라이브 조작은 구현하지 않는다.
- 첫 구현은 오프라인 경로 선택기로 둔다.

## 설계
- 여러 후보 경로를 beam으로 유지한다.
- 각 경로는 마지막 위치, 속도, 누적 비용, frame별 선택점을 가진다.
- 일반 후보에서는 예측점과 후보 중심의 거리, 가속 변화, 후보 score를 비용으로 쌓는다.
- 큰 병합 후보 안에 예측점이 들어오면 후보 중심으로 갈아타지 않고 예측점을 `IDENTITY_HOLD` 상태로 유지한다.
- 이후 분리된 후보가 예측 경로 근처에 다시 나타나면 낮은 누적 비용으로 복원된다.

## 성공 기준
- 순수 함수 테스트가 먼저 실패하고, 구현 뒤 통과한다.
- 기존 경량 GT 채점기에 `temporal_identity` 지표가 추가된다.
- 16GT 전체 실행 시간이 1분 이내다.
- 전체 puzzle 테스트와 문법 검사가 통과한다.
