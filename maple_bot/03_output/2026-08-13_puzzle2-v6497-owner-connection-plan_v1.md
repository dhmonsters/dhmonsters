# Puzzle2 V6497 owner 연결 계획

## 목표

별도 owner 체크포인트가 없는 원본 V6497 v4의 실제 설계를 그대로 Puzzle2에 연결한다.

## 성공 기준

1. Puzzle2 개발 실행과 포터블 빌드가 새 V6497 v4 공급 폴더를 사용한다.
2. `V6494OwnerGuard`가 추적기의 비삼각형 경로에 실제 생성되고 `apply()` 호출 경로가 유지된다.
3. 빈 `deep_model`은 오류가 아니라 원본의 고전적 owner 추적 모드로 판정한다.
4. 삼각형 전용 `triangle_guard_v6496.pt`는 계속 패키징하고 추론 검사를 통과한다.
5. 원본에서 명시적으로 끈 `global_recovery_enabled=False`는 임의로 변경하지 않는다.
6. 관련 자동 테스트와 포터블 런타임 검사를 통과한다.

## 진행 순서

1. 실패 테스트로 새 공급 경로와 owner 연결 계약을 고정한다.
2. 공급 경로와 빌드 설정을 새 v4 폴더로 변경한다.
3. owner 연결 상태를 진단 보고서에 추가한다.
4. 단위 테스트와 실제 공급본 로드 검사를 실행한다.
5. 새 포터블 패키지를 생성하고 해시를 기록한다.
