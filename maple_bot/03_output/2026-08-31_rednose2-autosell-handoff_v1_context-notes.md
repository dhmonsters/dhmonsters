# 빨코2 자동판매 핸드오프 작업 기록

## 확인된 원인

- `can_start_auto_sell()`이 회수 단계뿐 아니라 정상 사냥의 `owns_movement=True`도 차단한다.
- 주기 자동판매는 1초마다 다시 확인하지만 정상 좌우 사냥이 이동 소유권을 반복 점유하여 계속 밀릴 수 있다.
- 기존 로그는 회수와 정상 이동을 같은 문구로 표시해 실제 원인을 구분할 수 없다.

## 확정 결정

- 회수 단계와 층 조건은 자동판매 요청 전에 검사한다.
- 정상 사냥 이동은 자동판매 플래그를 먼저 세워 중단시킨다.
- 이동 소유권 반환 대기 상한은 사용자 요청에 따라 0.1초로 한다.

## 구현 및 검증

- 자동판매 요청 가능 조건을 회수·층 조건과 이동 유휴 조건으로 분리했다.
- 정상 사냥 중에는 자동판매 플래그를 먼저 설정하고 최대 0.1초 동안 이동 반환을 확인한다.
- 반환 실패 시 자동판매 플래그를 해제하고 기존처럼 1초 후 재시도한다.
- 자동판매 및 빨코2 관련 테스트 82개가 통과했다.
- 수정 파일의 `py_compile`과 `git diff --check`가 통과했다.
