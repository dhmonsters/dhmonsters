# 투명도형 퍼즐 Task 1 컨텍스트 노트

- 이번 단계는 실제 추적 성능이 아니라 세션과 trace가 의존할 데이터 모델과 ROI 좌표 기준을 고정하는 작업이다.
- 모든 후보 좌표는 퍼즐 영역 내부 좌표로 기록한다.
- 탐지 ROI와 퍼즐 ROI는 이후 세션에서 별도 객체로 관리한다.
- 기존 투명도형 family 실험은 이번 단계에 넣지 않는다.
- `pytest`는 현재 PATH와 번들 Python에 없어서 직접 실행하지 못했다.
- RED 단계는 테스트 import 시 `core.puzzle` 패키지가 없어 실패하는 것으로 확인했다.
- GREEN 단계는 번들 Python으로 테스트 함수를 직접 호출해 확인했다.
- `compileall`은 `__pycache__` 쓰기 권한 때문에 실패했으나, AST 파싱으로 새 파일 문법을 확인했다.
