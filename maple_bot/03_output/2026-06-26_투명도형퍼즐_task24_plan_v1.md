# 투명도형퍼즐 Task 24 계획

## 목표
저장된 trace 상태를 기준으로 특정 frame을 다시 선택하면 CCTV, 후보, evidence, identity 요약이 함께 이동하게 한다.

## 설계
`PuzzleConsoleWindow.select_timeline_frame(frame_index)` 메서드를 추가한다. frame index에 저장된 source, candidates, evidence, identity가 하나라도 있으면 현재 선택 frame으로 보고, 관련 CCTV 라벨과 우측 상태 metric을 저장된 값으로 다시 적용한다.

아직 실제 timeline 클릭 이벤트는 연결하지 않는다. 다음 단계에서 클릭 가능한 timeline UI를 붙일 때 이 메서드를 호출하게 한다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- 저장된 frame을 선택하면 `selected_frame_index`가 갱신된다.
- CCTV 상태, 후보 요약, evidence 요약, identity 요약이 선택 frame 기준으로 바뀐다.
- 저장된 frame이 없으면 `False`를 반환하고 기존 선택 frame은 바꾸지 않는다.
