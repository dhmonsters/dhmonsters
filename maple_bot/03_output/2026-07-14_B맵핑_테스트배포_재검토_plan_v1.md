# B 맵핑 테스트 배포 재검토 계획

## 목표

현재까지 구현된 B 방식 전역 지도 맵핑 기능을 다른 PC에서 시험할 수 있는 압축본으로 보존하고, 관련 기능을 다시 테스트·검토한 뒤 기록을 커밋한다.

## 진행 순서

1. 현재 커밋 기준의 휴대용 소스 압축본을 생성한다.
2. 압축본에 핵심 실행 및 전역 지도 파일이 포함됐는지 확인한다.
3. 전역 지도, 좌표 추적, 이동, 사냥 영역 이미지 트리거, 통합 UI 관련 회귀 테스트를 실행한다.
4. 실제 사용자 화면에서 설정 가능한 기능과 내부 API만 존재하는 기능을 구분해 검토한다.
5. 발견 사항과 테스트 결과를 기록하고 이번 산출물만 의미 단위로 커밋한다.

## 성공 기준

- 압축본이 `03_output`에 생성된다.
- 관련 자동화 테스트 결과를 확인한다.
- 검토에서 발견된 미완성 또는 위험 요소를 숨기지 않고 기록한다.
- 기존 사용자 변경을 포함하거나 되돌리지 않는다.
