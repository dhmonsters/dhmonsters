# 빨코2 회수 루틴 단축 및 Y 좌표 UI 작업 기록

- 사용자가 승인한 설계는 24번 발판 확인 0.45초·3회·X ±2·Y ±1, 1층 하강 3회·Y ±1이다.
- 7번 사다리 중간 위치는 `2층 최대 Y < 현재 Y < 1층 최소 Y`로 판정하고 위 텔레포트 후 오른쪽 텔레포트를 실행한다.
- 사다리 X 확인은 현재 좌표와 새 캡처 좌표를 각각 검사하는 기존 안전 확인을 유지한다.
- 14/15번은 3회 시도하고 실패 시 0.6초 공격 후 위 텔레포트를 재시도한다. 단계 상태를 보존한다.
- 16번은 X 재정렬 없이 0.5초의 95~100% 공격 후 위 텔레포트하며 0.55초 확인을 최대 3회 수행한다.
- 16번 실패 우회는 위 텔레포트 1회와 왼쪽 텔레포트 1회만 수행한다.
- 27번은 3회 시도하고 진입 후 0.5초의 95~100% 공격을 수행한다. 마무리 공격도 같은 시간이며 아래 텔레포트는 최대 5회다.
- 회수 완료 후 첫 일반 사냥 방향은 좌우 무작위로 선택한다.
- UI에는 1·2·3층 범위, 24번, 7번, 14/15번, 16번, 27번 Y 값을 추가한다.
- 앞선 미커밋 변경인 발판 14/15 범위 완료와 2층 좌우·회수 우측 끝 근거리 텔레포트 허용도 함께 검증하고 커밋한다.
- 수정 전 선택 테스트는 14건이 예상한 동작 차이로 실패했고 기존 경계값 2건만 통과했다.
- 구현 후 신규 선택 테스트 16건과 빨코2 관련 전체 테스트 62건이 통과했다.
- 변경한 실행·설정·UI·테스트 파일의 `py_compile` 구문 검사가 통과했다.
- 프로젝트 전체 `pytest -q`는 이번 변경과 무관하게 삭제·분리된 퍼즐 및 실험 모듈과 기존 `RiskProfile` 불일치로 테스트 수집 단계에서 30건 중단됐다. 누락 모듈은 `_final_selector_score`, `_background_identity_signal`, `_local_box_selector_score`, `_box_grid_viterbi_score`, `core.puzzle.retention` 등이며 이번 변경 파일 목록에는 포함되지 않는다.
