# 빨코2 미검출·자동판매·미니맵 정렬 작업 기록

## 진단 결과

- 캐릭터 위치 표본이 0.15초보다 오래되면 빨코2 러너는 위치를 `None`으로 받는다.
- 텔포 함수는 실행 직후 방향키를 해제하므로 텔포 직후 미검출되면 다음 이동 의도를 실행하지 못하고 대기한다.
- 자동판매 진입은 2층 X 범위만 확인한 뒤 위 텔포 결과를 확인하지 않고 0.25초 후 성공 처리한다.
- 자동판매 복귀 아랫텔포의 기본 아래키 선행 유지시간은 0.15초다.
- 빨코2 프리셋의 미니맵 원본값 `38, 128, 172×103`과 저장된 비율값이 서로 일치하지 않는다.
- 빨코2 프리셋에는 캐릭터 위치 X/Y 보정값이 없으므로 기본값 0이 적용된다.
- 미니맵 영역 선택기는 현재 루트 설정만 저장하고 활성 프리셋과 실행 중 런타임 영역을 즉시 갱신하지 않는다.

## 결정 사항

- 미검출 복구는 빨코2 전용 러너 안에서 최대 0.8초로 제한한다.
- 자동판매는 좌표 기반 안전지대 도착 확인 없이는 판매 단계로 넘어가지 않는다.
- 복귀 아랫텔포에만 0.30초 선행 유지시간을 적용해 다른 텔포 타이밍을 바꾸지 않는다.
- 미니맵 영역과 비율은 현재 활성 프리셋에 함께 동기화한다.
- 캐릭터 표시 보정 및 빨코2 이동 좌표는 수정 범위에서 제외한다.

## 구현 결과

- 빨코2 이동 중 위치가 잠시 사라지면 최대 0.8초 동안 마지막 좌우 방향을 유지한다.
- 좌우 텔포 뒤 다음 이동 단계가 미검출로 시작해도 이전 좌우 이동 의도를 이어간다.
- 자동판매 진입은 3층 안전지대 좌표가 확인될 때만 성공하며 최대 3회 재시도한다.
- 판매 후 복귀는 아래키를 0.30초 먼저 누른 뒤 텔포하고 2층 도착을 최대 3회 확인한다.
- 새 미니맵 영역의 원본 좌표와 비율을 활성 사냥터 프리셋에도 함께 저장한다.
- 영역 지정 직후 실행 중 캐릭터 스캐너와 빨코2 러너가 새 영역을 사용한다.
- 캐릭터 표시 X/Y 보정값과 빨코2 이동 좌표는 변경하지 않았다.

## 검증 결과

- 관련 회귀 테스트 67개 통과.
- 변경 파일 문법 검사 통과.
- 코드 공백 오류 검사 통과.
- 프로젝트 루트 전체 테스트는 `03_output`의 과거 백업까지 수집해 모듈 충돌 19건으로 중단됐다.
- 현재 `tests` 폴더 전체 테스트는 이번 변경과 무관한 `RiskProfile` 제거 후 남은 기존 테스트 2개의 가져오기 오류로 수집이 중단됐다.
- 위 기존 오류와 관련된 소스 및 테스트는 요청 범위 밖이므로 수정하지 않았다.
