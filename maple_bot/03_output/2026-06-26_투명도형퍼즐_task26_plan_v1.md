# Task 26 계획

## 목표
- timeline 패널에 현재 저장된 frame 목록을 표시한다.
- 사용자가 이전과 다음 버튼을 누르기 전에 이동 가능한 frame 범위를 알 수 있게 한다.
- 선택된 frame이 있으면 frame 목록 옆에 selected 값을 함께 표시한다.

## 범위
- `PuzzleConsoleWindow`에 `puzzleTimelineFrames` 라벨을 추가한다.
- frame source, candidates, evidence, identity가 저장될 때 frame 요약을 갱신한다.
- `select_timeline_frame` 성공 시 선택 frame 표시를 갱신한다.

## 검증
- timeline frame summary 라벨의 objectName을 확인한다.
- trace event 반영 후 저장된 frame 목록이 표시되는지 확인한다.
- frame 선택 후 selected 표시가 갱신되는지 확인한다.
