# 투명도형퍼즐 Task 23 계획

## 목표
CCTV preview와 같은 프레임의 evidence 판단 근거를 UI에 함께 표시한다.

## 설계
중앙 CCTV 영역에 `puzzleCctvEvidenceSummary` 라벨을 추가한다. `EVIDENCE` trace 이벤트를 받으면 frame index별 evidence 목록을 `current_frame_evidence`에 저장하고, CCTV evidence 요약 라벨에 frame, evidence 수, 첫 evidence의 candidate와 주요 점수를 표시한다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- evidence 요약 라벨 objectName은 `puzzleCctvEvidenceSummary`이다.
- `EVIDENCE` 이벤트가 frame index별 evidence 목록을 저장한다.
- evidence 요약 라벨은 frame 번호, evidence 수, candidate_id, bg, motion, merge 점수를 표시한다.
