# Task 31 계획

## 목표
- 솔버 중지와 녹화 종료를 분리해, 솔버가 실패해서 멈춰도 사용자가 직접 푸는 구간까지 녹화가 계속 남도록 한다.

## 범위
- 녹화 산출물 기본 포맷을 무손실 우선인 `FFV1 + MKV`로 바꾼다.
- `RecordingController`를 추가해 `stop_solver`와 `stop_recording`을 분리한다.
- UI에 `녹화 종료 F3` 버튼과 F3 입력 진입점을 추가한다.
- 기존 replay/headless 테스트 흐름은 유지한다.

## 제외
- 프로그램 전체가 강제 종료된 뒤에도 녹화가 계속되는 별도 프로세스 구조는 만들지 않는다.
- 실제 라이브 화면 캡처 연결과 마우스 자동 조작은 이번 범위에 넣지 않는다.

## 검증
- 솔버 중지 후에도 recorder write가 계속 가능한지 테스트한다.
- 녹화 종료 후에는 recorder close가 한 번만 호출되는지 테스트한다.
- 세션 영상 경로가 `.mkv`로 생성되는지 테스트한다.
- `SessionRecorder` 기본 fourcc가 `FFV1`인지 테스트한다.
- UI의 녹화 종료 버튼과 F3 경로가 handler를 호출하는지 테스트한다.
- 전체 puzzle 테스트와 실제 transparent-test 실행을 다시 확인한다.
