# Claude v2.4.8 배포 계획

## 목표

빨코2 회수 단계 복구, 정상 사냥 중 자동판매 진입, 미검출 지속 복구와 포탈 이탈 방지 수정사항을 Claude v2.4.8 설치파일로 배포한다.

## 순서

1. 현재 소스 전체 테스트를 실행한다.
2. `version.txt`, `version.json`, `installer.iss`, `build.bat`의 버전을 2.4.8로 맞춘다.
3. 버전 변경을 커밋하고 원격 저장소에 푸시한다.
4. `build.bat`과 Inno Setup으로 프로그램 및 설치파일을 생성한다.
5. 설치파일 이름, 내부 버전, 실행 여부, SHA-256을 검증한다.
6. 검증된 설치파일을 `03_output/Claude_v2.4.8_Setup.exe`로 보관한다.
7. GitHub Release v2.4.8을 게시하고 자동 업데이트 메타데이터를 확인한다.
