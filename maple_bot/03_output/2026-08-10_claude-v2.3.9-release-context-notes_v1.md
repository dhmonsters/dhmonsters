# Claude v2.3.9 릴리스 작업 기록

## 확정 사항

- 제품명은 Claude이다.
- 실행 진입점은 run_integrated.py이며 활성 UI는 core_ui이다.
- v2.3.9에는 캐릭터 노란 마커 면적 상한 보정, 중심 좌표 반올림, 오래된 좌표 재사용 방지 변경을 포함한다.
- 구형 UI와 제거된 Humanizer 경로는 다시 연결하지 않는다.
- 로컬 config.json의 개인 값은 배포에 포함하지 않고 정제된 설정만 사용한다.
- 현재 작업 트리의 다른 변경은 릴리스에 섞지 않는다.
- 코드 서명 인증서는 없으므로 이번 설치 파일도 서명되지 않는다.
