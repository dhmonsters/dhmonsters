# Task 34 계획

## 목표
- 듀얼 모니터 환경에서 라이브 캡처가 전체 가상 데스크톱이 아니라 메인 모니터 기준으로 동작하게 한다.
- 캡처 사전점검 PNG는 전체 화면이 아니라 고정 board ROI 영역만 저장하게 한다.

## 범위
- `mss` 캡처에서 `monitors[0]` 전체 가상 화면 대신 메인 모니터 후보를 선택한다.
- `PIL.ImageGrab` fallback은 전체 화면 옵션을 쓰지 않고 주 화면만 요청한다.
- `capture_check.png`는 `fixed_puzzle_rois`의 board ROI crop을 저장한다.
- 사전점검 리포트에는 원본 프레임 크기와 저장 이미지 크기를 함께 남긴다.

## 제외
- 자동 입력, 추적 솔버, 마우스 이동은 건드리지 않는다.
- 라이브 녹화의 `raw_cctv.mkv`는 메인 모니터 원본으로 유지하고, ROI 영상은 기존 `board_crop.mkv` 경로를 사용한다.

## 검증
- 메인 모니터 선택 단위 테스트를 추가한다.
- 사전점검 PNG가 board ROI 크기로 저장되는지 테스트한다.
- 전체 puzzle 테스트와 문법 검사를 통과시킨다.
