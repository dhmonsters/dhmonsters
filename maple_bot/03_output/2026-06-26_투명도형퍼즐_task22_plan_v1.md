# 투명도형퍼즐 Task 22 계획

## 목표
CCTV preview와 같은 프레임의 정체성 판단 상태를 UI에 함께 표시한다.

## 설계
중앙 CCTV 영역에 `puzzleCctvIdentitySummary` 라벨을 추가한다. `IDENTITY_STATE` trace 이벤트를 받으면 frame index별 identity payload를 `current_frame_identity`에 저장하고, CCTV identity 요약 라벨에 frame, state, confidence, candidate 또는 point를 표시한다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- identity 요약 라벨 objectName은 `puzzleCctvIdentitySummary`이다.
- `IDENTITY_STATE` 이벤트가 frame index별 identity payload를 저장한다.
- identity 요약 라벨은 frame 번호, state, confidence, candidate_id, point를 표시한다.
