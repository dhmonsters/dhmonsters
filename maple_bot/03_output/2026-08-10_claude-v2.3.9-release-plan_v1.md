# Claude v2.3.9 릴리스 계획

## 목표

캐릭터 중심 좌표 판독과 오래된 좌표 재사용 문제를 수정한 변경만 안전하게 묶어 Claude v2.3.9 EXE와 설치 파일을 만들고 GitHub Release에 배포한다.

## 실행 순서

1. v2.3.8 기준 변경 범위와 개인 설정 제외 여부를 검토한다.
2. 모든 버전 파일을 v2.3.9로 일치시킨다.
3. 관련 테스트, 문법 검사, 첨부 이미지 중심 좌표 재현 검사를 실행한다.
4. origin/main 기반의 독립 릴리스 커밋과 브랜치를 만들고 원격에 올린다.
5. 깨끗한 소스 묶음에서 EXE를 빌드하고 필수 파일과 설정을 검증한다.
6. Inno Setup 설치 파일을 만들고 설치 파일을 검증한다.
7. main 병합 후 GitHub Release v2.3.9를 생성한다.
8. 로컬 파일과 GitHub 자산의 크기와 SHA-256을 대조한다.

## 완료 기준

- version.txt, version.json, installer.iss, build.bat의 버전이 모두 2.3.9이다.
- 배포 설정에 텔레그램 정보, 라이선스 정보, 절대 경로가 없다.
- 관련 테스트와 문법 검사가 통과한다.
- EXE와 설치 파일에 필수 실행 파일, 모델, 맵, Interception 구성요소가 포함된다.
- GitHub main과 Release v2.3.9가 같은 설치 파일을 가리킨다.
- 로컬 설치 파일의 SHA-256이 GitHub 자산 digest와 일치한다.
