# 2026-06-29 게임창 기준 CCTV ROI 수정 계획

## 목표

`puzzle.py` 라이브 경로의 CCTV와 퍼즐 감지가 메인 모니터 전체가 아니라 메이플/월드 게임창 클라이언트 영역을 기준으로 동작하게 한다.

## 성공 기준

- 기본 라이브 캡처가 게임 클라이언트 영역만 반환한다.
- ROI 비율이 `planet_solver_noauth.py`의 보정된 HDR, DET, BOARD 비율과 일치한다.
- 게임창을 찾지 못하면 전체 화면으로 조용히 fallback하지 않는다.
- 기존 GT 16/16 경로가 유지된다.
