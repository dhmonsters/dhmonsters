# 빨코2 미검출 지속 복구 작업 기록

## 확인된 원인

- 수평 이동은 미검출 0.8초 후 방향키를 해제하지만 `pos is None` 분기에서는 이동 제한시간도 검사하지 않아 멈춘 채 계속 대기한다.
- 정상 2층 좌우 사냥에는 위 텔레포트가 없다.
- 미검출 후 7번 사다리 복구로 전환되면 중간 Y 범위만 확인하고 X를 확인하지 않는 빠른 복귀 경로가 있다.
- 이 경로에서 포탈 끝의 잘못된 중간 Y 검출이 7번 사다리로 오인되면 위 텔레포트가 실행될 수 있다.

## 확정 결정

- 일반 미검출은 기존 방향 0.8초 후 반대 방향으로 계속 움직인다.
- 포탈 끝 미검출은 맵 중앙 방향으로 위치가 잡힐 때까지 움직인다.
- 재검출 후 기존 목표와 회수 단계를 유지한다.
- 7번 사다리 중간 복귀는 X와 Y를 같은 좌표에서 함께 확인한다.

## 구현 결과

- 미검출 0.8초 이후 방향키 해제 분기를 반대 방향 유지로 변경했다.
- 마지막 X가 좌우 포탈 범위이면 경과시간과 무관하게 중앙 방향을 유지한다.
- 포탈 미검출 상태를 별도로 기록하여 좌표가 없는 동안 수직 텔레포트를 차단한다.
- 7번 사다리 중간 복귀의 빠른 경로에 X 범위 검사를 추가했다.
- 위치가 다시 검출되면 기존 이동 루프가 동일 목표와 회수 단계를 계속한다.
- 자동판매와 빨코2 관련 테스트 88개가 통과했다.
- 수정 파일의 `py_compile`과 `git diff --check`가 통과했다.
