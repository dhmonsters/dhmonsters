# 투명도형퍼즐 Task 20 계획

## 목표
`FRAME_REPLAYED` trace가 가리키는 이미지 프레임을 UI의 CCTV preview 슬롯에 로드한다.

## 설계
중앙 CCTV 영역에 `puzzleCctvFramePreview` 라벨을 추가한다. `FRAME_REPLAYED` 이벤트가 기존 이미지 파일 경로를 포함하면 `QPixmap`으로 읽어 preview 라벨에 설정하고, 현재 로드된 프레임 경로를 `current_cctv_source_path`에 저장한다.

영상 입력처럼 실제 이미지 파일이 아닌 출처는 이번 단계에서 렌더링하지 않고 상태 라벨만 유지한다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- CCTV preview 라벨 objectName은 `puzzleCctvFramePreview`이다.
- `FRAME_REPLAYED` 이벤트의 `source_frame_path`가 존재하는 이미지 파일이면 preview 라벨이 pixmap을 받는다.
- 현재 로드된 CCTV source path가 `current_cctv_source_path`에 저장된다.
