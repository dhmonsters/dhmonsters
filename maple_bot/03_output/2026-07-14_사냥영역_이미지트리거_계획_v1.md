# 사냥 영역 이미지 트리거 구현 계획

## 목적

캐릭터를 기준으로 이동하는 사냥 영역을 이미지 검색 범위로 사용하고, 등록한 템플릿이 검출되면 지정 액션을 실행한다.

## 확정 구조

- 사냥 영역은 활성화 조건이 아니라 매 프레임 이동하는 검색 ROI다.
- 캐릭터가 영역 안에 있는지는 검사하지 않는다.
- 템플릿 이미지 경로, 유사도 임계값, 감지 주기, 재실행 대기시간, 액션을 설정한다.
- 템플릿 매칭은 사냥 영역으로 잘라낸 게임 화면에서만 수행한다.
- 검출된 좌표와 유사도를 결과로 제공한다.
- 같은 이미지가 계속 보일 때는 쿨다운으로 중복 액션을 제한한다.
- 액션은 Task 3의 `ActionExecutor`를 재사용한다.

## 구현 순서

1. Task 3의 전역 그래프, 경로 실행기, 노드별 도착 허용 반경을 구현한다.
2. 이미지 트리거 설정과 검출 결과 모델을 추가한다.
3. ROI 템플릿 매칭과 쿨다운 실행기를 구현한다.
4. 기존 사냥 영역 좌표 공급자와 연결 가능한 공개 인터페이스를 만든다.
5. 단위 및 회귀 테스트를 실행한다.
6. 전역 경로와 이미지 트리거를 별도 의미 단위로 커밋한다.

## 성공 조건

- 등록된 이동 간선 밖으로 경로를 만들지 않는다.
- 순환 경로와 단일 목적지 이동이 모두 가능하다.
- 액션 노드에서만 등록 액션을 실행한다.
- 검색은 전체 화면이 아니라 사냥 영역 ROI에서만 수행한다.
- 임계값 미만이거나 쿨다운 중이면 액션을 실행하지 않는다.
- 임계값 이상이며 쿨다운이 끝났으면 액션을 한 번 실행한다.

## 범위 제외

- 실제 템플릿 이미지 제작.
- 객체 탐지 AI 모델 학습.
- Task 6 이전의 최종 UI 편집 화면.
