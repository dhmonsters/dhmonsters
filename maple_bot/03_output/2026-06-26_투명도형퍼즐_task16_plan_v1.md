# 투명도형퍼즐 Task 16 계획

## 목표
UI 분석 패널이 replay trace 이벤트를 받아 후보 수와 identity 상태를 즉시 표시하게 만든다.

## 범위
- `PuzzleConsoleWindow.apply_trace_event(event)` 메서드를 추가한다.
- `CANDIDATES` 이벤트는 후보 수 metric을 갱신한다.
- `IDENTITY_STATE` 이벤트는 상태, confidence, hold, reason, timeline frame을 갱신한다.
- `SESSION_START` 이벤트는 session id 표시를 갱신한다.
- 자동 입력, 실시간 화면 감시, 실제 후보 검출 연결은 이번 범위에 넣지 않는다.

- 새 테스트는 구현 전 실패해야 한다.
- 구현 후 UI smoke 테스트와 전체 puzzle 테스트가 통과해야 한다.
