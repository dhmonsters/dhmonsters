# 2026-06-27_puzzle_console_live_ui_simplify_plan_v1

## 목표

투명도형 퍼즐 콘솔을 실전 라이브 테스트용 화면으로 단순화한다.

## 변경 방향

- 왼쪽 입력 버튼 묶음, 분석 패널, 타임라인 패널을 화면에서 제거한다.
- 화면에는 CCTV, 제어 버튼, 로그, 텔레그램 알림, GPU 사용, 퍼즐 감지 알람 체크박스만 보이게 한다.
- F1, F2, F3 상태를 상단 배지로 보여준다.
- F1 solver on은 초록색, F2 solver stop은 주황색, F3 recording stop은 빨간색으로 표시한다.
- CCTV preview가 파일명 텍스트로 덮이는 문제를 수정한다.

## 성공 기준

- F1을 누르면 동작 중임을 상태와 색상으로 확인할 수 있다.
- solver armed 상태에서도 CCTV preview가 이미지로 보인다.
- F2는 solver만 멈춘다.
- F3은 녹화 종료 상태를 빨간색으로 표시한다.
- 사용자가 요청하지 않은 replay 입력 버튼들은 화면에 보이지 않는다.
