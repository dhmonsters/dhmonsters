# ShapeYolo 로더 수정 계획

목표는 현재 `puzzle.py` 라이브 경로에서 투명 도형이 사라진 뒤 후보가 0개로 붕괴하는 원인을 줄이는 것이다.

1. `PlanetNoAuthDetector`의 `ShapeYolo` 로딩 실패 재현 테스트를 추가한다.
2. `ShapeYolo`가 실패했을 때도 이후 모델 로딩 경로를 준비하고 재시도할 수 있게 수정한다.
3. 관련 단위 테스트를 돌려 회귀를 확인한다.
4. 최근 세션 `20260630_141458_001`을 현재 코드로 다시 재생해 후보 유지 여부를 확인한다.

성공 기준은 fade 이후에도 후보 공급 경로가 살아 있고, 로그에서 `raw_count`가 0으로만 유지되지 않는 것이다.
