# 전역 키 홀드 정책과 빨코2 설정 작업 메모

- 사용자는 텔포 공격의 현재 체감 속도를 유지하면서 간격 의미를 완료 후 대기로 바꾸길 원한다.
- 실제 키 홀드만 설정값의 `95~100%`를 소수점 넷째 자리까지 한 번 적용한다.
- 간격, 쿨다운, 텔포 전 대기와 좌표 폴링에는 랜덤을 적용하지 않는다.
- 적용 범위는 빨코2뿐 아니라 버프, 물약, 픽업, 마을귀환을 포함한 모든 시간 기반 키 입력이다.
- Interception의 `0.02초` 강제 하한은 과거 Windows 입력 경로의 방어값을 계승했으나 실측 근거가 없어 제거한다.
- 기존 상위 호출부 랜덤과 물리 입력 경계 랜덤이 겹치지 않도록 단일 적용 지점을 정리해야 한다.
- 방향키처럼 좌표 조건까지 유지하는 상태 기반 입력은 고정 홀드 시간이 없어 랜덤 대상이 아니다.
- 빨코2 일반 사냥 간격은 완료 후 `0.72초`, 7번 이후 우측 끝 이동은 완료 후 `0.90초`를 초기 호환값으로 사용한다.
- 기존 `0.40초`, `1.80초`는 시작 시점 기준 값이므로 타이밍 버전 없이 새 의미로 재사용하지 않는다.
- EXE 빌드, 설치본 생성, 푸시와 배포는 제외한다.
- 구현은 물리 입력 경계, 상위 이중 랜덤 제거, 빨코2 설정 마이그레이션, 접이식 UI, 완료 후 간격 순서로 나눈다.
- 현재 작업 폴더는 연결된 격리 worktree이므로 추가 worktree를 만들지 않는다.
- 물리 입력 경계의 키 홀드에만 `down_5`를 적용하고, 상위 공격·버프·픽업·물약·귀환 호출부는 원래 설정값을 전달하도록 정리했다.
- 직접 `key_down`/`key_up`을 사용하는 키헌터, 동선 액션, 빨코2 27번 발판 공격도 동일하게 한 번만 랜덤을 적용한다.
- 빨코2 좌표 설정과 공격 설정은 서로 독립적으로 접고 펼치며, 빨코2가 선택된 경우에만 표시한다.
- 빨코2 텔포 공격 간격은 동작이 완전히 끝난 시점부터 계산하며, 일반 사냥 `0.72초`, 7번 이후 우측 이동 `0.90초`를 기본값으로 사용한다.
- 관련 테스트는 `57 passed, 9 warnings`이며 경고는 기존 `mss.mss` 사용에 따른 deprecation 경고다.
- 전체 테스트 수집은 기존 테스트가 제거된 `RiskProfile`을 import하는 문제로 중단됐다. 이번 변경 파일과 무관한 기존 테스트 정합성 문제로 기록한다.
- `compileall`은 성공했고 변경된 28개 파일은 strict UTF-8 디코딩과 `git diff --check`를 통과했다.
- 기존 미추적 설치본, 진단 폴더와 로그는 수정하거나 커밋하지 않았다.
- EXE 빌드, 설치본 생성, 푸시와 배포는 수행하지 않았다.
