# 전역 키 홀드 정책과 빨코2 설정 작업 메모

- 사용자는 텔포 공격의 현재 체감 속도를 유지하면서 간격 의미를 완료 후 대기로 바꾸길 원한다.
- 실제 키 홀드만 설정값의 `95~100%`를 소수점 넷째 자리까지 한 번 적용한다.
- 간격, 쿨다운, 텔포 전 대기와 좌표 폴링에는 랜덤을 적용하지 않는다.
- 적용 범위는 빨코2뿐 아니라 버프, 물약, 픽업, 마을귀환을 포함한 모든 시간 기반 키 입력이다.
- Interception의 `0.02초` 강제 하한은 과거 Windows 입력 경로의 방어값을 계승했으나 실측 근거가 없어 제거한다.
- 기존 상위 호출부 랜덤과 물리 입력 경계 랜덤이 겹치지 않도록 단일 적용 지점을 정리해야 한다.
- 방향키처럼 좌표 조건까지 유지하는 상태 기반 입력은 고정 홀드 시간이 없어 랜덤 대상이 아니다.
- 빨코2 일반 사냥 간격은 완료 후 `0.72초`, 7번 이후 우측 끝 이동은 완료 후 `0.90초`를 초기 호환값으로 사용한다.
- 기존 `0.40초`, `1.80초`는 시작 시점 기준 값이므로 타이밍 버전 없이 새 의미로 재사용하지 않는다.
- EXE 빌드, 설치본 생성, 푸시와 배포는 제외한다.
