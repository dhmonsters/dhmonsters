# maple_bot 로컬 v2.3.11 동기화 인수인계 기록

## 확인된 원인

- 기본 폴더의 버전은 2.3.9였다.
- Claude v2.3.11 수정과 배포는 `maple_bot_main_release/maple_bot`에서 수행됐다.
- 기본 작업 공간은 `codex/shorts-growth-agent-mvp` 브랜치여서 배포 작업 폴더의 최신 변경이 자동 반영되지 않았다.

## 결정

- 전체 폴더를 덮어쓰지 않는다.
- 릴리스 기준 `v2.3.9..HEAD`에서 변경된 프로그램 파일만 동기화한다.
- `03_output` 안의 과거 산출물은 동기화 대상에서 제외한다.
- 사용자 설정과 런타임 데이터는 보존한다.
