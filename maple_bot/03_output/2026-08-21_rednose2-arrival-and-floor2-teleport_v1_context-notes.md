# 빨코2 도착 판정 및 2층 텔레포트 작업 기록

- 발판 14/15의 기존 이동 호출은 목표 X=95에 `arrival_tolerance=2.0`을 사용해 X=97도 이동 완료로 반환했다.
- 발판 14/15의 실제 허용범위는 `platform1415_x_min`과 `platform1415_x_max`이며 기본값은 94~96이다.
- 고정 오차로 대체하지 않고 실제 허용범위를 공통 이동 함수의 도착 조건으로 전달한다.
- 2층 좌우 끝 이동에는 별도 `teleport_stop_range`가 없지만 공통 `teleport_stop_px` 때문에 목표 한 칸 이내에서 텔레포트가 금지된다.
- 2층 좌우 끝 이동에만 근거리 텔레포트 제한을 0으로 재정의한다. 사다리와 다른 회수 단계의 제한은 유지한다.
- 사용자의 요청에 따라 전체 회귀 테스트와 커밋은 후속 수정 이후 진행한다. 단, TDD를 위한 최소 재현 테스트는 코드 수정 전에 실행한다.
- 재현 테스트 네 건이 수정 전 예상대로 실패했다. 발판 14/15는 범위 인자가 없어 실패했고 2층 좌·우·회수 우측 끝은 근거리 텔레포트가 차단되어 실패했다.
- 공통 이동 함수에 선택적인 `arrival_range`와 `teleport_stop_distance`를 추가했다.
- 발판 14/15는 설정된 허용범위를 `arrival_range`로 전달한다. 범위가 전달된 이동에서는 기존 오차나 목표 통과만으로 완료하지 않는다.
- 2층 일반 사냥 좌우 끝과 회수 루틴의 우측 끝 이동만 `teleport_stop_distance=0.0`을 전달한다.
- 최소 재현 테스트 결과는 4건 통과다. 관련 전체 테스트와 커밋은 후속 수정 이후로 보류했다.
- 후속 회수 루틴 변경과 함께 빨코2 관련 전체 테스트 62건 및 변경 파일 구문 검사를 통과했다.
