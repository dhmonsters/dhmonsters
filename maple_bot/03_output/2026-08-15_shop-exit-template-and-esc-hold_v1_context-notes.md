# 상점 나가기 템플릿 및 ESC 홀드 변경 기록

- 사용자가 상점 나가기 고정 좌표를 기존 `templates/junk/shop_exit.png` 기반 탐지로 바꾸도록 승인했다.
- 템플릿을 찾으면 게임 창 기준 중심 좌표를 한 번 클릭하고 기존 대기 0.12초를 유지한다.
- 템플릿을 찾지 못하면 기존 ESC 폴백 순서를 유지하되 두 입력 모두 `hold_sec=0.5`를 명시한다.
- 미니맵 및 다른 자동판매 단계는 수정 범위에서 제외한다.
- 기존 코드에서는 새 테스트 2개가 `_exit_shop()` 인자 구조 차이로 실패했고, 구현 후 모두 통과했다.
- 기존 고정 좌표 클릭을 기대하던 회귀 테스트는 새 ESC 폴백 동작을 검증하도록 갱신했다.
- 최종 검증 결과 문법 검사 성공, 자동판매 관련 테스트 12개 통과를 확인했다.
