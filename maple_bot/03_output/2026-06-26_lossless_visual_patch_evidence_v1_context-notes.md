# 무손실 visual patch evidence 기록

이번 단계의 핵심 가정은 타겟이 너무 투명해도 후보 중심 주변의 주기차분 잔차에는 약한 흔적이 남을 수 있다는 것이다.

이 신호는 단독 selector로 쓰지 않는다. 위치 연속성 beam이 이미 들고 있는 여러 가설 사이에서 동점 또는 근소 차이를 깨는 보조 점수로만 사용한다.

165634에서는 f43, f44 부근에서 타겟 후보의 잔차가 강하게 보였지만, 모든 프레임에서 안정적이지는 않았다. 그래서 프레임 하나만 보고 선택하지 않고, beam 누적 점수로 천천히 반영한다.

처음 visual rescue를 기본 설정으로 넣었을 때 165634는 평균 53.6px로 실패했다. f83 이후 다른 가지가 최종 선택되면서 f89~f92가 크게 틀어졌다.

track 보너스를 낮추고 visual 보너스를 조건부로 쓰는 설정에서 165634는 평균 23.1px로 통과했다. 하지만 같은 visual rescue를 180636에 강제로 쓰면 평균 46.2px로 실패했다.

따라서 visual rescue는 전체 판에 항상 적용하면 안 된다. 기존 track이 화면 밖으로 나가는 등 건강하지 않을 때만 선택하는 selector가 필요하다.

track 건강도 selector를 추가하니 165634는 visual rescue를 고르고, 180636은 track을 유지했다. 무손실 2판 최종 selected 기준은 2/2 통과다.
