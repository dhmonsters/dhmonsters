# 2점 보정 창 종료 수정 계획

## 목표

`2점 보정 적용`을 눌렀을 때 보정점 부족 또는 잘못된 보정점으로 예외가 발생해 창이 종료되는 문제를 막는다.

## 원인

버튼 클릭이 `apply_calibration()`에 직접 연결되어 있고, 이 함수는 `ValueError`를 호출자에게 그대로 전달한다. Qt 버튼 슬롯에서 예외가 처리되지 않으면 앱 창이 종료될 수 있다.

## 진행 순서

1. UI 버튼용 안전 래퍼 테스트를 먼저 추가한다.
2. 실패하는 테스트로 현재 문제를 재현한다.
3. 버튼 클릭 연결을 안전 래퍼로 바꾼다.
4. 래퍼에서 실패 시 경고창과 상태 문구를 표시하고 창은 유지한다.
5. 관련 테스트를 실행하고 결과를 기록한다.
