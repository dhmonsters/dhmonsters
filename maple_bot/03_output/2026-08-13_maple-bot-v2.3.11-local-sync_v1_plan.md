# maple_bot 로컬 v2.3.11 동기화 계획

## 목표

기본 `maple_bot` 폴더에서 `run_integrated.py`를 직접 실행해도 배포본과 동일한 Claude v2.3.11 코드가 실행되게 한다.

## 범위

- 배포 작업 폴더의 `v2.3.9..v2.3.11` 변경 파일만 반영한다.
- `config.json`, 템플릿, 지도, 로그, 라이선스 및 기타 사용자 데이터는 유지한다.
- 교체 전 기존 파일을 `03_output`의 백업 폴더에 보존한다.
- 기존 파일이나 폴더를 삭제하지 않는다.

## 검증

1. 기본 폴더의 `version.txt`와 `version.json`이 2.3.11인지 확인한다.
2. 배포 변경 파일이 배포 작업 폴더와 일치하는지 확인한다.
3. 관련 테스트와 Python 컴파일 검사를 실행한다.
4. 업데이트 검사에서 로컬 버전이 2.3.11로 판독되는지 확인한다.
