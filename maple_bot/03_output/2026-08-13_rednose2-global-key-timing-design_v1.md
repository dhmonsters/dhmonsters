# 전역 키 홀드 정책과 빨코2 접이식 설정 설계

## 목적

- 프로그램이 실제로 누르는 모든 키의 홀드 시간에 설정값 대비 `95~100%` 랜덤을 정확히 한 번만 적용한다.
- 랜덤 결과는 소수점 넷째 자리까지 사용한다.
- 키 입력 간격, 쿨다운, 텔포 전 대기, 좌표 확인 주기에는 랜덤을 적용하지 않는다.
- 빨코2 좌표와 공격 관련 값을 UI에서 안전하게 조절한다.
- 텔포 공격 간격의 기준을 동작 시작 시점에서 동작 완료 시점으로 바꾸되 현재 체감 속도를 최대한 유지한다.

## 범위

### 전역 키 입력

- 공격, 버프, 물약, 픽업, 마을귀환 주문서, 텔포, 점프 등 시간값을 지정해 누르는 모든 키 입력을 포함한다.
- 방향키처럼 조건이 충족될 때까지 유지하고 좌표에 따라 해제하는 상태 기반 입력은 고정 홀드 시간이 없으므로 랜덤 대상이 아니다.
- 사용자가 직접 누르는 F1·F2 단축키 감지는 출력 키 입력이 아니므로 대상이 아니다.
- 마우스 입력은 대상이 아니다.

### 빨코2 UI

- 사냥터가 빨코2일 때만 빨코2 설정 카드 전체를 표시한다.
- 카드 안에 `빨코2 좌표 설정`과 `빨코2 공격 설정`을 독립적인 접이식 영역으로 둔다.
- 두 영역은 프로그램을 열었을 때 모두 접혀 있다.
- 한 영역을 펼쳐도 다른 영역의 상태는 바뀌지 않는다.
- 실행 중 다른 사냥터로 바꿨다가 빨코2로 돌아오면 접기 상태를 유지한다.

## 전역 키 홀드 적용 구조

### 단일 적용 원칙

1. 시간값 기반의 일반 키 누름은 물리 입력 경계에서 설정 원값을 받는다.
2. 물리 입력 직전에 `down_5()`를 한 번 호출한다.
3. `down_5()`는 `round(value * uniform(0.95, 1.0), 4)`를 반환한다.
4. 상위 공격·버프·물약·픽업 코드에 이미 있는 `down_5()` 또는 `plus_minus_5()` 홀드 변환은 제거한다.
5. 수동 `key_down → 대기 → key_up` 방식은 물리 `press()`를 지나지 않으므로 해당 동작을 소유한 루틴에서 홀드 원값에 `down_5()`를 한 번 적용한다.

이 구조로 상위 호출부와 Interception에서 랜덤이 중복 적용되는 것을 막는다.

### Interception 하한

- `press()`의 `max(0.02, hold_sec)` 강제 하한을 제거한다.
- `0.01초` 설정은 `0.0095~0.0100초`로 계산된다.
- 실제 측정 홀드는 드라이버 호출 지연과 Windows 스케줄링으로 계산값보다 길 수 있다.
- 자동 기능이 별도 기본 홀드값을 전달하면 그 기본값의 `95~100%`가 적용되므로 마을귀환 등의 기존 입력 누락 방지는 각 기능의 기본값으로 유지한다.

### 간격과 대기

- 키 홀드가 아닌 간격과 대기는 설정값을 그대로 사용한다.
- 빨코2 일반 사냥 텔포 공격 간격과 7번 이후 우측 끝 이동 간격에도 랜덤을 적용하지 않는다.
- 좌표 스캐너의 반복 대기와 입력 잠금 대기도 변경하지 않는다.

## 빨코2 공격 설정

다음 다섯 값을 `0.01초` 단위로 편집한다.

| 항목 | 설정 키 | 초기 호환값 | 적용 방식 |
|---|---|---:|---|
| 일반 텔포 홀드 | `teleport_hold_sec` | `0.30` | 키 홀드이므로 `95~100%` 한 번 |
| 공격키 홀드 | `attack_hold_sec` | `0.90` | 키 홀드이므로 `95~100%` 한 번 |
| 일반 사냥 텔포 공격 완료 후 간격 | `floor2_hunt_teleport_interval_sec` | `0.72` | 설정값 그대로 |
| 7번 계단 우측 텔포 홀드 | `stair7_right_teleport_hold_sec` | `0.10` | 키 홀드이므로 `95~100%` 한 번 |
| 7번 이후 우측 끝 이동 완료 후 간격 | `floor2_right_edge_teleport_interval_sec` | `0.90` | 설정값 그대로 |

- 값은 좌표 설정과 같은 `rednose2_v5` 설정 객체에 병합 저장한다.
- 좌표 저장은 시간값을 보존하고 공격 설정 저장은 좌표값을 보존한다.
- 저장값은 다음 F1 시작부터 새 러너 프로필에 적용한다.
- 손상된 값, 불리언, 음수, 허용 범위를 벗어난 값은 기본값으로 표시하며 저장 전까지 설정 파일을 자동 변경하지 않는다.
- 홀드와 간격은 `0.00~10.00초` 범위로 제한한다. `0.00초` 홀드는 즉시 키업 요청을 의미한다.

## 빨코2 텔포 공격 시간 의미

### 공격 홀드

- `attack_hold_sec`는 공격키가 내려간 시점부터 해제 요청까지의 목표 총 홀드 시간이다.
- 텔포 전 대기와 텔포키 입력은 이 총 홀드 안에서 진행한다.
- 동기식 텔포 입력 자체가 목표 총 홀드보다 오래 걸리면 공격키는 텔포키가 해제된 직후 해제한다. 이 경우 실제 홀드는 설정값보다 길 수 있으며 입력 진단 로그에 드러난다.

### 완료 후 간격

- 기존 구현은 텔포 공격을 시작하기 직전에 다음 허용 시각을 계산했다.
- 새 구현은 공격키와 텔포키 해제가 끝난 뒤 다음 허용 시각을 계산한다.
- 다음 허용 시각은 `완료 시각 + UI 간격 설정값`이다.
- 일반 사냥과 7번 이후 우측 끝 이동은 서로 다른 간격 값을 소비한다.

### 현재 체감 속도 보존

- 기존 일반 텔포 공격은 약 `1.61~1.65초` 동안 동작했고 시작 기준 `0.40초` 간격은 동작 중 이미 지나갔다.
- 공격키 총 홀드를 `0.90초` 기준으로 정리한 뒤 완료 후 `0.72초`를 더해 기존 일반 사냥의 시작 간 체감 속도에 가깝게 맞춘다.
- 7번 이후 우측 끝 이동은 완료 후 `0.90초`를 사용해 기존 시작 기준 `1.80초`에 가까운 속도를 유지한다.
- 컴퓨터별 Interception 호출 지연 차이는 UI에서 `0.01초` 단위로 보정할 수 있다.

## 설정 마이그레이션

- 간격 기준 변경을 식별하는 빨코2 타이밍 버전 값을 저장한다.
- 타이밍 버전이 없는 기존 설정의 `0.40초`, `1.80초`는 새 의미로 그대로 사용하지 않는다.
- 최초 로드 시 새 호환값 `0.72초`, `0.90초`를 UI와 런타임에 사용한다.
- 사용자가 공격 설정을 저장하면 새 타이밍 버전과 다섯 값을 함께 저장한다.
- 좌표와 빨코3 설정은 마이그레이션하지 않는다.

## UI 연결

- 사냥터 프리셋 위젯이 불러오기 완료 신호로 선택된 사냥터 이름을 전달한다.
- 빨코2 설정 위젯은 초기 활성 사냥터와 프리셋 불러오기 신호를 모두 받아 표시 여부를 갱신한다.
- `빨코2`, `rednose2`, `rednose2v5` 등 기존 정규화 이름을 동일하게 인식한다.
- 현재 사냥터 텍스트를 직접 바꿔 저장하거나 불러오는 기존 경로에서도 표시 상태를 갱신한다.

## 오류 처리

- 잘못된 시간값은 저장하지 않고 공격 설정 영역의 상태 문구로 원인을 표시한다.
- 좌표 검증 실패와 공격 설정 검증 실패는 서로 영향을 주지 않는다.
- 설정 저장 실패 시 기존 설정 객체를 변경하지 않는다.
- 전역 랜덤 적용 과정에서 음수 홀드는 `0.0`으로 처리한다.

## 테스트

### 전역 입력 정책

- `down_5()`가 `95~100%`, 소수점 넷째 자리, 음수 `0.0` 규칙을 지키는지 확인한다.
- Interception `press()`가 `0.02초` 하한 없이 랜덤 결과를 한 번만 대기하는지 확인한다.
- 공격, 버프, 물약, 픽업, 마을귀환의 대표 경로가 원값을 물리 입력 경계에 전달해 이중 랜덤이 없는지 확인한다.
- 수동 공격 홀드 경로가 한 번만 랜덤을 적용하는지 확인한다.

### 빨코2 UI와 런타임

- 빨코2에서만 카드가 표시되는지 확인한다.
- 두 영역이 처음에 접혀 있고 독립적으로 펼쳐지는지 확인한다.
- 다섯 값의 불러오기, 저장, 기본값 복원, 손상값 복구를 확인한다.
- 좌표값과 시간값이 서로 보존되는지 확인한다.
- 일반 사냥과 우측 끝 이동이 각자의 완료 후 간격을 사용하는지 확인한다.
- 기존 설정이 새 호환값으로 마이그레이션되는지 확인한다.
- 빨코3 러너와 일반 사냥터 설정이 바뀌지 않는지 확인한다.

## 변경 제외 범위

- 입력 잠금 구조, 좌표 스캐너 주기, 빨코2 좌표 자체, 빨코3 동선은 변경하지 않는다.
- 키 종류와 키 매핑은 변경하지 않는다.
- EXE 빌드, 설치본 생성, 푸시, 배포는 이 구현 범위에 포함하지 않는다.

## 완료 조건

- 모든 시간 기반 실제 키 누름에 `95~100%` 랜덤이 정확히 한 번만 적용된다.
- Interception의 전역 `0.02초` 홀드 하한이 제거된다.
- 간격과 대기에는 랜덤이 적용되지 않는다.
- 빨코2의 두 접이식 설정이 빨코2 선택 시에만 보인다.
- 다섯 시간값이 다음 F1 시작부터 각각 올바른 구간에 적용된다.
- 관련 회귀 테스트, 문법 검사, UTF-8 검사와 변경 범위 검사가 통과한다.
