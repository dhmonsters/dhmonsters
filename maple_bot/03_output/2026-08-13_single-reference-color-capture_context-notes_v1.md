# 단일 캐릭터 기준색 캡처 작업 기록

## 승인된 결정

기준색은 드래그 영역 전체 픽셀의 평균 RGB 한 값만 저장한다. 기존 HSV 네 슬라이더는 제거하고 점 크기 최소·최대는 유지한다. 검출 허용 범위는 프로그램이 자동 계산한다.

## 드래그 완료 조건

정상 해제 이벤트와 왼쪽 버튼 해제 상태 감시를 동일한 완료 함수로 연결한다. 정상 드래그는 선택 창을 자동으로 닫으며 X 또는 ESC만 취소로 취급한다.

## 호환 정책

새 `reference_color_rgb`가 있으면 기존 HSV 네 설정을 무시한다. 새 값이 없으면 기존 `char_r/g/b`를 사용한다. 기존 키는 이전 버전 복귀 호환을 위해 즉시 삭제하지 않는다.

## 적용 시점

설정은 캡처 직후 저장하며 실행 중인 스캐너에는 정지 후 다음 F1 시작 시 적용한다.

## 배포 범위

EXE 빌드, 설치본 생성, 배포는 수행하지 않는다.

## 구현 결과

배포 기본 대표 색상은 RGB `[225, 225, 0]`으로 확정했다. OpenCV 화면에서는 같은 색이 BGR `(0, 225, 225)`로 표현된다. 새 기준색 캡처는 드래그 영역 전체 픽셀의 채널 평균을 반올림해 `reference_color_rgb` 한 항목으로 저장한다.

선택기는 16ms 간격으로 왼쪽 버튼 상태를 확인한다. 정상 해제 이벤트와 상태 감시는 하나의 완료 함수를 사용하므로 해제 이벤트가 누락돼도 마지막 영역을 확정하고 중복 저장하지 않는다. 원본 기준 2×2 미만 영역은 창을 닫지 않고 다시 선택하도록 안내한다.

UI에서는 HSV 네 슬라이더를 제거하고 저장된 기준색의 견본, HEX, RGB만 표시한다. 점 크기 최소·최대와 `y_p.png` 단일 안전 덮어쓰기는 유지했다. 설정 저장 실패 시 메모리의 이전 기준색을 복원하고 성공 표시를 하지 않는다.

## 검증 결과

선택기, 연결·인식 페이지, 색상 변환, 캐릭터 스캐너, 템플릿 재로딩, 설정 변환 관련 테스트는 `68 passed`다. 경고 9개는 기존 `mss.mss` 폐기 예정 경고이며 새 경고는 없다. 관련 Python 파일의 `compileall`은 출력 없이 종료 코드 0으로 통과했다.

기존 `tests/test_runtime.py`의 Humanizer 및 이전 공격·픽업 구조 불일치는 이번 변경과 무관해 수정하지 않았다.
