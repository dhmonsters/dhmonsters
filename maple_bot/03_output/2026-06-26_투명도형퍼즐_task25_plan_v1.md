# Task 25 계획

## 목표
- trace에 저장된 frame state를 UI에서 이전과 다음 버튼으로 탐색한다.
- 현재 선택 frame이 없으면 다음 버튼은 가장 이른 저장 frame을 선택한다.
- 현재 선택 frame이 없으면 이전 버튼은 가장 늦은 저장 frame을 선택한다.
- 시작 또는 끝에 도달하면 선택 상태를 유지하고 false를 반환한다.

## 검증
- timeline navigation 버튼의 objectName을 smoke test로 확인한다.
- 저장된 frame 간 next 이동을 smoke test로 확인한다.
- 저장된 frame 간 previous 이동을 smoke test로 확인한다.
- 전체 puzzle smoke test와 문법 검사를 통과시킨다.
