# 빨코2 회수 단계 재선택 컨텍스트 노트

## 확정 범위

- 사용자는 앞서 제안한 해결책 중 위치별 단계 복구와 미검출 시 이전 단계 승계만 승인했다.
- `arrival_side`와 X 도착 판정은 이번 작업에서 변경하지 않는다.
- 텔레포트 직전 X·Y 이중 확인도 이번 작업에서 추가하지 않는다.

## 확인된 증상

- 로그에서 `platform27` 상태, 목표 X=91, 현재 X=11, 거리 80인데 도착으로 처리됐다.
- 이후 왼쪽 텔레포트로 X=4, Y=76에 떨어져 7번 사다리 복구가 시작됐다.
- 이번 수정은 추락 이후 실제 위치에 맞게 회수 단계를 복구하는 데 한정한다.

## 구현 결과

- 회수 진행 중 1층에서 7번 복귀가 성공하면 다음 단계를 `right_edge`로 선택한다.
- 14/15·16·27 위치가 검출되면 각각 `platform16`·`platform27`·`return_floor2`를 선택한다.
- 일반 2층이 검출되면 `right_edge`, 1층이 검출되면 `stair7_return`을 선택한다.
- 미검출이면 마지막 확정 단계의 다음 순서를 유지한다.
- 기존 X 도착 판정과 텔레포트 전 조건은 변경하지 않았다.

## 검증 결과

- 수정 전 신규 테스트 4개가 의도한 상태 불일치로 실패하는 것을 확인했다.
- 수정 후 빨코2 전용 테스트 72개와 Python 컴파일이 통과했다.
- 오래된 `tests/test_floor_fall_recovery.py` 2개는 현재 생성자에 없는 `humanizer` 인자를 사용해 별도로 실패했으며 이번 변경 파일과 무관하다.
