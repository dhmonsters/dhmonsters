# Claude v2.4.0 릴리스 계획

## 목표

- 현재 검증된 maple_bot 변경사항을 Claude v2.4.0으로 배포한다.
- 설치파일 이름을 `Claude_v2.4.0_Setup.exe`로 생성한다.

## 순서

1. 버전 관련 파일을 2.4.0으로 통일한다.
2. 관련 테스트와 문법 검사를 실행한다.
3. 릴리스 변경만 커밋하고 원격 저장소에 푸시한다.
4. 실행파일과 설치파일을 빌드한다.
5. 설치파일 이름, 버전, 해시를 확인한다.
6. GitHub Release v2.4.0을 생성한다.

## 성공 기준

- `version.txt`, `version.json`, `installer.iss`, `build.bat`가 모두 2.4.0을 가리킨다.
- `03_output/Claude_v2.4.0_Setup.exe`가 생성된다.
- GitHub Release v2.4.0에 동일한 설치파일이 첨부된다.
