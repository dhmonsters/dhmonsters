# 투명도형 퍼즐 F1 시작 단축키 계획

## 목표

인게임 포커스 상태에서도 F1로 화면 감시 녹화를 시작할 수 있게 만든다.

## 성공 기준

- UI 창에 포커스가 있을 때 F1 입력이 화면 감시 시작과 같은 동작을 한다.
- 게임 창에 포커스가 있을 때도 전역 F1 단축키가 화면 감시 시작 핸들러를 호출한다.
- 기존 F3 녹화 종료 동작은 유지된다.
- 버튼 표기에서 F1 시작과 F3 종료를 바로 알 수 있다.
- 관련 자동 검증이 통과한다.

## 작업 순서

1. F1 시작 동작을 검증하는 테스트를 먼저 추가한다.
2. 콘솔 UI 내부 키 입력에 F1 처리를 연결한다.
3. 전역 단축키 등록에 F1 시작을 추가한다.
4. 관련 테스트와 실행 전 점검을 돌린다.
