# 캡처 드래그 해제 고정 수정 계획

## 목표

기준색 및 캐릭터 템플릿 캡처에서 마우스 버튼을 놓아도 선택이 종료되지 않고 다음 클릭에 1×1로 초기화되는 문제를 수정한다.

## 원인 가설

캔버스가 드래그 중 마우스 입력을 독점하지 않아 버튼 해제 이벤트를 놓칠 수 있으며, 별도의 드래그 상태가 없어 다음 클릭이 새 시작점으로 처리된다.

## 구현 범위

1. 왼쪽 버튼을 누를 때 드래그 상태를 시작하고 마우스를 캔버스에 고정한다.
2. 왼쪽 버튼을 누른 이동만 선택 영역에 반영한다.
3. 버튼 해제 시 마우스 고정을 풀고 드래그 상태를 종료한 뒤 한 번만 확정한다.
4. 무효 선택은 시작점과 끝점을 모두 초기화한다.
5. 선택기 단위 테스트와 관련 회귀 테스트를 실행한다.

## 제외 범위

EXE 빌드, 설치본 생성, 배포는 수행하지 않는다.
