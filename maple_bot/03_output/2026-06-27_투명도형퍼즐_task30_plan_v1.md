# Task 30 계획

## 목표
- `puzzle.py` UI에서 기본 테스트 또는 replay 실행 후 `녹화 폴더` 버튼으로 방금 생성된 세션 폴더를 바로 열 수 있게 한다.

## 범위
- `PuzzleConsoleWindow`에 마지막 리포트 경로와 마지막 세션 폴더 경로를 저장한다.
- `녹화 폴더` 버튼을 실제 폴더 열기 동작에 연결한다.
- 테스트에서는 실제 파일 탐색기를 열지 않도록 folder opener를 주입한다.
- replay 실행 전에는 열 폴더가 없다는 로그만 남긴다.

## 제외
- 라이브 화면 감시, 자동 마우스 입력, 외부 알림 전송은 이번 범위에 넣지 않는다.
- OS별 파일 탐색기 세부 옵션은 기본 구현만 둔다.

## 검증
- replay 실행 후 `녹화 폴더` 버튼이 report parent 폴더를 opener에 전달하는지 테스트한다.
- replay 실행 전 버튼을 누르면 opener를 호출하지 않는지 테스트한다.
- 전체 puzzle 테스트와 실제 transparent-test 실행을 다시 확인한다.
