# 게임창 템플릿 캡처 및 캐릭터 위치 진단 판단 기록

## 2026-08-14 초기 조사

- 몬스터·닉네임 캡처는 `mss.monitors[1]`을 직접 사용해 주 모니터 전체를 캡처한다.
- 같은 파일의 `_capture_game_client`는 설정된 게임창의 클라이언트 영역과 화면 원점을 정상적으로 반환한다.
- 미니맵 UI는 스캐너 좌표를 중앙으로 원을 그리므로 별도의 수평 보정이 없다.
- 템플릿 감지는 캡처 사각형의 기하학적 중앙을 반환한다.
- 색상 감지는 기준색 범위에 포함된 윤곽의 무게중심을 반환한다.
- 실제 실행에서 어느 감지 방식이 선택됐는지 현재 로그만으로 구분하기 어려워, 좌표 계산을 바꾸기 전에 방식과 원시 좌표를 기록한다.
- 사용자의 기존 미커밋 변경은 보존하고 이번 작업과 무관한 코드는 수정하지 않는다.

## 구현 및 검증 결과

- 공용 몬스터·닉네임 템플릿 캡처는 `_capture_game_client`가 반환한 게임 클라이언트 이미지와 화면 원점을 사용한다.
- 캐릭터 감지 로그는 `source=template|color`, `raw=(x,y)`, `candidate=(x,y,w,h)`를 1초 주기로 기록한다.
- 템플릿 감지는 실제 일치 사각형을, 색상 감지는 선택된 윤곽의 경계 사각형을 진단값으로 남긴다.
- 좌표 선택과 중심 계산 공식은 변경하지 않았다.
- 직접 관련된 회귀 테스트는 `40 passed`, 기존 `mss` 폐기 예정 경고 9개이며 구문 검사는 성공했다.
- 확장 실행에서는 오래된 `tests/test_runtime.py` 기대값 때문에 `60 passed, 6 failed`가 나왔다. 실패는 제거된 `humanizer`, 현재 `pickup` 구성, 변경된 `AttackSequence` 생성자 등 이번 변경 파일과 무관하다.
- EXE 빌드, 설치본 생성, 배포는 수행하지 않았다.
- 제품 코드와 회귀 테스트 네 파일은 기존 인덱스와 분리해 커밋 `547ac1b`에만 포함했다.
