# Claude v2.4.1 배포 컨텍스트

- 현재 수정 작업 브랜치는 원격 main과 크게 갈라져 있어 직접 병합하지 않는다.
- 실제 v2.4.0 태그를 기준으로 새 릴리스 브랜치를 만들고 이번 수정 커밋 세 개만 적용했다.
- templates/player/y_p.png와 templates/junk/shop_exit.png는 새 설치 환경의 기능에 필요하므로 릴리스에 포함한다.
- 설치파일 이름은 사용자가 지정한 Claude_v2.4.1_Setup.exe를 사용한다.
- 미니맵 영역과 좌표 설정은 이번 배포에서 변경하지 않는다.
- 자동판매 및 캐릭터 감지 관련 테스트 40개가 통과했다.
- 기존 템플릿 재로딩 테스트의 일반 객체 모형을 실제 8x8 이미지 배열로 바로잡았다.
- 기존 2.4.0 설치본과 원본 작업 폴더의 assets, templates, monsters, models, maps 파일 해시가 일치함을 확인했다.
- 실행파일 빌드 후 배포 폴더의 버전, 수정 코드, 두 템플릿 해시가 릴리스 원본과 일치했다.
- 최종 설치파일을 별도 검사 폴더에 설치해 버전 2.4.1과 수정 코드 및 템플릿 포함을 재검증했다.

- SHA-256은 E6FD56D57C91E85F009E047A3E0FD0E641DC978634F95DE61894A345A028EDAE다.
- GitHub Release 주소는 https://github.com/dhmonsters/dhmonsters/releases/tag/v2.4.1 이다.
