# 투명도형 퍼즐 Task 14 컨텍스트 노트

- 사용자가 탐지 ROI도 해상도 변화에 맞게 상대좌표로 변경하길 요청했다.
- 기존 탐지 절대좌표 `[1126, 297, 296, 130]`은 2560×1369 기준값으로 보고 비율로 환산한다.
- 탐지 ROI도 `basis="window_client"`로 생성하고 `x_ratio`, `y_ratio`, `w_ratio`, `h_ratio`를 유지한다.
- 세션 시작 후 ROI는 여전히 고정이며, 세션 중 해상도 변화는 자동 보정이 아니라 별도 무효 이벤트 대상이다.
- RED는 UI 탐지 ROI 라벨이 아직 절대좌표를 표시하는 실패로 확인했다.
- 탐지 ROI 비율은 `1126/2560`, `297/1369`, `296/2560`, `130/1369`로 계산한다.
- UI 라벨은 탐지 ROI를 `0.440,0.217,0.116,0.095` 형식으로 표시한다.
- headless replay의 `SESSION_START` trace에는 detect ROI의 `basis="window_client"`와 ratio 값이 남는다.
- 집중 테스트 8개, 전체 퍼즐 회귀 테스트 41개, AST 파싱 4개를 통과했다.
