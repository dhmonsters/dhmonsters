# 빨코2 좌표 설정 UI 설계

## 목적

빨코2 전용 러너가 사용하는 이동·회수 X 좌표를 사용자가 동선·이동 탭에서 숫자로 조정할 수 있게 한다. 저장된 값은 실행 중인 러너를 바꾸지 않고 다음 F1 시작 시 적용한다.

## 범위

수정 가능한 값은 기준 미니맵 너비 172의 X 좌표로 제한한다.

| UI 그룹 | 표시 항목 | 설정 키 | 기본값 |
|---|---|---|---:|
| 2층 사냥 범위 | 왼쪽 X | `floor2_left_x` | 55 |
| 2층 사냥 범위 | 오른쪽 X | `floor2_right_x` | 124 |
| 회수 우측 끝 | 정지 X | `floor2_right_safe_x` | 124 |
| 7번 계단 | 목표 X | `stair7_x` | 41 |
| 7번 계단 | 허용 최소 X | `stair7_x_min` | 38 |
| 7번 계단 | 허용 최대 X | `stair7_x_max` | 44 |
| 24번 발판 | 접근 X | `platform24_approach_x` | 43 |
| 24번 발판 | 도착 X | `platform24_x` | 30 |
| 14/15번·16번 | 공통 접근 X | `platform1415_16_approach_x` | 95 |
| 14/15번 | 허용 최소 X | `platform1415_x_min` | 94 |
| 14/15번 | 허용 최대 X | `platform1415_x_max` | 96 |
| 27번 발판 | 접근 X | `platform27_approach_x` | 91 |
| 16번 실패 시 27번 우회 | 접근 X | `platform27_bypass_approach_x` | 80 |
| 16번 실패 시 27번 우회 | 허용 최소 X | `platform27_bypass_x_min` | 72 |
| 16번 실패 시 27번 우회 | 허용 최대 X | `platform27_bypass_x_max` | 89 |

Y 판정 범위, 입력 시간, 공격 횟수, 시도 횟수, 자동판매 좌표, 빨코3 설정은 이번 범위에 포함하지 않는다.

## UI 구조

동선·이동 탭의 사냥터 프리셋 카드 바로 아래에 `빨코2 좌표 설정` 카드를 배치한다. 카드 구현은 `pages.py`에서 분리한 전용 위젯이 담당한다.

각 값은 정수 입력칸으로 제공하며 범위는 0부터 171까지다. 카드 하단에는 `저장`과 `빨코2 기본값 복원` 버튼 및 상태 문구를 둔다.

- `저장`은 모든 값을 검증한 후 `rednose2_v5`에 한 번에 기록하고 설정 파일을 저장한다.
- 저장 성공 시 `저장 완료 · 다음 F1 시작부터 적용됩니다.`를 표시한다.
- `빨코2 기본값 복원`은 입력칸만 기본값으로 되돌린다. 설정 파일에는 `저장`을 눌렀을 때만 반영한다.
- 입력 오류가 있으면 설정을 일부만 저장하지 않고 카드 안에 원인을 표시한다.

## 검증 규칙

모든 입력은 다음 조건을 동시에 만족해야 한다.

1. 모든 값은 0부터 171 사이의 정수다.
2. `floor2_left_x <= floor2_right_x`다.
3. `stair7_x_min <= stair7_x <= stair7_x_max`다.
4. `platform1415_x_min <= platform1415_16_approach_x <= platform1415_x_max`다.
5. `platform27_bypass_x_min <= platform27_bypass_approach_x <= platform27_bypass_x_max`다.

검증 실패 시 어떤 그룹이 잘못됐는지 표시하고 기존 저장값은 그대로 유지한다.

## 저장과 런타임 적용

설정 파일의 `rednose2_v5`를 단일 저장 위치로 사용한다. 런타임 프로필 생성 시 기존 검증된 기본값을 먼저 만들고, 위 표에 있는 허용 키만 사용자 설정으로 덮어쓴다. 다른 키는 UI 저장값으로 덮어쓰지 않는다.

덮어쓴 X 값에서 기존 방식대로 기준 미니맵 너비 172에 대한 비율을 생성한다. 실제 미니맵 너비가 달라지면 러너가 현재 크기로 환산한다.

프로그램의 F1 시작 경로는 매번 `to_runtime_config()`를 다시 호출하고 빨코 전용 러너를 재생성한다. 따라서 저장 시 실행 중인 러너는 건드리지 않고 다음 F1 시작 시 새 좌표가 적용된다.

설정 파일이 외부에서 손상됐거나 허용 범위를 벗어난 경우 런타임 생성 단계에서는 해당 그룹의 사용자 값을 무시하고 기본값을 사용한다. 잘못된 설정 때문에 프로그램 시작이 실패해서는 안 된다.

## 구성요소 경계

- 전용 UI 위젯은 입력 표시, 기본값 복원, 검증, 저장 상태만 담당한다.
- `pages.py`는 전용 위젯을 동선·이동 탭에 배치하기만 한다.
- `config_adapter.py`는 빨코2 기본 프로필과 사용자 X 좌표의 허용 목록 병합 및 비율 생성을 담당한다.
- 빨코2 러너는 이미 전달받은 프로필을 소비하므로 좌표 편집을 위해 동작 로직을 바꾸지 않는다.
- `config_manager.py`는 기존 UTF-8 저장 방식과 사용자 설정 병합 동작을 유지한다.

## 테스트

다음 동작을 자동 테스트한다.

1. 카드가 기존 저장값을 정확히 표시한다.
2. 유효한 좌표를 저장하면 허용 키만 `rednose2_v5`에 기록된다.
3. 각 최소·목표·최대 관계가 잘못되면 저장되지 않는다.
4. 기본값 복원만 누르면 설정 파일은 바뀌지 않고 입력칸만 바뀐다.
5. 기본값 복원 후 저장하면 표의 기본값이 기록된다.
6. 사용자 X 좌표가 런타임 프로필과 비율 키에 반영된다.
7. 미니맵 너비가 달라져도 저장된 비율로 환산된다.
8. 허용하지 않은 빨코2 설정 키는 이번 UI 병합으로 변경되지 않는다.
9. 손상되거나 범위를 벗어난 외부 설정은 기본값으로 안전하게 대체된다.
10. 빨코3 런타임 프로필은 변경 전과 동일하다.

## 완료 조건

- 사용자가 지정된 빨코2 X 좌표만 UI에서 수정할 수 있다.
- 저장값이 실행 중에는 반영되지 않고 다음 F1 시작부터 적용된다.
- 잘못된 범위는 저장되지 않으며 기존 설정을 보존한다.
- 기본값 복원이 명시적인 저장 전에는 설정 파일을 변경하지 않는다.
- 기존 빨코2 좌표 비율 환산과 빨코3 동작에 회귀가 없다.
