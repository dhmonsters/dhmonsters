# 게임창 템플릿 캡처 및 캐릭터 위치 진단 계획

## 목적

- 사냥 영역의 몬스터·닉네임 템플릿 캡처가 주 모니터 전체가 아니라 게임 클라이언트만 사용하게 한다.
- 캐릭터 표시의 수평 치우침을 임의 보정하지 않고 실제 감지 방식과 원시 좌표로 구분할 수 있게 한다.

## 변경 범위

1. `core_ui/pages.py`의 공용 템플릿 캡처 버튼이 기존 게임 클라이언트 캡처 함수를 재사용하게 한다.
2. `core/sensing/char_scanner.py`가 성공한 감지 방식과 원시 좌표를 진단 로그에 남기게 한다.
3. `tests/test_pages.py`, `tests/test_char_scanner.py`에 회귀 테스트를 먼저 추가한다.
4. 기존 좌표 계산, 빨코2·빨코3 루틴, EXE 빌드와 배포는 변경하지 않는다.

## 검증 기준

- 캡처 선택기에 게임 클라이언트 이미지와 화면 원점이 전달된다.
- 선택 좌표가 게임창 원점 기준으로 정확히 잘려 저장된다.
- 감지 성공 로그에서 `template` 또는 `color`와 원시 X/Y를 확인할 수 있다.
- 관련 테스트와 Python 구문 검사가 통과한다.
