# Claude v2.4.8 배포 작업 기록

## 승인 내용

- 배포 버전은 2.4.8이다.
- 사용자가 `dhmonsters/dhmonsters` 저장소의 소유 또는 관리 권한을 확인했다.

## 포함 수정

- 빨코2 회수 실패 후 실제 위치 또는 이전 확정 단계에 따른 단계 재선택.
- 회수 종료 후 2층 정상 사냥 중 자동판매 진입 허용과 0.1초 입력 반환 대기.
- 미검출 0.8초 이후 반대 방향 이동 및 포탈 끝 중앙 방향 지속 복구.
- 포탈 끝 미검출 중 수직 텔레포트 차단.
- 7번 사다리 중간 복귀 시 X와 Y 동시 확인.
- 구형 Humanizer API 제거 후 홀드시간 95~100%, 실행 간격 95~105% 보정은 독립 모듈로 유지.
- 프로그램에서 퍼즐·검증 도구 연결을 해제하고 배포 번들에서도 제외.
- OCR·CUDA·ncnn·모델 중복 포함을 제거해 검증 빌드를 약 240.1MB로 축소.
- 최종 설치파일 크기는 약 65.9MB이며 SHA-256은 `e7b3d5d6240c39129e7ebfdfc5c51b00d51ee1da37b5d2f6b6c9191d33a51a4d`다.
- 복구 런처 관리 환경에서 `ClaudeApp.exe`가 5초 이상 정상 실행되는 것을 확인했다.
- GitHub Release `v2.4.8` 자산의 원격 SHA-256이 로컬 설치파일과 일치한다.
- main의 `maple_bot/version.json`을 2.4.8로 공개해 기존 프로그램의 업데이트 확인 경로를 연결했다.
