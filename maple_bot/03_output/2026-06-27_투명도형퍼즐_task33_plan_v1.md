# Task 33 계획

## 목표
- 실전 라이브 테스트 전에 현재 PC에서 화면 캡처가 가능한지 한 번에 확인하는 사전점검을 추가한다.

## 범위
- `--live-capture-check` CLI를 추가한다.
- 캡처 성공 시 `capture_check.png`와 `capture_check.md`를 남긴다.
- 캡처 실패 시 실패 원인을 `capture_check.md`에 남기고 CLI는 실패 코드를 반환한다.
- UI 입력 패널에 `캡처 점검` 버튼을 추가한다.
- 자동 마우스 입력과 풀이 로직은 넣지 않는다.

## 검증
- 가짜 캡처 프레임으로 성공 리포트와 PNG 생성 테스트를 통과시킨다.
- 가짜 캡처 실패로 실패 리포트 생성 테스트를 통과시킨다.
- CLI와 UI 버튼 연결 테스트를 통과시킨다.
- 전체 puzzle 테스트와 문법 검사를 통과시킨다.
