# Claude v2.4.5 배포 컨텍스트 기록

## 배포 기준

- GitHub 최신 공개 릴리스는 2026-08-24 게시된 `v2.4.4`다.
- 배포 기준 브랜치는 `codex/claude-v2.4.2-release`이며 현재 2.4.4 공개 배포 결과 커밋을 포함한다.
- 선행 수정 `0ff6a69`와 기능 커밋 `ebf8e08`을 v2.4.4 배포 기준에 병합했다.
- 설치 파일명은 `Claude_v2.4.5_Setup.exe`로 고정한다.
- 퍼즐 관련 대형 CUDA·Qt 라이브러리는 이번 빨코2 배포에 추가하지 않는다.

## 검증 기록

- 빨코2 복귀·자동판매·좌표 UI·설정 재적용 관련 회귀 테스트 101개가 통과했다.
- 기존 셸 테스트 두 개는 100ms 로그 배치 처리 이전 기대값과 과거 배경색 기대값을 검사하는 배포 전부터 존재한 별도 테스트 문제로 확인했다.
- 자동 업데이트 코드는 `origin/main`의 `maple_bot/version.json`을 읽는다. 공개 릴리스 생성 후 main 메타데이터도 2.4.5로 별도 갱신해야 한다.

## 릴리스 설명 초안

빨코2 회수 루틴에서 7번 복귀 후 첫 두 공격 텔레포트의 공격 홀드·텔레포트 홀드·간격을 각각 설정할 수 있도록 개선하고, 우측 끝부터 14/15 접근까지 느린 이동을 유지했으며, 일반 사냥 중 좌측 추락 시 7번 복귀 후 우측 끝까지 느리게 회수하도록 안정화했습니다.
