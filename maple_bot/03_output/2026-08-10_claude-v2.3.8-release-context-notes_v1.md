# Claude v2.3.8 릴리스 기록

- GitHub 최신 Release는 v2.3.7이며 다음 버전은 v2.3.8이다.
- 자동 업데이트는 main 브랜치의 maple_bot/version.json을 읽는다.
- 현재 작업 브랜치는 origin/main과 크게 갈라져 있으므로 그대로 병합하지 않는다.
- 원격 main을 부모로 하는 별도 릴리스 인덱스에 현재 Claude 제품 파일만 담는다.
- 현재 로컬 config에는 개인 텔레그램 정보가 있어 배포본에는 정제된 사본만 포함한다.
- 현재 작업용 config는 수정하거나 초기화하지 않는다.
- 구형 main.py는 이미 run_integrated.py의 main을 호출한다.
- 배포 설정은 민감정보를 비우고 프로젝트 내부 절대경로를 상대경로로 바꾸며 외부 PC 경로를 제거한다.
- 미니맵 지도 파일이 배포에서 누락되지 않도록 maps 폴더를 빌드 입력에 추가했다.
- Python 전체 구문 검사를 통과했고 이번 변경 관련 회귀 테스트 56개가 모두 통과했다.
- 전체 구형 테스트 모음은 제거된 Humanizer API와 예전 절대좌표·구형 UI 전제로 실패하므로 릴리스 판정에서 분리했다.
- 첫 PyArmor 점검에서 run_integrated.py의 BOM과 첫 줄에 남은 문자형 줄바꿈을 발견해 UTF-8 무BOM 헤더로 복구했다.
