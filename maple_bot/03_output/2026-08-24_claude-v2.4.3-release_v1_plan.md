# Claude v2.4.3 배포 계획

1. 모든 버전 파일과 설치파일 이름을 2.4.3으로 통일한다.
2. 한국어 릴리스 문구와 소스 파일의 UTF-8 상태를 검사한다.
3. 빨코2 관련 테스트와 변경 파일 구문 검사를 실행한다.
4. 배포 준비 변경을 커밋하고 소스 브랜치를 푸시한다.
5. PyArmor·PyInstaller와 Inno Setup으로 설치파일을 생성한다.
6. 빌드 결과물의 버전·필수 파일·실행·임시 설치를 검증한다.
7. 검증을 통과한 설치파일만 GitHub Release에 게시한다.
8. main 브랜치의 자동 업데이트 메타데이터를 2.4.3으로 갱신한다.
