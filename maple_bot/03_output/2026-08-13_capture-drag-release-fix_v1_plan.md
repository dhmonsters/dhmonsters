# 캡처 드래그 해제 초기화 수정 계획

## 목적

- 기준색과 캐릭터 템플릿 선택 중 드래그 영역이 해제 순간 초기화되는 문제를 수정한다.

## 변경 범위

1. 해제 좌표가 비정상적으로 시작점으로 돌아오는 이벤트를 테스트로 재현한다.
2. 유효한 마지막 드래그 위치를 해당 경우에만 보존한다.
3. 정상 드래그와 기준색·템플릿 저장 흐름을 회귀 검증한다.

## 성공 기준

- DPI 환경 재현 이벤트에서 선택창이 한 번의 드래그로 완료된다.
- 이동 이벤트 없이 누르고 놓는 기존 동작도 유지된다.
- 기준색과 캐릭터 템플릿 버튼 테스트가 통과한다.
- EXE 빌드와 배포는 진행하지 않는다.
