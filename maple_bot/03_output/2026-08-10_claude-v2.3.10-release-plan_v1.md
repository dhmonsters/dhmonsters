# Claude v2.3.10 릴리스 계획

## 목표

빨코2 이동·회수 X 좌표 15개를 UI에서 수정하고 다음 F1 시작부터 적용하는 기능을 Claude v2.3.10 설치 파일로 안전하게 배포한다.

## 실행 순서

1. 빨코2 기능 PR을 main에 병합하고 변경 범위를 확인한다.
2. version.txt, version.json, installer.iss, build.bat을 2.3.10으로 일치시킨다.
3. 관련 테스트, 문법, UTF-8, 배포 설정 정제 상태를 검증한다.
4. 릴리스 브랜치를 원격에 올리고 깨끗한 소스에서 EXE를 빌드한다.
5. 필수 파일과 개인 정보 부재를 확인한 뒤 Inno Setup 설치 파일을 만든다.
6. GitHub Release v2.3.10을 생성하고 설치 파일 크기와 SHA-256을 대조한다.
7. 릴리스 PR을 main에 병합해 업데이트 공지를 활성화한다.

## 완료 기준

- 네 버전 파일이 모두 2.3.10을 가리킨다.
- 관련 테스트와 문법·UTF-8 검사가 통과한다.
- 배포 설정에 텔레그램 정보, 라이선스 정보, 개인 절대 경로가 없다.
- EXE와 설치 파일에 필수 모델, 맵, Interception 구성요소가 포함된다.
- GitHub Release 설치 파일과 로컬 설치 파일의 크기와 SHA-256이 일치한다.
- main의 version.json이 실제로 존재하는 v2.3.10 Release 설치 파일을 가리킨다.
