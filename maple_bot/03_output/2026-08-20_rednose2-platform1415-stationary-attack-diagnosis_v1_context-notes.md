# 빨코2 14/15 발판 제자리 공격 진단 기록

## 첨부 로그 공통 증거

- 접근 목표는 X=95인데 검출 위치는 계속 X=97이다.
- 이동 함수는 거리 -2를 도착으로 처리하고 방향키를 누르지 않는다.
- 직후 14/15 발판 정렬 판정은 실패한다.
- 이 과정이 반복되며 다음 시도까지 약 1.5초가 걸린다.
- 첨부 로그에는 자동판매 실행 로그가 없다.

## 코드 원인

- 14/15 접근 목표는 X=95이고 실제 정렬 허용범위는 X=94~96이다.
- 접근 이동에는 `arrival_tolerance=2.0`이 적용되어 X=97도 목표 도착으로 판정된다.
- X=97은 정렬 허용범위 밖이므로 직후 `platform 14/15 X not aligned`가 발생한다.
- 정렬 실패 분기는 `_retry_attack_once()`를 호출하며 기본 공격 홀드시간은 1.5초다.
- 6회 실패 후에도 회수 단계가 `platform1415`로 보존되어 다음 실행에서 같은 과정을 다시 반복한다.

## 재현 및 배제 결과

- X=97 고정 모의 실행 결과는 함수 실패, 공격 6회, 각 1.5초, 총 모의시간 9초였다.
- 빨코2 러너는 `controls_attack=True`이므로 런타임의 일반 공격 스레드는 별도 공격을 실행하지 않는다.
- 첨부 로그에 자동판매 진입 로그가 없고 해당 분기는 자동판매 코드와 독립적이다.
- 회수·타이밍·미검출 관련 기존 테스트 17개가 통과했다.
- 기존 테스트에는 X=97처럼 이동 도착 허용오차와 실제 정렬범위가 충돌하는 사례가 없다.

## 확정 결론

- 제자리 공격은 몬스터 공격 판단이 아니라 14/15 정렬 실패 복구용으로 의도적으로 실행되는 1.5초 공격이다.
- 근본 원인은 접근 도착 허용오차가 실제 정렬범위보다 넓은 조건 불일치다.
- 수정 시에는 정렬 접근을 실제 유효범위 안까지 계속 이동시키고, X 정렬 실패만으로 1.5초 공격을 실행하지 않도록 분리해야 한다.
