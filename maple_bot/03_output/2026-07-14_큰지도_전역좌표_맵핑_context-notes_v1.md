# 큰 지도 전역좌표 맵핑 맥락 메모

## 2026-07-14 현재 구조 확인

- 실행 진입점은 `run_integrated.py`지만 지도·이동·공격의 실제 로직은 `core/runtime.py`, `core/navigation/block_runner.py`, `core_ui/minimap_canvas.py` 등에 분리되어 있다.
- 현재 `MinimapCanvas`와 `RouteCanvas`는 캡처된 미니맵 폭·높이를 전체 좌표 범위로 사용한다.
- 현재 이동기는 캐릭터의 미니맵 X와 블록의 `target_x`를 비교해 좌우 입력을 수행한다.
- 현재 사냥 구간 공격은 `move` 블록 진입 상태에 묶여 있다.
- 현재 설정의 미니맵 캡처 크기는 `276×100`이고 기존 루트는 로컬 X `50~215` 구간을 사용한다.
- 현재 `floor_hunt.route_mode`는 `false`이며 기존 route에는 이동 블록 한 개가 저장되어 있다.

## 사용자 결정

- 실제 지도는 미니맵 창보다 크고 미니맵에는 일부만 보이는 B 이동 창형이다.
- 큰 지도 이미지를 직접 불러오고 두 기준점으로 보정한다.
- 큰 지도와 미니맵의 방향과 가로세로 비율은 같다.
- 전역 위치는 수동 기준점과 자동 배경 추적을 결합한다.
- 구역 밖에서는 사용자가 지정한 이동점과 액션점만 허용한다.
- 액션점은 키, 누르는 시간, 반복 횟수, 대기로 제한한다.
- 반복 루트와 일회성 목적지 이동을 모두 지원한다.
- 기존 로컬 설정은 자동 변환한다.
- 전역 추적이 끊겨도 로컬 정보를 이용해 모든 이동과 액션을 시간 제한 없이 계속한다.

## 설계 판단

- 기존 블록에 단순 오프셋만 추가하면 미니맵 창 이동, 목적지 길 찾기, 추적 상태를 한 모델에서 처리하기 어려워 좌표계와 실행 모델을 분리한다.
- 큰 지도 픽셀을 영구 저장 좌표로 사용하면 이미지 위 편집과 실행 좌표가 일치한다.
- 기존 `BlockRunner`의 입력 동작은 재사용하고 전역 목표를 실행 시점의 로컬 목표로 바꾸는 어댑터를 둔다.
- 사냥 영역과 이동 가능 연결을 분리해 사냥 구역 밖 이동을 허용하면서 자동 사냥 범위가 의도치 않게 넓어지는 것을 막는다.
- 반복 루트와 일회성 목적지 이동은 같은 노드·연결망을 공유한다.
- 추적 실패 시 계속 실행은 오차 누적 위험이 있지만 사용자 결정이므로 차단하지 않고 상태 표시로 구분한다.

## 주의사항

- 추정 좌표를 시간 제한 없이 사용하면 잘못된 위치에서 액션할 수 있다.
- 미니맵 배경에 반복 무늬가 많으면 창 원점 매칭이 다른 위치로 튈 수 있다.
- 두 기준점이 너무 가까우면 배율 오차가 크게 증폭된다.
- 기존 로컬 설정 자동 변환은 보정 당시 미니맵 창 원점이 정확해야 한다.
- 실제 구현 전에 큰 지도 이미지와 동일 지점 두 곳을 식별할 수 있는 실제 미니맵 화면이 필요하다.
