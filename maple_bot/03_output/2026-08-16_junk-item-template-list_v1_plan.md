# 기타템 템플릿 동적 목록 구현 계획

## 목표

- 자동화·운영 화면에서 `+` 버튼으로 기타템 행을 순차 추가한다.
- 각 행에서 게임창 이미지만 사용해 템플릿을 설정하거나 덮어쓴다.
- `−` 버튼으로 해당 파일을 삭제하고 뒤 번호를 앞으로 당긴다.
- 등록된 `item_N.png` 전체를 기타템 판매 대상으로 사용한다.

## 검증 기준

1. 파일이 없으면 행 없이 `+` 버튼만 표시된다.
2. `+`를 누르면 기타템 1부터 순차적으로 빈 행이 추가된다.
3. 템플릿 설정은 게임창 캡처의 선택 부분을 해당 번호에 저장하고 재설정 시 덮어쓴다.
4. 중간 행 삭제 시 뒤 파일과 행 번호가 연속 번호로 정리된다.
5. 판매 로직이 `item_1.png`를 포함한 모든 등록 템플릿을 사용한다.
