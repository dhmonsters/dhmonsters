# 사냥 영역 이미지 트리거 결정 기록

## 사용자 결정

- 영역들은 캐릭터를 기준으로 전개되므로 캐릭터가 사냥 영역 안에 있는지는 항상 참이다.
- 지정한 사냥 영역에서 특정 이미지를 검색한다.
- 이미지가 검출되면 특정 액션을 실행한다.

## 설계 해석

- 사냥 영역은 조건용 세계 좌표 구역이 아니라 화면 이미지 검색 ROI다.
- ROI 공급 방식은 기존 프로젝트의 사냥 영역 좌표 모델을 우선 재사용한다.
- 기존 모델이 없다면 최소한의 사각형 좌표 인터페이스만 추가한다.
- 이미지 액션은 별도 키 입력 코드를 만들지 않고 `ActionSpec`과 `ActionExecutor`를 재사용한다.

## 안전장치

- 유사도 임계값을 설정한다.
- 반복 검출에 대한 쿨다운을 설정한다.
- 템플릿 파일을 읽을 수 없으면 액션을 실행하지 않고 명확한 오류를 제공한다.

## 4~7단계 연결 결과

- 이미지 트리거 설정은 `attack.image_trigger`에 저장하고 ROI는 기존 `attack.hunt_area`를 재사용함.
- hunting tick에서 사냥 ROI만 캡처해 이미지 트리거를 실행함.
- 전역 지도 편집기에서 템플릿, 유사도, 감지 주기, 쿨다운과 액션 시간을 모두 편집함.
- 이미지 트리거 오류는 메인 사냥 루프를 중단하지 않고 감지 로그로 격리함.
- 전역 이동과 기존 층별 루트는 동시에 입력을 제어하지 않도록 상호 배제함.
- 최종 관련 회귀 테스트는 106개 통과함.
