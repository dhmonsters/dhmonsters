# 입력 시간 및 배포 정리 작업 기록

## 확정 결정

- 키 홀드시간은 설정값의 95~100%를 소수점 넷째 자리까지 한 번만 보정한다.
- 실행 간격과 반복 주기는 설정값의 95~105%를 소수점 넷째 자리까지 한 번만 보정한다.
- 검출 제한시간과 발판 확인시간 같은 로직 타임아웃은 랜덤화하지 않는다.
- 입력 백엔드와 사다리 우선 입력은 유지하되 Humanizer 명칭과 호환 객체는 제거한다.
- 연결 해제된 퍼즐·검증 도구와 중복 코드·자산은 배포에 포함하지 않는다.

## 조사 근거

- `Humanizer` 운영 인스턴스는 현재 생성되지 않는다.
- `plus_minus_5`는 2026-08-13 이중 랜덤 제거 커밋 이후 호출되지 않지만 UI 안내와 기존 의도는 간격의 최대 5% 랜덤 보정이다.
- 기존 빌드는 Python 모듈과 models·assets 등을 PyInstaller 데이터와 후속 xcopy로 중복 포함한다.

## 구현 및 검증 결과

- `core/input_timing.py`로 입력 홀드와 실행 간격 보정을 분리했다.
- 운영 입력 경로에서 `core/humanize` 의존성과 구형 전용 테스트를 제거했다.
- 퍼즐·검증 모듈은 통합 런타임과 UI에서 연결을 해제하고 배포 번들에서 제외했다.
- 제거된 구형 픽업 객체 호출을 공용 `pickup_tick()`으로 교체했다.
- 입력·런타임·빨코2 배포 대상 회귀 테스트 97개가 통과했다.
- 경량화 검증 빌드가 성공했으며 산출물은 약 240.1MB다.
- CUDA·ncnn·OCR 런타임·퍼즐 모듈·모델은 검증 번들에서 발견되지 않았다.
- `libscipy_openblas` 이름의 DLL은 SciPy 패키지가 아니라 NumPy가 포함한 필수 OpenBLAS DLL이다.
