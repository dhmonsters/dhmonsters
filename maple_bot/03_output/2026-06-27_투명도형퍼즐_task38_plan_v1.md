# Task 38 계획

## 목표
- 시간축 selector에 실제 background identity frame cost를 연결해 배경 데칼 후보를 감점한다.

## 범위
- GT는 채점에만 사용한다.
- 후보 생성은 늘리지 않는다.
- 기존 `_background_identity_signal.py`의 expected background ID 매칭을 재사용한다.

## 설계
- JSONL 후보를 `TemporalFrame`으로 변환할 때 optional expected background 후보를 받는다.
- 현재 후보가 한 바퀴 전 배경 후보와 매칭되면 `background_penalties`를 올린다.
- 매칭 비용이 낮을수록 더 강하게 감점한다.
- `_fast_gt_score.py`의 `score_clip`에서 clip 이름과 frame 범위를 알고 있으므로 expected background를 계산해 selector에 전달한다.

## 성공 기준
- background identity 후보 감점 테스트가 먼저 실패하고 구현 뒤 통과한다.
- 16GT에서 `temporal_identity`가 Task37의 2/16을 넘거나, 넘지 못하면 원인을 문서에 기록한다.
- 전체 puzzle 테스트와 문법 검사가 통과한다.
