# Claude v2.4.3 배포 기록

- 배포 대상 커밋은 빨코2 회수 루틴 단축, 도착 범위 정렬, 2층 근거리 텔레포트 허용, Y 좌표 UI 설정을 포함한다.
- 설치파일 이름은 `Claude_v2.4.3_Setup.exe`로 고정한다.
- 자동 업데이트 주소는 GitHub Release의 `v2.4.3/Claude_v2.4.3_Setup.exe`를 사용한다.
- 프로젝트 전체 테스트는 분리된 퍼즐·실험 모듈을 참조하는 기존 테스트 때문에 수집 단계에서 중단된다. 사용자가 승인한 대로 빨코2 관련 테스트, 구문 검사, 빌드·설치·실행 검증을 배포 기준으로 사용한다.
- 빌드나 설치 검증에서 오류가 발생하면 GitHub Release 게시 전에 중단한다.
- 2026-08-24 배포 직전 빨코2 관련 테스트 62개가 모두 통과했다.
- 변경된 실행 코드·테스트·메인 화면·업데이터의 Python 구문 검사가 통과했다.
- 버전 파일과 배포 스크립트는 UTF-8 엄격 디코딩 및 버전 일치 검사를 통과했다.
- 첫 빌드는 릴리스 브랜치에 `assets/claude_logo.ico`가 없어 시작 단계에서 중단됐다. 원본 프로젝트·v2.3.9 배포 원본·v2.4.1 설치본에서 SHA-256 `574FF08C05E2A400F618552390B93577E04D0A5EC857BA95EDECDB374C88215C`로 동일한 공식 아이콘임을 확인하고 복원했다.
- 재시도 시 릴리스 브랜치에 거탐 제목 템플릿과 64비트 Interception DLL도 빠진 사실을 확인했다. 원본·과거 배포본의 해시가 각각 `F5DB131909D34F58287C7312AEC14A0BF8FB26352789B61A97167AA4E094804C`, `AB88164C11B1B48488772D4C3BFAA4509D5B0AE9DBC5A691DC4F96F0260443C8`로 일치해 공식 파일을 복원했다.
