# 캐릭터 감지 연속성 수정 기록

- 진단에서 현재 3×2 템플릿, 전체 미니맵 최고 점수 우선 선택, 2프레임 급변 확정이 오검출 원인으로 확인됐다.
- 미니맵 영역과 사용자 좌표 보정은 변경하지 않는다.
- 기존 UI 파일에는 다른 작업 변경이 있어 이번 수정에서는 겹치지 않도록 감지기에서 작은 템플릿을 제외한다.
- 정상 추적 중에는 이전 위치 주변을 우선 검색하고, 주변 검색 실패 후 전체 영역 후보는 3회 연속 확인한다.
- 신규 테스트 3개는 기존 코드에서 각각 작은 템플릿 허용, 이전 위치 인자 미지원, 두 번째 급변 후보 조기 확정으로 실패했다.
- 수정 후 신규 테스트 3개를 포함한 캐릭터 감지 최종 테스트 23개가 통과했다.
- 합성 162×102 미니맵의 이전 위치 주변 탐색 200회 평균은 2.587ms였다.
- 오래된 `tests/test_runtime.py`의 실패 6개는 `humanizer`, `pickup`, 연속기 생성자 등 현재 런타임과 테스트의 기존 불일치이며 이번 변경 파일과 무관해 수정하지 않았다.
