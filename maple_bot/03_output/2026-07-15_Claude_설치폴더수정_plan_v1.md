# Claude 설치 폴더 수정 계획

## 목표

기존 설치 기록이 남아 있는 PC에서도 새 설치파일이 `Claude` 폴더만 사용하도록 수정한다.

## 원인

설치 프로그램 이름과 기본 폴더는 `Claude`로 변경됐지만 기존 제품과 같은 Inno Setup 설치 ID를 사용해 이전 설치 경로가 재사용됐다.

## 진행 순서

1. 기존 설치 ID를 `Claude` 전용 새 ID로 변경한다.
2. 이전 설치 폴더 재사용을 명시적으로 끈다.
3. 충돌 없는 `Claude_v2.1.5_Setup_v2.exe`를 생성한다.
4. 설치 스크립트 검사와 컴파일 결과를 확인한다.
5. 변경 파일과 검증 기록만 커밋한다.
