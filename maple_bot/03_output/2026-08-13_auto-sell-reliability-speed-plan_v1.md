# 자동판매 안정성·속도 개선 계획

## 목표

- 빨코2 자동판매 요청 시 현재 층에 맞게 상점 진입 위치까지 복구한다.
- 상점 진입층에서는 즉시 판매하고, 판매가 끝난 뒤에만 2층으로 복귀한다.
- 판매 위치 도착 이후 장비 일괄판매와 상점 종료를 정상 상태에서 약 5초 안에 끝낸다.
- 실행 중 변경된 자동판매 설정을 다음 판단부터 반영한다.

## 구현 순서

1. 층별 자동판매 진입과 실패 재현 테스트를 작성한다.
2. 템플릿 중복 탐색과 전체 모니터 캡처를 재현하는 테스트를 작성한다.
3. 최신 설정 반영과 실패 후 짧은 재시도 테스트를 작성한다.
4. 최소 코드로 테스트를 통과시킨다.
5. 관련 테스트, 컴파일, UTF-8, 변경 범위를 검증한다.
6. 승인된 릴리즈 체크리스트에 따라 버전 갱신, 빌드, 설치본 생성, GitHub 배포를 진행한다.

## 성공 기준

- 1층은 7번 계단 복구 후 2층 정렬 및 윗텔포한다.
- 2층은 X `123~136` 정렬 후 윗텔포한다.
- 상점 진입층은 텔포 없이 바로 판매한다.
- 정상 장비 판매 경로가 가상 시계 기준 5초 이내다.
- 같은 화면과 템플릿의 점수·좌표 계산은 한 번만 수행한다.
- 실패한 판매는 전체 판매 주기를 건너뛰지 않고 짧게 재시도한다.
