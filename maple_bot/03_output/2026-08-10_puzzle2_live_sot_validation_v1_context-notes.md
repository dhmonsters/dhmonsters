# Puzzle2 라이브 SOT 검증 컨텍스트

## 고정 결정

- 대상 코어는 `C:\Users\PC\Downloads\Telegram Desktop\1테스트\V6497_LIVE_ONE_SHOT_1280_SELF_CLEAN`이다.
- 받은 `START_HERE.cmd`는 실행하지 않는다.
- 외부 프로그램의 자동 설치, 네트워크 다운로드, 비밀번호, 자기삭제 기능은 사용하지 않는다.
- 첫 실행의 마우스 출력은 반드시 OFF다.
- 사용자가 UI 버튼으로 마우스 출력을 명시적으로 켜거나 끈다.
- 기존 `puzzle.py`와 사용자 변경 파일은 건드리지 않는다.

## 현재 분석

- 코어는 표준 Siamese SOT 라이브러리가 아니라 초기 흰색 검출, 배경 광학 흐름 정렬, 잔차 템플릿, 다중 가설, 신분 잠금을 결합한 시간축 추적기다.
- 라이브 코어는 1280x720 클라이언트와 `(396, 196, 488, 328)` 퍼즐 ROI를 사용한다.
- tracker row의 `center_x`, `center_y`는 클라이언트 기준 좌표다.
- 외부 `live_core.run_one_shot()`은 마우스가 항상 켜지는 구조이므로 직접 실행하지 않고 마우스 게이트가 있는 어댑터로 감싼다.

## 주의사항

- 삼각형 `.pt`는 신뢰되지 않은 pickle 가능성이 있으므로 일반 `torch.load()`를 그대로 호출하지 않는다.
- 현재 Git 작업 트리에 관련 없는 변경이 많으므로 새 파일만 다룬다.

## 구현 결과

- `puzzle2.py` 실행 시 실제 게임창의 고정 퍼즐 ROI를 CCTV로 표시한다.
- 최종 타겟은 초록색, H1~H3 후보는 주황색과 회색으로 표시한다.
- 솔버 시작·종료와 마우스 ON·OFF 버튼을 분리했다.
- 마우스는 항상 OFF로 시작하며, OFF 상태에서도 추적 계산은 계속된다.
- 현재 PC의 Torch `2.11.0+cu128`과 RTX 4060 CUDA 환경을 허용하되 CUDA 자체는 필수로 유지한다.
- 받은 삼각형 모델의 unsafe global 검사 결과는 빈 목록이었다.
- 세션에는 영상 대신 `events.jsonl`과 `summary.json`만 저장한다.
- 테스트 결과는 8개 통과다.
- 실제 GUI 프로세스가 기동되고 응답 중인 상태까지 확인했다.
