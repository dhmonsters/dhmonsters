# 투명도형 퍼즐 F1 F2 F3 런타임 계획

## 목표

F1, F2, F3의 역할을 분리한다.

- F1은 솔버 감시 ON이다.
- 퍼즐 도형이 감지되어 솔버가 작동할 때 녹화를 시작한다.
- F2는 솔버 정지다.
- F3은 녹화 종료다.

## 성공 기준

- F1을 눌러도 도형 감지 전에는 녹화 세션이 생성되지 않는다.
- 도형 감지 후에는 기존 무손실 녹화 세션이 시작된다.
- F2는 감시 대기 중이면 감시를 끄고, 녹화 중이면 솔버만 정지한다.
- F3은 녹화만 종료한다.
- UI 버튼과 전역 단축키가 같은 의미로 동작한다.
- 관련 자동 검증이 통과한다.

## 설계

기존 `LiveRecordingRuntime`은 유지하되, 앞단에 감시 게이트를 둔다. 감시 게이트는 화면을 주기적으로 캡처하고 고정 보드 ROI에서 퍼즐 도형 존재 여부를 판단한다. 도형이 보이면 그 프레임을 첫 프레임으로 기존 녹화 런타임을 시작한다.

UI는 `SOLVER_ON`, `RECORDING`, `SOLVER_STOPPED` 상태를 구분해서 표시한다.
