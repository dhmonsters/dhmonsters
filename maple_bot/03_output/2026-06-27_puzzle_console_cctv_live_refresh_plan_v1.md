# 퍼즐 콘솔 CCTV 실시간 갱신 계획.

## 목표.

F1로 솔버 감시가 켜진 상태에서 CCTV 영역이 고정 스크린샷처럼 멈추지 않고, 같은 preview 파일 경로가 계속 덮어써져도 최신 프레임을 표시하게 만든다.

## 원인 가설.

감시 루프는 `live_watch_preview.png`를 같은 경로에 반복 저장한다. 기존 UI는 preview 경로가 이전과 같으면 이미 표시한 화면으로 판단해서 로딩을 건너뛰었다. 그래서 실제 파일은 갱신되어도 CCTV 라벨의 Pixmap은 바뀌지 않았다.

## 수정 방향.

- preview 경로만 비교하지 않는다.
- 파일의 변경 시각과 크기를 함께 기록해서 실제 파일이 바뀌었는지 판단한다.
- PyQt 경로 기반 이미지 캐시를 피하기 위해 파일 바이트를 읽어 `QPixmap.loadFromData`로 표시한다.
- F1 감시 상태와 녹화 상태 모두 같은 preview 경로 갱신을 허용한다.

## 성공 기준.

- 같은 preview 파일 경로라도 내용이 바뀌면 UI Pixmap이 다시 갱신된다.
- F1 감시 상태에서 퍼즐 감지 전 CCTV preview가 계속 갱신된다.
- 감지 후 녹화 상태에서도 preview 표시가 깨지지 않는다.
