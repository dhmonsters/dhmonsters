# 구형 설치 모듈 잔존으로 인한 시작 오류 수정 계획

## 목표

- 구형 설치본의 `core_ui` 폴더가 남아도 시간 설정 키 불일치로 프로그램이 종료되지 않게 한다.
- 새 설치 시 더 이상 사용하지 않는 구형 소스 폴더를 제거한다.
- 실제 구버전 위에 새 버전을 설치하는 경로로 수정 결과를 검증한다.

## 구현 범위

1. 빨코2 시간 설정 UI는 실제 생성된 입력칸만 불러오고 복원한다.
2. Inno Setup 설치 시작 시 `{app}\core`, `{app}\core_ui`, `{app}\ui` 구형 폴더를 정리한다.
3. 미래 기본 설정 키가 UI보다 먼저 추가돼도 시작되는 회귀 테스트를 추가한다.
4. 구버전 설치 후 새 설치본 덮어쓰기와 시작 검사를 수행한다.

## 성공 기준

- 재현 테스트가 수정 전 실패하고 수정 후 통과한다.
- 관련 UI 및 배포 테스트가 통과한다.
- 구버전 설치 경로에서 구형 소스 폴더가 제거되고 새 앱 시작 검사가 성공한다.
