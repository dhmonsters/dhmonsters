# Claude v2.4.2 배포 작업 기록

## 기준과 범위

- 기준 태그는 `v2.4.1`이다.
- 릴리스 브랜치는 `codex/claude-v2.4.2-release`다.
- 반영 대상은 `4106d20` 빨코2 미검출·자동판매·미니맵 수정과 `1809349` 기타템 템플릿 동적 목록 수정이다.
- 현재 사용자 작업 브랜치의 다른 변경은 배포 범위에서 제외한다.

## 릴리스 설명

- 빨코2 미검출 시 마지막 이동 방향을 유지한다.
- 자동판매 안전지대 진입과 판매 후 2층 복귀를 확인한다.
- 미니맵 영역 재지정 내용을 활성 프리셋과 실행 중 스캐너에 즉시 반영한다.
- 기타템 템플릿을 `+`와 `−`로 관리하고 게임창 캡처에서 설정·덮어쓰기한다.

## 소스 구성 결과

- `v2.4.1` 태그에서 `codex/claude-v2.4.2-release` 브랜치를 만들었다.
- `4106d20`은 `b1b6ea3`, `1809349`는 `cb55061`로 충돌 없이 적용됐다.
- `version.txt`, `version.json`, `installer.iss`, `build.bat`을 모두 2.4.2로 통일했다.
- 설치파일 이름은 `Claude_v2.4.2_Setup.exe`로 설정했다.

## 소스 검증 결과

- 빨코2·자동판매·기타템·미니맵·페이지·설정 관련 테스트 75개가 통과했다.
- 변경된 Python 파일 문법 검사가 통과했다.
- 전체 `tests` 수집은 릴리스 브랜치에 없는 퍼즐 실험 보조 모듈과 기존 `RiskProfile` 참조 때문에 기존 오류 30건으로 중단됐다.
- 위 전체 수집 오류는 2.4.2 배포 대상 기능과 무관하므로 수정 범위에서 제외했다.

## 빌드 검증 결과

- `build.bat` 실행이 정상 완료됐고 `dist/Claude_2.4.2/Claude.exe`가 생성됐다.
- 패키지의 `version.txt`가 `2.4.2`임을 확인했다.
- 패키지에 빨코2 미검출 복구, 자동판매 안전 확인, 미니맵 영역 동기화, 기타템 동적 템플릿 코드가 모두 포함됐음을 확인했다.
- Inno Setup 컴파일이 정상 완료됐고 설치파일 이름은 `Claude_v2.4.2_Setup.exe`다.
- 설치파일 크기는 638,842,989바이트이며 SHA-256은 `EFDA3587064D5BD0E84BB5B63DCC41B32F9CE1EF31C2683C2FD11B2630F884EF`다.
