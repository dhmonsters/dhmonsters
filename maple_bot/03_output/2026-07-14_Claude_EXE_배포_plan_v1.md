# Claude EXE 배포 계획

## 목표

현재 통합 실행 경로와 B 방식 전역 지도 기능을 Python이 없는 다른 PC에서 실행할 수 있는 `Claude` 설치 파일로 패키징한다.

## 진행 순서

1. 프로그램 화면과 빌드·설치 설정의 기존 제품명을 `Claude`로 통일한다.
2. PyInstaller 진입점을 `run_integrated.py`로 지정한다.
3. 템플릿, 몬스터 이미지, 모델, 자산, 설정, 버전 파일을 독립 실행 폴더에 포함한다.
4. 관련 회귀 테스트를 실행한다.
5. 포터블 실행 폴더를 빌드하고 EXE 기동을 점검한다.
6. Inno Setup으로 `Claude_v2.1.5_Setup.exe`를 생성한다.
7. 산출물과 변경 파일을 검토하고 의미 단위로 커밋한다.

## 성공 기준

- 다른 PC에 Python이 없어도 설치 후 `Claude.exe`를 실행할 수 있다.
- 최신 통합 UI와 B 맵핑 모듈이 빌드에 포함된다.
- 기존 사용자 변경과 과거 배포물을 덮어쓰지 않는다.
