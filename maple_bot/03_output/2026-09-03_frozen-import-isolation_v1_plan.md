# 배포 실행파일 모듈 경로 격리 계획

## 목표

- 설치 폴더에 과거 Python 모듈이 남아도 배포 실행파일이 이를 불러오지 않게 한다.
- 업데이트 시 `_internal`을 통째로 교체하여 구형 모듈과 DLL이 남지 않게 한다.

## 구현 범위

1. 배포 실행에서는 `sys._MEIPASS`만 Python 모듈 검색 경로로 사용한다.
2. 소스 실행에서는 기존 프로젝트 루트 검색 동작을 유지한다.
3. 설치 시작 시 `{app}\_internal`을 제거한 뒤 새 묶음을 설치한다.
4. 구형 루트 모듈이 남은 배포 환경에서 실제 시작 검사를 수행한다.

## 성공 기준

- 배포 경로 선택 회귀 테스트가 수정 전 실패하고 수정 후 통과한다.
- 관련 테스트와 새 실행파일 빌드가 통과한다.
- 구형 모듈을 남긴 설치 경로에 덮어쓰기 후 실제 Qt 셸 시작이 성공한다.
