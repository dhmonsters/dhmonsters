# Task 18 Implementation Plan

## 목표
Trace 이벤트의 흐름을 UI 하단 timeline에 짧게 누적 표시한다.

## 설계
`PuzzleConsoleWindow`에 최근 trace 이벤트 텍스트 목록을 두고, `apply_trace_event()`가 후보, 근거, 정체성 상태 이벤트를 간결한 한 줄로 추가한다. 화면에는 최근 5개만 보여주어 오래 실행해도 UI가 과하게 길어지지 않게 한다.

## 변경 파일
- `maple_bot/ui/puzzle_console.py`.
- `maple_bot/tests/test_puzzle_console_smoke.py`.

## 검증 기준
- Timeline detail 라벨의 objectName은 `puzzleTimelineDetail`이다.
- `CANDIDATES`, `EVIDENCE`, `IDENTITY_STATE` 이벤트가 프레임 번호와 함께 표시된다.
- 최근 5개만 유지된다.
