# Task 32 계획

## 목표
- 실전 라이브 리허설이 가능하도록 `puzzle.py`에서 실제 화면 녹화를 시작하고 F3로 종료할 수 있게 한다.

## 범위
- `LiveRecordingRuntime`을 추가해 현재 화면을 캡처하고 고정 ROI 기반 세션 녹화를 만든다.
- UI의 `화면 감시` 버튼을 라이브 녹화 시작에 연결한다.
- 기존 `녹화 종료 F3` 버튼과 F3 경로가 라이브 녹화를 종료하게 한다.
- CLI 비상 진입점 `--live-record`와 검증용 `--live-max-frames`를 추가한다.
- 자동 마우스 입력과 CAPTCHA 우회 동작은 넣지 않는다.

## 제외
- 프로그램 강제 종료 후에도 계속 녹화되는 별도 프로세스 구조는 만들지 않는다.
- 실시간 솔버 판정과 마우스 이동은 이번 범위에 넣지 않는다.

## 검증
- 가짜 캡처 프레임으로 라이브 녹화가 MKV 3종과 trace/report를 생성하는지 테스트한다.
- 솔버 중지 상태에서도 라이브 녹화 프레임이 계속 쓰이는지 테스트한다.
- UI `화면 감시` 버튼이 start handler를 호출하고 세션 폴더를 기억하는지 테스트한다.
- CLI `--live-record --live-max-frames`가 runtime을 호출하는지 테스트한다.
- 전체 puzzle 테스트와 실제 제한 프레임 라이브 녹화 dry-run을 확인한다.
