# 자동판매 안정성·속도 개선 작업 메모

- 5초 목표는 빨코2 이동 시간을 제외하고 상점 진입층 도착 이후부터 측정한다.
- 상점 진입층에서는 아랫텔포하지 않고 즉시 판매하며, 판매 종료 후 2층으로 복귀한다.
- 1층에서는 기존 7번 계단 복구를 자동판매 전용 실행 상태에서도 사용할 수 있게 한다.
- 기존 런타임은 시작 시 복사한 자동판매 설정을 계속 사용해 UI 변경이 즉시 반영되지 않는다.
- 판매 준비 실패도 `finally`에서 전체 주기를 다시 예약해 한 주기를 건너뛰는 문제가 있다.
- 기존 화면 인식은 전체 가상 모니터를 캡처하고 같은 템플릿을 점수와 위치 계산으로 두 번 매칭한다.
- 인벤토리 템플릿이 한 번 미감지되면 `I`를 눌러 이미 열린 인벤토리를 닫을 수 있다.
- 기타템 판매가 켜진 경우 아이템 수와 스크롤 횟수에 따라 5초를 넘을 수 있다. 5초 기준은 장비 일괄판매 경로다.
- 기존 미추적 설치본, 진단 폴더와 로그는 수정하거나 커밋하지 않는다.
- 상점 진입 위치는 Y뿐 아니라 X `123~136`도 함께 확인해 같은 높이의 16번·27번 발판과 구분한다.
- 회수 중 상단 발판은 아랫텔포로 2층에 복구한 뒤 판매 위치를 정렬한다.
- 장비 일괄판매 버튼 미감지는 성공으로 처리하지 않고 실패 및 5초 후 재시도로 전환한다.
- 정상 장비 판매 가상 시계 테스트는 5초 제한을 통과했다.
- 관련 통합 테스트는 `72 passed, 9 warnings`이며 경고는 기존 `mss.mss` deprecation 경고다.
- 전체 테스트 수집은 기존 `RiskProfile`을 가져오는 구형 테스트 2개 때문에 중단된다. 이번 변경과 무관한 기존 정합성 문제다.
- `compileall`은 `core`, `core_ui`, `run_integrated.py`, `main.py`에서 통과했다.
- 버전 필수 파일 `version.txt`, `version.json`, `installer.iss`, `build.bat`을 모두 `2.3.11`로 맞췄다.
- PR #7을 원격 `main`에 병합해 자동 업데이트가 읽는 `main/maple_bot/version.json`을 먼저 갱신했다.
- PyArmor와 PyInstaller 빌드가 성공했고 배포 설정은 Python JSON 파싱, UTF-8 한글, 민감정보 제거 검증을 통과했다.
