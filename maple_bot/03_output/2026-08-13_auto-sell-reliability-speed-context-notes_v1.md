# 자동판매 안정성·속도 개선 작업 메모

- 5초 목표는 빨코2 이동 시간을 제외하고 상점 진입층 도착 이후부터 측정한다.
- 상점 진입층에서는 아랫텔포하지 않고 즉시 판매하며, 판매 종료 후 2층으로 복귀한다.
- 1층에서는 기존 7번 계단 복구를 자동판매 전용 실행 상태에서도 사용할 수 있게 한다.
- 기존 런타임은 시작 시 복사한 자동판매 설정을 계속 사용해 UI 변경이 즉시 반영되지 않는다.
- 판매 준비 실패도 `finally`에서 전체 주기를 다시 예약해 한 주기를 건너뛰는 문제가 있다.
- 기존 화면 인식은 전체 가상 모니터를 캡처하고 같은 템플릿을 점수와 위치 계산으로 두 번 매칭한다.
- 인벤토리 템플릿이 한 번 미감지되면 `I`를 눌러 이미 열린 인벤토리를 닫을 수 있다.
- 기타템 판매가 켜진 경우 아이템 수와 스크롤 횟수에 따라 5초를 넘을 수 있다. 5초 기준은 장비 일괄판매 경로다.
- 기존 미추적 설치본, 진단 폴더와 로그는 수정하거나 커밋하지 않는다.
