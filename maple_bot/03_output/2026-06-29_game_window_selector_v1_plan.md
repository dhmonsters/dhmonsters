# 2026-06-29 게임창 선택기 수정 계획 v1

## 목표
- `puzzle.py` CCTV가 도구 UI 창이 아니라 실제 게임 client 창을 캡처하게 만든다.
- 캡처 기준 창과 마우스 클릭 기준 창이 같은 선택기를 쓰게 만든다.

## 성공 기준
- 작은 `거짓말탐지기`, `감지 영역`, `solver/noauth` 도구 UI 창은 게임창 후보에서 제외된다.
- 충분히 큰 `MapleStoryClass`, `UnityWndClass`, `NEXON Plug-in Window` 계열 게임창이 우선 선택된다.
- 기존 라이브 CCTV, 마우스 이동, 16GT 시간축 판별기 검증이 깨지지 않는다.

## 진행 순서
- 기존 창 찾기 함수가 너무 넓은 키워드로 후보를 고르는 원인을 확인한다.
- 게임창 전용 선택기를 추가한다.
- 라이브 캡처와 마우스 브릿지가 같은 선택기를 사용하게 연결한다.
- 테스트와 16GT 검증을 실행한다.
