# 현재 설치 버전 복구본 보관 계획

## 목표

- 업데이트 직전 PC에 설치되어 있던 버전의 설치파일을 그대로 복구본으로 보관한다.
- 특정 안정 버전으로 강제 치환하지 않는다.

## 구현

1. 설치된 `version.txt`에서 현재 버전을 읽는다.
2. 현재 버전과 새 설치 버전이 다를 때 현재 버전의 공식 GitHub Release 설치파일을 내려받는다.
3. 내려받은 파일의 SHA-256을 계산하고 복구 폴더에 복사한다.
4. 현재 버전, 새 버전, 설치 경로, SHA-256을 `recovery.json`에 기록한다.
5. 저장된 파일의 SHA-256을 다시 확인한 뒤에만 업데이트를 계속한다.

## 검증

- 2.4.1, 2.4.5, 2.4.8이 각각 자기 버전의 URL과 파일명으로 선택되는지 확인한다.
- 동일 버전 재설치와 신규 설치에서는 복구본 다운로드를 생략하는지 확인한다.
- Inno Setup 테스트 설치기 컴파일과 자동 검증을 실행한다.
