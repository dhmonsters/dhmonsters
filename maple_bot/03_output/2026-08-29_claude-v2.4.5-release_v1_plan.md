# Claude v2.4.5 배포 계획

## 목표

최신 Claude v2.4.4 배포 소스에 빨코2 복귀 타이밍과 일반 추락 회수 개선을 반영하고 Claude v2.4.5 설치 파일과 GitHub Release를 게시한다.

## 순서

1. 기능 커밋 `ebf8e08`을 2.4.4 배포 브랜치에 반영한다.
2. 빨코2 관련 테스트와 Python 구문 검사를 실행한다.
3. `version.txt`, `version.json`, `installer.iss`, `build.bat`를 2.4.5로 갱신한다.
4. 변경을 커밋하고 배포 브랜치에 푸시한다.
5. `build.bat`과 Inno Setup으로 `Claude_v2.4.5_Setup.exe`를 생성한다.
6. 설치 파일 내용과 버전을 검증한다.
7. GitHub Release `v2.4.5`를 게시하고 자동 업데이트 메타데이터를 확인한다.
