# 캡처 드래그 해제 초기화 수정 작업 기록

## 확인된 원인

- 드래그 중 마지막 위치는 시작점과 다른 유효한 좌표로 기록된다.
- 일부 Windows/DPI 환경에서는 마우스 해제 이벤트 좌표가 시작점으로 돌아온다.
- 기존 코드는 해제 좌표로 마지막 위치를 무조건 덮어써 선택 영역을 1×1로 만든다.
- 선택 영역 최소 크기 검사에서 거부되므로 창이 닫히지 않고 반복 드래그처럼 보인다.

## 수정 결정

- 마지막 위치가 시작점과 다르고 해제 좌표만 시작점인 경우 마지막 위치를 보존한다.
- 이동 이벤트가 없었던 경우에는 해제 좌표를 사용해 기존 수정 동작을 유지한다.
- 정상 해제 좌표가 들어오면 해당 좌표를 그대로 사용한다.
