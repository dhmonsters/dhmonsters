# Puzzle2 GT 1030 전용 포터블 컨텍스트

## 고정 결정

- GT 1030 직접 검사 결과는 PASS였다.
- `sm_61`, 전용 VRAM 4,095.9MB, 여유 3,373.7MB, 512MB 할당 성공을 확인했다.
- 기존 Torch 2.11.0+cu128은 `sm_75` 이상만 포함하므로 사용하지 않는다.
- 공식 CUDA 11.8 Torch 중 `sm_61`을 실제 포함한 버전만 채택한다.
- 기존 RTX 4060용 ZIP과 소스 동작은 변경하지 않는다.
- 마우스는 항상 OFF로 시작한다.
- 공유 GPU 메모리 8GB는 성능 기준에 포함하지 않는다.
- 임시 가상환경과 빌드 중간 산출물은 최종 검증 후 삭제한다.

## 환경

- Python 3.12.13 64비트 런타임을 사용할 수 있다.
- 실제 빌드 직전 C 드라이브 여유 공간은 6.64GiB였다.

## 검증 결과

- 채택 런타임은 `torch 2.5.1+cu118`이다.
- Torch 아키텍처 목록에 `sm_61`이 포함됐다.
- V6497 `triangle_guard_v6496.pt`가 CUDA에 로드되어 실제 추론값을 반환했다.
- 첫 패키지 자체 검사는 `unittest` 제외 때문에 실패했다.
- Torch 2.5.1이 시작 과정에서 `unittest.mock`을 사용하므로 제외 규칙을 제거했다.
- 수정 후 패키지 자체 검사와 GUI 12초 기동 검사를 통과했다.
- 최종 ZIP 크기는 2,698,817,046바이트다.
- 최종 SHA-256은 `AC4781792DECA416267B8DD48AD3CAE596067C5ECA2524A456CFF7A1DB8DC957`이다.
