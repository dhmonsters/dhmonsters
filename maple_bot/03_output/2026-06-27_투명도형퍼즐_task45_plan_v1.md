# Task45 계획

## 목표

`RELEASE_PENDING`을 항상 열지 않고, track hint와 예측 위치가 과하게 충돌하지 않을 때만 열도록 gate를 추가한다.

## 판단 근거

- 111417은 보류 상태를 낮은 비용으로 열면 평균 오차가 크게 줄었다.
- 044401은 같은 설정에서 초반부터 잘못된 가지가 살아남아 크게 악화됐다.
- 두 판의 차이는 보류 후보 자체보다, track과 예측이 크게 벌어진 가짜 가지에 보류 후보가 공급되는지 여부다.

## 작업 순서

1. `prediction_hold_track_gate` 테스트를 먼저 추가한다.
2. RED 실패를 확인한다.
3. `_temporal_identity_selector.py`에 gate helper를 추가한다.
4. 16GT를 다시 채점한다.
5. 결과를 task45 문서에 기록하고 커밋한다.

## 성공 기준

- 기존 단위 테스트가 통과한다.
- 새 gate 테스트가 통과한다.
- 기본 16GT 점수는 기존 6/16을 깨지 않는다.
- opt-in gate 실험에서 044401 악화가 줄어드는지 확인한다.
