# 누락 캐릭터 템플릿 경고 제거 계획

## 목적

- 캐릭터 템플릿이 없을 때 OpenCV 파일 읽기 경고가 반복되지 않게 한다.
- 현재 정책대로 사용자 캐릭터 템플릿은 `y_p.png` 한 개만 사용한다.
- 템플릿이 없으면 기존 색상 감지 대체 동작을 유지한다.

## 변경 범위

1. 템플릿 로더가 `y_p.png`만 검색하게 한다.
2. 후보 파일이 실제로 존재할 때만 `cv2.imread`를 호출한다.
3. 사용자 템플릿 우선순위와 캡처 후 재로딩 동작은 유지한다.
4. EXE 빌드와 배포는 수행하지 않는다.

## 검증 기준

- 누락 파일에는 OpenCV 읽기가 호출되지 않는다.
- 구형 `r_p.png`는 로드되지 않는다.
- 사용자 `y_p.png`가 번들 파일보다 우선한다.
- 관련 테스트와 Python 구문 검사가 통과한다.
