# 빨코2 미검출·자동판매·미니맵 정렬 수정 계획

## 목표

빨코2에서 캐릭터가 잠깐 미검출되어도 진행 방향을 짧게 유지하고, 자동판매는 안전지대 도착을 확인한 뒤 실행하며, 새로 지정한 미니맵 영역을 프리셋과 실행 중 스캐너에 동일하게 반영한다.

## 변경 범위

1. 빨코2 이동 중 좌표 미검출 시 마지막 좌우 진행 의도를 최대 0.8초 유지한다.
2. 자동판매 진입과 복귀 텔포 뒤 실제 층 도착을 확인하고 실패 시 제한된 횟수만 재시도한다.
3. 자동판매 복귀용 아래키 선행 유지시간을 0.30초로 적용한다.
4. 미니맵 영역 지정 시 현재 사냥터 프리셋의 미니맵 값도 함께 저장한다.
5. 영역 지정 직후 실행 중 스캐너와 미리보기가 새 영역을 사용하도록 연결한다.
6. 캐릭터 위치 X/Y 보정값과 빨코2 이동 좌표값은 변경하지 않는다.

## 검증 기준

- 미검출 구간에도 마지막 좌우 방향이 0.8초 이내 유지된다.
- 위 텔포 실패 시 안전지대가 아닌 곳에서 판매가 시작되지 않는다.
- 판매 후 아래 텔포는 0.30초 선행 입력을 사용하고 2층 도착을 확인한다.
- 빨코2 미니맵 원본 좌표와 비율 좌표가 함께 저장된다.
- 실행 중 스캐너 영역과 미리보기 영역이 지정 직후 일치한다.
- 관련 빨코2·자동판매·프리셋·미니맵 테스트가 통과한다.
