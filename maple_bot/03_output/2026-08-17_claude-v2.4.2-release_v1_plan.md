# Claude v2.4.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Claude 2.4.1을 기준으로 최신 빨코2 안정화와 기타템 템플릿 관리 기능을 포함한 Claude v2.4.2 설치파일을 검증하고 배포한다.

**Architecture:** `v2.4.1`에서 분기한 전용 릴리스 브랜치에 검증된 두 기능 커밋만 적용한다. 버전 메타데이터와 빌드 경로를 2.4.2로 통일한 뒤 PyArmor·PyInstaller·Inno Setup 순서로 빌드하고, GitHub Release와 `main`의 업데이트 메타데이터를 게시한다.

**Tech Stack:** Python 3.14, PyQt6, pytest, PyArmor, PyInstaller, Inno Setup 6, GitHub CLI.

**Spec:** 사용자 승인 릴리스 계획과 `AGENTS.md`의 maple_bot 버전 릴리스 체크리스트.

## Global Constraints

- 설치파일 이름은 `Claude_v2.4.2_Setup.exe`다.
- `version.txt`, `version.json`, `installer.iss`, `build.bat`을 모두 2.4.2로 갱신한다.
- 현재 사용자 작업 폴더의 다른 변경은 포함하지 않는다.
- 결과 설치파일과 SHA-256 기록은 `maple_bot/03_output`에 둔다.
- 기존 클라이언트 업데이트 확인을 위해 GitHub `main/maple_bot/version.json`을 2.4.2로 갱신한다.
