# 투명 도형 YOLO 라벨링 가이드 (2단계 — 수동 라벨링)

> 작성 2026-06-10. 대상: `dataset/raw/` 캡처 이미지. 정책 근거: 업체(planet v2) 역분석 — YOLOv8n 1클래스로 샘플 영상 94% 탐지 검증됨.

## 핵심 정책 5가지

### 1. 타겟 도형만 라벨링한다
- 우리가 쫓는 그 도형 하나만. 흰색 → 반투명 → 완전투명 **전 단계 모두** 라벨.
- 가장 가치 있는 건 반투명·완전투명 프레임 (지금 추적이 실패하는 구간).
- **도형 위치를 확신할 수 없는 프레임은 라벨하지 말 것** — 라벨 없는 이미지는 빌더가 자동 제외하므로 그냥 건너뛰면 됨. 추측 라벨이 가장 해롭다.

### 2. 배경 도형은 라벨링하지 않는다
- YOLO는 박스가 없는 영역을 자동으로 "검출하면 안 되는 것"으로 학습한다.
- 배경 글라스 마크를 안 그리는 것 자체가 "배경은 무시하라"는 학습 신호.

### 3. 마우스 포인터는 라벨링하지 않는다
- 단, **커서가 도형을 가리고 있어도 도형 박스는 반드시 그린다.**
- 실전에서는 커서가 항상 도형 위에 있으므로, 커서에 가려진 도형이 핵심 학습 데이터다.

### 4. 클래스는 1개("shape")로 통합한다
- 원/세모/네모/별 구분하지 않는다. 봇은 박스 중심 좌표만 사용.
- 4클래스로 나누면 데이터가 4분의 1로 쪼개져 손해만 본다.

### 5. 박스는 글라스 림 기준 타이트하게
- 도형 테두리(글라스 림) 바깥에 딱 맞게, 대략 60px 내외.
- 화면 가장자리에 일부 잘린 도형은 보이는 부분만 박스.

## 분량·다양성 가이드

- 목표 **800~1500장** (라벨 기준).
- 연속 캡처(초당 15~18장)는 거의 같은 그림 — **3~5장 간격으로 골라** 라벨하는 게 효율적.
- 4종 도형(원/세모/네모/별) 골고루, 중앙·벽 근처 등 다양한 위치 포함.
- 한 게임 세션 편중 방지 — 여러 판 캡처 권장 (`tools/shape_capture.py --live --every 0.05 --tag live2` 처럼 tag만 바꿔서).

## 라벨링 도구

### labelImg (1순위)
```
pip install labelImg
labelImg dataset\raw
```
1. 좌측 메뉴에서 저장 포맷을 **YOLO**로 변경 (PascalVOC 아님!)
2. `W` = 박스 그리기, `D` = 다음 이미지, `A` = 이전 이미지
3. 클래스 이름은 항상 `shape` 하나만 사용
4. 저장하면 이미지 옆에 같은 이름의 `.txt` 생성됨

> 설치 실패 시(파이썬 버전 호환 문제) 대안: 웹 도구 [makesense.ai](https://www.makesense.ai) — 설치 불필요, 이미지 올려서 라벨 후 "Export → YOLO" 받아 `dataset/raw/`에 txt를 같은 파일명으로 넣으면 됨.

## 전체 진행 순서

```
1. (필요 시 추가 캡처)  python tools/shape_capture.py --live --every 0.05 --tag live2
2. 라벨링               labelImg dataset\raw   (이 문서 정책대로)
3. 데이터셋 생성        python tools/shape_dataset.py
4. 학습 환경            pip install ultralytics
5. 학습 + 변환          python tools/shape_train.py
   → models/shape_yolo.param/.bin 자동 배치 → 봇이 자동 로드
6. 오프라인 검증        python _test_yolo_track.py
7. 인게임 테스트        python planet_solver_noauth.py
```
