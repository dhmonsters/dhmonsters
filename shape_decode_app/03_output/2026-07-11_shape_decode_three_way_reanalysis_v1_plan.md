# Shape Decode 3자 재분석 계획

## 목적

원본 녹화 영상을 유일한 정답 기준으로 삼아 현재 Python 프로그램과 Claude WebGL 프로그램을 동일한 항목으로 비교한다. 이전 구현 과정에서 사용자 설명과 추측이 뒤섞인 부분을 걷어내고, 다음 구현에 바로 사용할 수 있는 자연어 명세를 확정한다.

## 비교 대상

1. `Downloads/녹화_2026_07_09_00_28_18_662_trim.mp4`
2. `shape_decode_app`
3. `.claude/worktrees/video-file-analysis-7e6ee6/lie_captcha_studio`

## 진행 순서

1. 세 대상의 구조와 상태 전환을 확인한다.
2. 영상의 초기·Sample·Play·회전·이동·투명화 구간을 프레임별로 분리한다.
3. 배경, 배경 도형, 타겟, 조작 UI를 항목별로 비교한다.
4. 차이가 생긴 원인을 구현 구조까지 추적한다.
5. 영상 복제용 자연어 명세와 다음 작업 우선순위를 작성한다.

## 완료 기준

- 배경, 배경 도형, 타겟의 역할이 서로 섞이지 않는다.
- 영상에서 확인된 사실과 사용자 요청에 의해 변경된 목표를 구분한다.
- 세 구현의 장단점과 재사용할 부분을 근거와 함께 정리한다.
- 다음 구현에서 검증할 수 있는 수치와 상태 전환 조건을 명시한다.
