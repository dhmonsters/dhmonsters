# Studio 독립 강체 신호 구현 계획

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

GT는 실행 중 정답 선택에 사용하지 않고, 실행이 끝난 뒤 측정과 원인 분류에만 사용한다.

## 확인된 문제

- 현재 `motion_divergence`와 `rigid_violation`은 완전히 같은 값이다.
- `phase_similarity`는 `1 - motion_divergence`라서 세 심판이 사실상 하나다.
- 기존 970점 선택기는 `rigid_violation`을 직접 사용하므로 의미를 바로 바꾸면 기준선도 함께 흔들린다.

## 구현 순서

1. `CandidateEvidence`에 `local_rigid_residual` 그림자 값을 추가한다.
2. 현재 프레임 후보 박스와 전역 배경 이동으로 되돌린 이전 프레임 박스를 비교한다.
3. 밝기 자체보다 국소 경계와 질감의 차이를 비교한다.
4. 새 값은 trace에 기록하되 기존 선택 비용에는 연결하지 않는다.
5. 고정 seed 10판을 다시 실행한다.
6. selector 오류 프레임에서 정답 가설과 오답 선택을 얼마나 구분하는지 측정한다.
7. 판별력이 확인될 때만 제한된 전환 규칙에 연결한다.

## 성공 기준

- 기존 선택 결과를 바꾸지 않는 그림자 측정 단계가 먼저 통과한다.
- 새 값이 `motion_divergence`와 완전히 같지 않아야 한다.
- selector 오류 211프레임에서 정답 가설을 지지하는 비율과 평균 차이가 기존 texture/merge보다 좋아야 한다.
- 실제 선택기에 연결한 뒤에는 고정 seed 970점보다 낮아지면 채택하지 않는다.

## 구현 결과

- `CandidateEvidence`와 trace에 `local_rigid_residual`을 추가했다.
- 기존 운동·강체·phase 신호와 독립된 값임을 확인했다.
- 고정 시드 그림자 A/B에서 `1019 → 1121`, 회귀 0을 기록했다.
- 실제 `puzzle.py`의 현재 Studio A/B에서 `1009 → 1110`, 회귀 0을 기록했다.
- 선택 기준은 잔차 0.20, 이득 0.121, 경로 분리 30px로 고정했다.
- 기존 16GT는 16/16을 유지했다.
- 다음 우선순위는 147프레임의 hypothesis generation 오류다.
