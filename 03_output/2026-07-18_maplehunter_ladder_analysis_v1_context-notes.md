## 2026-07-18 확인 결과

- 프로그램은 사다리 형상을 화면에서 자동 검출하지 않는다. 사용자가 좌표 HUD로 `x`, `y_top`, `y_bot`을 미리 기록한다.
- 캐릭터 위치는 선택된 미니맵 영역을 MSS로 캡처하고 BGR 영상을 HSV로 변환한 뒤, 면적 3~100픽셀인 노란 윤곽선 중 가장 큰 것의 무게중심으로 얻는다.
- 위치는 50ms마다 갱신되며, 사다리 동작은 아래층·위층·애매한 위치의 세 경우로 나뉜다.
- 애매한 위치에서는 사다리 X 방향으로 접근하다가 오차 ±4픽셀에서 점프와 위 키를 함께 눌러 붙잡는다.
- 등반 중에는 약 50ms마다 Y를 확인하고 목표 높이의 ±2픽셀에 들어오면 입력을 해제한다. 최대 제한 시간은 30초다.
- 아래층에서는 위 키 유지 등반을 사용하고, 위층에서는 아래 키를 1초 누른 뒤 이탈 방향과 점프를 조합한다.
- 입력 계층은 Interception을 사용할 수 있으면 PyAutoGUI 입력을 커널 필터 입력으로 교체하고, 사용할 수 없으면 확장 방향키 스캔 코드 보정이 있는 대체 경로를 사용한다.
- 즉시 재시도 횟수나 별도의 사다리 붙잡힘 영상 판정은 확인되지 않았다. 성공은 주로 좌표 변화로 간접 판단한다.
- 노란 윤곽선 오인식, 오래된 좌표 유지, 고정 임계값의 미니맵 축척 의존성이 주요 한계다.
