# 병합-분리 배경 상대 좌표 체크리스트

## 설계 고정

- [x] 고정 목적과 GT 사용 제한을 명시한다.
- [x] 부분 병합과 완전 병합을 모두 다루는 상태기계를 정의한다.
- [x] 배경 상대 좌표 수식과 적응형 오차를 정의한다.
- [x] 상대 좌표와 local rigid의 중복 투표를 금지한다.
- [x] 보류·기권·후보 부족의 의미를 분리한다.

- [ ] 사용자가 작성된 설계 문서를 검토한다.

- [ ] 평행 이동 불변성 테스트를 작성한다.
- [ ] 회전 불변성 테스트를 작성한다.
- [ ] 균일 확대 불변성 테스트를 작성한다.
- [ ] 배경 상대 좌표가 깨지는 타겟 자식 테스트를 작성한다.
- [ ] 기준점 1개·0개에서 보류·기권하는 테스트를 작성한다.
- [ ] 경계에서 잘린 기준점을 기권하는 테스트를 작성한다.
- [ ] 부분 병합과 완전 병합 상태 전환 테스트를 작성한다.

- [ ] 최소 3개 유효 관측 전에는 확정하지 않는 테스트를 작성한다.
