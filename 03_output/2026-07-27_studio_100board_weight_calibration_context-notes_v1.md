# Studio 100판 공통 가중치 보정 컨텍스트 노트

## 2026-07-27 고정 결정

- 고정 목표는 처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기다.
- 현재 심판의 핵심 임무는 겹친 두 도형이 다시 분리될 때 타겟을 정확히 구분하는 것이다.
- 준비시간에는 타겟 경로가 아니라 배경 흐름을 학습한다.
- 분리 후 배경 모델로 설명되는 후보를 제거하고 남은 후보를 타겟으로 복원한다.
- 타겟 움직임은 순간이동처럼 물리적으로 불가능한 후보를 제거하는 약한 제한으로만 쓴다.
- 각 판의 GT 기반 가중치 조율은 공통 세팅을 찾기 위한 오프라인 연구에만 사용한다.
- 런타임에는 판별마다 다른 세팅을 사용하지 않는다.
- 100판은 10겹 교차검증으로 90판 보정과 10판 대조를 번갈아 수행한다.
- 비교 세팅은 평균형, 효율형, 고확률형 세 가지다.
- 1차 평가는 겹침 후 타겟 역할 복원 정확도다.
- 전체 판 끝까지 추적 성공률은 2차 평가다.
- `SAFE_HOLD`는 오답 전환과 별도로 집계하지만 전체 추적 통과에서는 실패다.
- 최종값을 잠근 뒤 새로운 seed 100판에서 GT 없이 실행하고 종료 후에만 채점한다.

## 과적합 방지 규칙

- 특정 좌표, 방향, 프레임, 사건 번호를 규칙에 넣지 않는다.
- 같은 판을 공통값 생성과 대조 평가에 동시에 사용하지 않는다.
- 개별판 최적값의 단순 평균 대신 성공 가능한 영역과 최소 점수 차이를 사용한다.
- 후보 누락과 selector 오판을 분리한다.
- 실패가 나오면 가중치부터 바꾸지 않고 실패 단계를 먼저 분류한다.

## 기존 기반

- Studio는 seed 기반 랜덤판, GT export, batch 실행을 지원한다.
- `puzzle.py --studio-auto-validate`는 Studio와 lockstep으로 같은 프레임을 처리한다.
- 기존 하네스는 마우스 출력을 끄고 solver trace와 GT를 사후 비교한다.
- 현재 구현은 대표 identity-risk Gate에서 `premerge_identity_untrusted`로 사건 생성 전에 막힌 기록이 있다.
- 따라서 새 보정기는 selector 가중치뿐 아니라 사건 감지와 후보 생성 상한을 먼저 보여줘야 한다.

## 다음 구현 단계

1. 사건 단위 데이터 계약과 GT 격리 테스트를 작성한다.
2. 판별 심판의 원시 특징과 가용 상태를 trace에 남긴다.
3. 개별판 성공 영역과 세 공통 세팅을 계산한다.
4. 10겹 교차검증으로 일반화 결과를 비교한다.
5. 최종값을 잠그고 새 100판 GT 비공개 검증을 실행한다.

## 2026-07-27 구현 계획 승인 후 결정

- 구현은 배경 심판 계약, 비대칭 역할 복원, 사건 데이터셋, 공통 프로필 탐색, 교차검증, 잠금 검증 순서로 나눈다.
- 가중치 탐색은 외부 최적화 패키지 없이 결정론적 simplex 탐색과 국소 정밀 탐색으로 구현한다.
- 실제 실험은 1판, 10판, 100판 순서로 확대한다.
- 10판에서 사건 감지, pair 생성, 정답 후보 포함 상한이 100%가 아니면 100판 가중치 탐색을 시작하지 않는다.
- 최종 잠금 검증도 새 1판, 새 10판, 새 100판 순서로 확대한다.
