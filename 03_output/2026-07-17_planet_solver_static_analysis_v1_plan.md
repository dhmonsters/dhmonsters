# Planet Solver 정적 분석 계획

## 목표

`Planet_solver_v1.0.5.exe`와 동봉 파일을 실행하지 않고 조사하여 프로그램의 구성 기술, 핵심 처리 흐름, 외부 프로그램 의존성, 파일·네트워크·프로세스 관련 기능과 보안상 주의점을 근거 중심으로 설명한다.

## 분석 원칙

- 대상 실행 파일을 직접 실행하지 않는다.
- 대상 폴더를 수정하지 않는다.
- 해시, 전자서명, PE 구조, 포함 문자열, 패키징 흔적, 설정과 안내 문서를 교차 검증한다.
- 확인된 사실과 합리적 추정을 명확히 구분한다.
- 동적 분석이 필요한 부분은 실행하지 않고 후속 권고로 남긴다.

## 작업 단계

1. 파일 인벤토리와 사용자 문서를 수집한다.
2. 실행 파일의 해시, 서명, 버전 정보와 PE 헤더를 조사한다.
3. 패키징 방식과 포함 라이브러리·프레임워크 흔적을 식별한다.
4. 문자열과 내장 리소스에서 핵심 기능, 입력, 출력, 프로세스 및 네트워크 단서를 찾는다.
5. `MapleHunter_v3.1.17.exe`, `VC_redist.x64.exe`, 설정과 녹화물의 역할을 교차 분석한다.
6. 근거 수준을 표시한 작동 흐름과 핵심 구성요소를 작성한다.
7. DOCX 보고서를 생성하고 페이지 렌더링으로 레이아웃을 검증한다.

## 완료 기준

- 프로그램별 역할과 관계가 정리되어 있다.
- `Planet_solver_v1.0.5`의 입력→처리→출력 흐름이 설명되어 있다.
- 핵심 기술과 라이브러리가 근거와 함께 정리되어 있다.
- 확정 사실, 높은 가능성의 추정, 미확인 항목이 구분되어 있다.
- 최종 DOCX의 모든 페이지를 렌더링해 깨짐과 겹침을 확인했다.
