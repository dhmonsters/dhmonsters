# Studio와 puzzle.py 자동 시각 검증 계획

## 목표

Lie Captcha Studio를 문제 출제기로 두고, `puzzle.py`를 마우스 출력 없는 표적 시각화 판정기로 두어 반복 검증한다.
목표는 실제 마우스를 움직이지 않고도 매번 새 판에서 표적 경로를 얼마나 잘 따라가는지 자동으로 확인하는 것이다.

## 핵심 원칙

- 메모리 읽기, DLL 주입, 커널 드라이버, 원격 코드 실행은 사용하지 않는다.
- 검증 중 마우스 제어는 항상 OFF로 강제한다.
- Studio의 정답 경로와 puzzle.py의 선택 표적 경로를 같은 프레임 번호로 비교한다.
- 실패 프레임은 사람이 볼 수 있는 이미지와 엑셀 리포트로 남긴다.
- `ffmpeg`는 판단기가 아니라 증거 영상 저장 장치로만 사용한다.

## 단계

1. 검증 모드 고정.
   - `puzzle.py`의 `target_visual_check` 경로에서 마우스 출력이 절대 켜지지 않게 확인한다.
   - CCTV 오버레이에 선택 표적, 후보, 경로가 반드시 보이게 한다.

2. Studio 정답 경로 내보내기.
   - Studio가 `run_id`, `frame_id`, `target_x`, `target_y`, `canvas_rect`, `seed`를 JSONL로 남기게 한다.
   - 정답은 화면 좌표 또는 보드 기준 좌표 중 하나로 통일한다.

3. puzzle.py 선택 경로 내보내기.
   - 매 프레임 선택 표적 좌표, 후보 수, 선택 이유, confidence, mouse_enabled 상태를 JSONL로 남긴다.
   - 검증 모드에서는 `mouse_enabled=false`가 세션 시작부터 끝까지 유지되어야 한다.

4. 채점기 추가.
   - Studio 정답 경로와 puzzle.py 선택 경로를 `frame_id`로 맞춘다.
   - 프레임별 거리, 성공 여부, 튐 여부, 후보 없음, identity lost를 계산한다.

5. 리포트 생성.
   - 엑셀에는 run별 성공률, 실패 프레임, 실패 이유, 평균 오차, 최대 오차를 기록한다.
   - 이미지 contact sheet에는 정답, 선택 표적, 후보 박스, 실패 이유를 표시한다.
   - 영상은 원본, 오버레이, 필요 시 3D 흑백 관찰본을 분리 저장한다.

## 성공 기준

- 10회 자동 검증을 사람이 개입하지 않고 실행할 수 있다.
- 모든 세션 로그에 `mouse_enabled=false`가 기록된다.
- 정답 경로와 선택 표적 경로가 같은 프레임 번호로 비교된다.
- 실패 프레임을 엑셀과 이미지에서 바로 찾을 수 있다.
- Studio, GT, 녹화본 검증 결과가 같은 리포트 형식으로 쌓인다.

## 범위 밖

- 실제 서비스 CAPTCHA 우회.
- 메모리 읽기 기반 정답 획득.
- 마우스 자동 클릭 또는 자동 조작.
- 서버에서 코드를 내려받아 실행하는 구조.
- 관리자 권한, 드라이버, DLL 주입 방식.
