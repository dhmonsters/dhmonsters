# Planetlie 파일 분석 계획

## 목적

`C:\Users\PC\Downloads\planetliev1.02\planetlie` 폴더를 정적으로 분석해 사용된 프로그램과 라이브러리, 각 구성요소의 역할, 핵심 실행 파일, 전체 작동 방식을 파악한다.

## 범위

1. 폴더 구조와 설정·로그·설명서 확인.
2. 실행 파일과 DLL의 버전·서명·해시·PE 메타데이터 확인.
3. 문자열과 import 정보를 바탕으로 기능 및 의존 관계 추정.
4. 핵심 구성요소와 실행 흐름 정리.
5. 확인된 사실과 추정 내용을 구분해 보고서 작성.

## 안전 원칙

- 대상 실행 파일과 DLL을 직접 실행하거나 등록하지 않는다.
- 파일을 수정하거나 삭제하지 않는다.
- 네트워크 통신을 발생시키지 않는다.

## 완료 기준

- 주요 파일별 역할이 근거와 함께 정리되어 있다.
- 프로그램의 시작부터 주요 처리까지의 흐름이 설명되어 있다.
- 확인 불가능한 부분과 추가 동적 분석이 필요한 부분이 구분되어 있다.
