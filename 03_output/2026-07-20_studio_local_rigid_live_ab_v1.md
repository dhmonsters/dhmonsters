# Studio 독립 국소 강체 실제 A/B 결과

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

GT는 실행 중 선택에 사용하지 않고 실행 종료 후 채점에만 사용했다. 모든 검증은 마우스 출력 없이 표적 시각화만 켠 `puzzle.py` 경로로 실행했다.

## 변경 내용

- 후보 주변 패치를 전역 배경 이동만큼 되돌려 이전 프레임과 비교하는 `local_rigid_residual`을 추가했다.
- 밝기 잔차 40%와 경계 잔차 60%를 합쳐 배경과 다르게 움직이는 국소 물체를 찾는다.
- 기본 후보 잔차가 측정되지 않은 0이면 전환하지 않는다.
- 새 가설 잔차가 0.20 이상, 기본 후보 대비 이득이 0.121 이상, 두 경로가 30px 이상 떨어졌을 때만 전환한다.
