# MapleHunter 빨코 루틴 분석 맥락 기록

## 2026-07-19 시작 결정

- 사용자가 `빨코`는 맵 이름이며 관련 정보가 `config.json`에 있다고 확인했다.
- 분석 대상은 앞서 조사한 `MapleHunter_v3.1.17.exe`와 동일하다.
- 대상 다운로드 폴더에는 별도 설정 파일이 보이지 않고 EXE만 확인됐다.
- 원본 EXE를 실행하지 않고 기존 안전 추출물의 번들 설정을 조사한다.
- 결과는 루틴 순서, 좌표, 이동 수단, 반복 구조와 실패 가능 지점을 중심으로 정리한다.

## 2026-07-19 설정과 맵 모듈 확인

- 번들 `config.json`에는 `minimap_region`, `hunting`, `detection`만 있으며 선택된 맵 이름이나 루틴 배열은 없다.
- `minimap_region`은 GUI 코드상 CCTV·유저 감지 영역이며 사냥 좌표와 무관하다는 안내가 있다.
- GUI는 월드가 `planet`이면 `maps_planet`, 그 외에는 `maps` 폴더의 Python 파일을 맵 목록으로 읽는다.
- 빨코 계열 소스는 `maps/빨코2.py`, `maps_planet/빨코2_v2.py`, `빨코2_v3.py`, `빨코2_v4.py`, `빨코new.py` 다섯 개다.
- 일반 `빨코2`는 미니맵 픽셀 좌표를 사용하고, 플래닛 변형은 외부 메모리 리더의 월드 좌표를 사용한다.

## 2026-07-19 기본 빨코2 동선

- 고정 미니맵 영역은 `(43,159)~(276,297)`이고 주요 좌표는 2층 `y=83`, 1층 `y=100~102`, 우측 끝 `x=173`, 계단 `x=44~54`다.
- 2층에서 오른쪽 방향을 누른 채 공격 `a`와 텔레포트 `space`를 0.25초 간격으로 반복해 `x>=173`까지 이동한다.
- 아래 텔레포트를 반복해 1층에 도달한 뒤, 왼쪽 텔레포트 공격으로 `x<=54`까지 이동한다.
- 계단 범위를 지나쳤으면 걷기로 `x=44~54`에 복귀하고 위 텔레포트 두 번으로 2층을 확인한다.
- 2층 미도착 시 계단 범위로 재정렬한 뒤 위 텔레포트를 반복한다.
- 같은 좌표가 3초 유지되면 왼쪽 점프로 낑김 탈출을 시도한다.

## 2026-07-19 플래닛 변형 동선

- `빨코2_v2`는 2층 `x=-2.70~5.72`를 좌우 텔레포트 공격으로 왕복한다. 3사이클마다 우측 ID39 `x=7.4~8.4`에서 점프 낙하 후 1층을 좌측으로 수거하고 7번 계단 `x=-4.66~-4.05`으로 복귀한다.
- `빨코2_v3`과 `v4`는 v2를 그대로 상속하며 수거 주기만 각각 5사이클과 7사이클이다.
- `빨코new`는 로그상 v5이며 2층에서 약 92.83~102.483초 왕복 사냥 후 24번 발판, 1층, 7번 계단, 2층, 14/15번, 16번, 27번 발판 순으로 수거하고 2층으로 복귀한다.
- `빨코new`는 텔레포트 거리 1.5 미만에서는 걸어서 X를 정밀 정렬하고, 발판 도착은 Y 좌표로 확인한 뒤 다음 텔레포트를 실행한다.

## 2026-07-19 레거시와 v5 코드 객체 확인

- `빨코2(플래닛).pyc`는 일반형과 같은 4단계 동선을 사용하지만 컴파일된 좌표는 2층 `y=82`, 1층 `y=99~101`, 우측 `x=175`, 계단 `x=48~55`다.
- 레거시는 공격 스레드, 약 1초 간격 방향 재그립, 5초 좌표 실패 종료, 25초 복귀 제한을 추가한다.
- `빨코2_v5.pyc`와 `빨코new.pyc`는 클래스명, 소스 경로와 공격 스레드 이름을 정규화하면 전체 코드 객체 메타데이터가 일치한다.
- 따라서 `빨코new`는 v5 동선을 사용자에게 노출하는 새 이름으로 판단했다.

## 2026-07-19 문서 검증

- DOCX 빌더 테스트에서 전 버전 포함, Letter 1인치 여백, 고정 9360 DXA 표 폭과 페이지 필드 구조를 확인했다.
- 번호 목록이 절을 넘어 이어지는 문제를 렌더링에서 발견하고, 목록마다 독립 `numId`와 `startOverride=1`을 생성하는 회귀 테스트로 수정했다.
- Word로 최종 PDF를 만들고 8페이지 전체를 이미지로 확인했다.
- 표 머리행 반복, 페이지 분리, 번호 재시작, 글자 잘림, 겹침과 누락을 확인했으며 시각적 결함은 남지 않았다.
