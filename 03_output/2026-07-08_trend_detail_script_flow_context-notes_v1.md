# 2026-07-08 트렌드 상세 분석과 대본 편집 결정 노트 v1

## 결정

- 후보 상세 분석은 외부 AI 없이 deterministic 서비스로 먼저 구현한다.
- 실제 유튜브 데이터와 샘플 데이터 모두 같은 분석 API에 넣어 처리한다.
- 하네스는 구조화된 필드와 자유 입력 커스터마이징을 함께 사용한다.
- 장면 편집은 우선 프론트 상태에서 수정하고, 영구 저장은 다음 단계에서 다룬다.

## 이유

- 지금 단계의 핵심은 “소재 후보가 대본 방향으로 바뀌는 과정”을 사용자가 볼 수 있게 하는 것이다.
- 실제 AI 연결 전에 입력과 출력 구조를 고정해야 이후 OpenAI, TTS, 렌더링 API를 안정적으로 붙일 수 있다.

## 구현 메모

- 후보 분석 API는 `POST /api/trends/analyze`로 추가했다.
- 대본 생성 API는 선택 payload로 `harness`와 `trend_analysis`를 받는다.
- 프론트는 상세 분석 결과를 상태에 저장하고 추천 하네스를 즉시 반영한다.
- 장면 수정, 다시 생성, 순서 변경은 프론트 상태에서 먼저 동작한다.
