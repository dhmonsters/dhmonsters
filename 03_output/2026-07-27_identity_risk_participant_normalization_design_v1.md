# Identity-Risk 사건 참여자 정규화 설계

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

이번 단계는 보드 전체 검출을 억지로 두 개로 줄이지 않는다. 타겟 신분이 실제로 위험해진 접촉 사건만 열고, 그 사건에 참여한 타겟 1개와 충돌 배경 1개의 계보만 분리 후보 판별기로 전달한다.

## 현재 실패의 재정의

대표 기록의 첫 진단 프레임에는 신뢰 가능한 흰색 앵커와 보드 전체의 실제 배경 도형 약 29개가 함께 존재한다. 기존 추출기는 흰색 타겟과 가까운 배경 박스의 접촉을 즉시 병합 사건으로 열고, 보드 전체 후보를 정확히 두 자식으로 정리하려 했다.

이 진단은 후보 중복 제거 실패 이전에 사건 자격 판정이 잘못된 경우다. 흰색 타겟이 보이는 접촉은 신분 복원이 필요한 사건이 아니라 배경 충돌 계보를 관찰하는 준비 자료다.

## 관측 계층

네 단위를 섞지 않는다.

1. 검출 제안은 검출기가 출력한 박스 하나다.
2. 물리 후보는 같은 도형을 나타내는 같은 프레임의 검출 제안 묶음이다.
3. 사건 참여자는 타겟과 실제 충돌 배경이다.
4. 신분 역할은 두 참여자에게 타겟과 배경을 배정한 H1/H2다.

## 상태

### VISIBLE_CALIBRATION

흰색 앵커와 선택 타겟이 같은 물리 후보를 가리킨다. 접촉이 없어도 배경 흐름과 안정 크기를 관찰한다.

### CONTACT_VISIBLE

흰색 신분이 보이는 동안 타겟과 배경이 접촉한다. 사건을 열지 않고 가장 가까운 충돌 배경의 마지막 신뢰 상태를 보존한다.

### IDENTITY_RISK

신뢰 가능한 흰색 관측이 사라진 뒤 타겟과 충돌 배경의 접촉이 확인된다. 이때 마지막 신뢰 타겟 상태와 충돌 배경 상태를 동결하고 scoreable event를 연다.

### MERGED

하나의 큰 박스나 겹친 두 박스가 남는다. 부모 박스는 영역 계보로만 사용하고 타겟 위치와 속도를 갱신하지 않는다.

### SPLIT_HYPOTHESES

분리 후보가 돌아오면 사건 지역 안의 가능한 물리 후보 쌍을 보존한다. 각 쌍에 H1/H2 역할 가설을 만든다.

### RESOLVED 또는 HOLD

물리 쌍과 역할 배정이 모두 분명할 때만 신분을 전달한다. 어느 단계든 모호하면 HOLD한다.

## 사건 자격

- 신뢰 가능한 흰색 앵커가 선택 타겟과 일치하면 접촉은 scoreable event가 아니다.
- 흰색 앵커가 사라졌다고 단독으로 사건을 열지 않는다. 기하학적 접촉이나 병합 영역 관측도 함께 필요하다.
- 페이드 경계에서 이미 접촉 중이면 마지막 visible contact의 타겟과 충돌 배경 상태를 premerge snapshot으로 사용한다.
- 사건 자격은 고정 프레임 번호가 아니라 현재 관측 가능성과 접촉 상태로 판단한다.

## 사건 참여자 지역화

보드 전체 후보 중 다음 조건을 만족하는 후보만 사건 후보가 된다.

- 병합 직전 타겟의 독립 예측 영역과 호환된다.
- 충돌 배경의 현재 판 배경 흐름 예측 영역과 호환된다.
- 최근 병합 부모 영역의 자식으로 설명된다.

지역 크기는 고정 픽셀이 아니다. 병합 전 도형 대각선, 최근 속도 분산, 배경 흐름 분산, 경과 관측 수와 부모 영역 불확실성으로 정규화한다.

## 물리 후보와 쌍 가설

사건 지역 안에서만 같은 프레임 검출 제안을 묶는다. 높은 IoU 하나만으로 묶지 않고 중심 거리, 크기 호환성과 박스 겹침을 함께 요구한다. 서로 다른 실제 도형일 가능성이 남으면 합치지 않는다.

정규화 뒤 후보가 정확히 두 개가 아니어도 즉시 실패하지 않는다. 가능한 두 후보 조합을 만들고 다음 조건으로 지배되는 조합만 제거한다.

- 두 후보의 합집합이 병합 부모 영역을 설명하지 못한다.
- 두 후보가 같은 물리 묶음에 속한다.
- 두 후보 모두 타겟 예측과 배경 예측 어느 쪽에도 연결되지 않는다.
- 다른 조합보다 모든 필수 잔차가 나쁘고 불확실성도 크다.

여러 조합이 남으면 같은 사건 ID로 HOLD하며 후속 분리 관측을 기다린다.

## 역할 판별

각 물리 쌍에 기존 H1/H2 판별기를 적용한다. 배경 운동과 주변 상대관계는 배경 역할을, 병합 전 타겟 운동은 타겟 역할을 판단한다. YOLO와 모양은 낮은 품질 감점만 담당한다.

같은 원인에서 나온 motion divergence와 rigid violation은 하나의 배경 운동 계열로 취급한다. 측정할 수 없는 심판은 0점이 아니라 기권한다.

하나의 물리 쌍이 다른 쌍보다 분명하고 그 쌍 안의 H1/H2도 분명할 때만 RESOLVED한다. 쌍 선택 또는 역할 선택 중 하나라도 모호하면 HOLD한다.

## 안전 계약

- 실행 중 GT, 정답 좌표, seed 이름을 사용하지 않는다.
- 고정 좌표, 고정 방향, 절대 프레임 번호를 사용하지 않는다.
- visible contact를 실패 사건으로 세지 않는다.
- 부모 박스 중심을 타겟 관측으로 사용하지 않는다.
- 보드 전체 후보 수가 변해도 사건 지역 밖 후보는 결정에 영향을 주지 않는다.
- 후보 부재와 후보 모호성을 구분한다.
- 실제 선택 권한과 마우스 출력은 계속 끈다.

## 검증 게이트

합성 테스트에서 먼저 다음 계약을 검증한다.

1. 흰색 접촉과 30개 배경 후보가 있어도 사건을 열지 않는다.
2. 흰색이 사라진 뒤의 접촉만 identity-risk 사건이 된다.
3. 사건 밖 후보를 추가해도 물리 쌍과 역할 결정이 변하지 않는다.
4. 같은 물리 도형의 중복 제안은 묶고 서로 다른 근접 도형은 합치지 않는다.
5. 여러 쌍이 남으면 HOLD하고 후속 관측에서 해소한다.
6. GT를 바꿔도 runtime 결정이 변하지 않는다.

합성 계약이 모두 통과한 뒤 대표 기록의 첫 scoreable identity-risk 사건을 정확히 한 번 실행한다. 첫 visible contact 진단은 비채점 관찰로 기록하고 event limit에 포함하지 않는다.

## 비목표

- 보드 전체 다중 객체 추적기를 새로 만들지 않는다.
- 전체 주기 hard gate의 임계값을 완화하지 않는다.
- 대표 판 결과에 맞춰 좌표나 방향 규칙을 넣지 않는다.
- Gate를 통과하기 전에 Studio 또는 `puzzle.py` 선택 경로에 연결하지 않는다.
