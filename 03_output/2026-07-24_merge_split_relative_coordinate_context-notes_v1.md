# 병합-분리 배경 상대 좌표 맥락 기록

## 2026-07-24 결정

- 주요 남은 실패는 타겟과 배경 도형이 겹친 뒤 분리될 때 배경 자식으로 신분을 갈아타는 현상이다.
- 겹침 양에 따라 서로 겹친 두 박스가 유지되기도 하고 하나의 커진 병합 박스만 남기도 한다.
- 박스 겹침 자체가 타겟을 뜻하지 않는다. 기존 타겟 계보가 참여한 병합 사건만 처리한다.
- 배경 도형들은 함께 움직이므로 주변 배경 기준점과의 상대 관계가 유지된다.
- 분리된 자식 중 이 관계를 유지하는 자식은 배경이고 관계가 깨지는 자식은 타겟 후보다.
- 절대 거리 대신 두 기준점으로 만든 정규화 좌표 `(u, v)`를 사용한다.
- 허용 오차는 고정값이 아니라 현재 판의 배경 상대 좌표 흔들림에서 계산한다.
- 완전 병합 중에는 커진 박스 중심으로 타겟 신분을 갱신하지 않는다.
- 상대 좌표는 배경 배정의 주심이고 local rigid는 같은 계열의 확인 근거이므로 독립 표로 중복 계산하지 않는다.
- YOLO는 낮을 때만 감점하고 높은 점수 하나로 신분을 교체하지 않는다.
- 기준점 부족, 경계 잘림, 관측 불가능은 0점이 아니라 보류 또는 기권이다.
- 첫 구현은 Studio replay의 opt-in shadow로 제한한다.
- 검증은 이론상 예측이 맞는지 대표 실패판 하나부터 시작하고 통과할 때만 범위를 넓힌다.
- GT는 실행 종료 후 채점에만 사용한다.

## 이전 채택 후보와의 관계

- 기존 `PersistentEvidenceQuorum`은 도전 경로가 여러 유효 관측에서 유지되는지 확인한다.
- 새 병합 resolver는 분리 자식 중 어떤 것이 배경인지 먼저 배정한다.
- resolver와 quorum을 한 점수 함수로 합치지 않는다.
- 최소 3개 관측의 최종 확정은 quorum 한 곳에서만 수행한다.
- detector 후보 ID가 바뀌어도 예측 위치와 상대 좌표로 이어지는 공간 경로에 신분을 귀속한다.
- 기존 Studio seed 10판 기준은 1123/1500에서 1135/1500, A/B 회귀 0이다.
- GT 비참조 selector와 런타임 selector의 기존 기준은 각각 16/16이다.
