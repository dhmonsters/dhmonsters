# Studio 가설 생성 개선 결과

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

GT는 실행 중 입력으로 사용하지 않았고, 모든 경로 선택이 끝난 뒤 결과 채점과 실패 원인 분류에만 사용했다.

## 핵심 결론

- 실패 원인은 후보 부족보다 보관함의 중복 점유였다.
- 후보 다양성 우선 폭 24 경로는 가설 생성 오류를 147프레임에서 10프레임으로 줄였다.
- 넓은 경로를 바로 선택에 쓰면 기존 성공도 잃으므로, 기존 경로와 도전자 경로를 분리했다.
- 도전자는 상위 12개 가설, 3프레임 연속 확인, 프레임당 60px 제한을 통과해야 한다.
- 기존 강체 경로가 선택된 경우에는 도전자가 교체하지 못한다.

마지막 행은 같은 재생기에서 기존 경로 1,109와 비교한 결과다. 공식 기준선 1,110과 1프레임 차이는 과거 trace와 score 정렬 차이다.

## 실제 연결 확인

- 동일 고정 seed 01은 기존 93/150에서 실제 `puzzle.py` 97/150으로 개선됐다.
- shadow 예상은 98/150으로 실제와 1프레임 차이였다.
- 서로 다른 새 seed 묶음은 1,392프레임 중 1,021프레임, 73.35%였다.
- 새 seed 실행은 Studio가 1,393번째 GT를 보내지 않아 전체 1,500프레임 전에 종료됐다.

## 회귀 검증

- 관련 회귀 테스트 150개 통과와 하위 테스트 3개 통과를 확인했다.
- 16GT 16/16을 유지했다.
- 16GT 평균 오차는 26.317640328557086px이고 coverage는 전부 100%다.
