# MapleHunter 빨코2 전 버전 비교 분석 설계

## 확정 범위

- 일반 월드의 `maps/빨코2.py`를 분석한다.
- 플래닛 월드의 `빨코2(플래닛)`, `빨코2_v2`, `v3`, `v4`, `v5`, `빨코new`를 분석한다.
- `빨코new`와 `v5`가 같은 구현인지 별도 구현인지 파일·코드 객체 수준에서 확인한다.
- `config.json`이 맵 선택이나 루틴을 저장하는지 확인하고 실제 맵 로딩 구조와 구분한다.

## 보고서 구조

1. 결론에서 버전별 핵심 차이를 먼저 요약한다.
2. 공통 비교표에서 좌표 출처, 사냥 범위, 수거 주기, 층간 이동, 복구 방식과 입력 패턴을 나란히 비교한다.
3. 각 버전별로 시작점부터 반복점까지 동선을 순서대로 설명한다.
4. 일반형과 플래닛형의 좌표 체계 차이를 별도 절로 설명한다.
5. 안정성 보정과 실패 가능 지점을 직접 확인된 코드 근거로 정리한다.

## 증거 기준

- 소스가 포함된 버전은 원본 줄 번호와 상수·함수 호출을 근거로 삼는다.
- `.pyc`만 존재하는 버전은 코드 객체의 이름·상수·문자열·해시를 사용하고 소스와 동일한 수준으로 단정하지 않는다.
- 파일명, 클래스명, 로그 표기가 다르면 각각 기록하고 별칭 여부를 판정한다.
- 실행 결과나 실제 게임 성공률은 추정하지 않는다.

## 산출물

- 분석 원문 Markdown.
- 버전 비교와 동선 흐름을 포함한 DOCX.
- 추출 파일 목록과 코드 객체 메타데이터.

## 자체 검토

- 미정 항목이나 임시 표시는 없다.
- `config.json`과 실제 맵 모듈의 역할이 혼동되지 않도록 분리했다.
- 사용자가 요청한 모든 빨코2 버전과 `빨코new`가 범위에 포함됐다.
