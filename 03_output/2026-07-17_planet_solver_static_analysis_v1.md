## 1. 핵심 결론

`Planet_solver_v1.0.5.exe`는 Python 3.13 프로그램을 PyInstaller 단일 실행 파일로 묶은 64비트 Windows GUI 앱이다. UI는 PyQt5, 화면 분석은 OpenCV·NumPy·ncnn, 화면 캡처는 MSS와 Win32 PrintWindow, 입력은 Win32 PostMessage 또는 SetCursorPos 방식을 사용한다.

프로그램의 핵심은 투명 도형 퍼즐을 찾고 추적하는 두 단계 YOLO 구조다. M1은 동일한 1클래스 모델 가중치 4개를 앙상블하여 도형 후보 위치를 찾고, M2는 후보를 원·사각형·삼각형·별의 4종으로 분류한다. 입력 크기는 320이며 세 출력 스케일을 합친 뒤 NMS로 중복 박스를 제거한다.

다만 실제 추적·좌표·임계값·클릭 순서를 담당하는 `_track_once`, `_match_xz`, `_on_trigger_start` 등의 핵심 함수는 실행 파일에 완전하게 들어 있지 않다. 라이선스 인증 후 Firebase Cloud Functions 계열 서버에서 AES-256-GCM 암호문으로 내려받고, 복호화한 Python 코드를 `exec()`로 실행해 `Macro` 객체에 주입한다. 따라서 서버가 보내는 코드가 바뀌면 같은 실행 파일도 동작이 달라질 수 있으며, 오프라인 정적 분석만으로 런타임 동작 전체를 확정할 수 없다.

`MapleHunter_v3.1.17.exe`는 더 큰 통합 자동화 프로그램이다. Planet 관련 탐지 모듈 외에 Tesseract OCR 기반 거짓말 탐지기 풀이, MSS 화면 캡처, PyAutoGUI·keyboard·Interception 입력 제어, 텔레그램 알림, 자동 드라이버 설치 기능을 포함한다.

악성 프로그램이라고 단정할 직접 증거는 발견하지 못했다. 그러나 두 주요 실행 파일이 전자서명되지 않았고, 안내문이 Windows 보안 기능 전체 비활성화를 요구하며, 서버에서 받은 코드를 메모리에서 실행하고, MapleHunter가 서명되지 않은 키보드·마우스 필터 드라이버 설치와 보안 관련 드라이버 파일 삭제를 시도하는 구조이므로 신뢰·보안 위험은 높다. 주 PC에서 그대로 실행하는 것은 권장하지 않는다.

## 2. 분석 범위와 방법

이번 분석에서는 실행 파일을 직접 실행하지 않았다. 원본 폴더도 수정하지 않았다.

조사 항목은 파일 인벤토리, SHA-256, 전자서명, PE 헤더와 임포트 DLL, PyInstaller 패키지 목차, 포함 라이브러리와 모델, 압축된 자체 Python 모듈의 함수·상수 구조, 안내 문서, 설정, 이미지 및 디버그 캡처다.

확정 수준은 다음과 같이 구분한다.

- 확인됨. 패키지 안의 파일·소스·코드 객체·상수 또는 전자서명 정보로 직접 확인했다.
- 높은 가능성. 여러 독립 단서가 일치하지만 동적 실행으로 검증하지 않았다.
- 미확인. 서버 제공 코드나 실행 환경에 따라 달라 정적 분석만으로 확정할 수 없다.

## 4. Planet Solver의 기술 구성

### 4.1 패키징과 UI

PE 헤더는 64비트 PE32+ GUI 프로그램을 나타낸다. 파일 끝의 PyInstaller CArchive 쿠키와 132MB 오버레이, `python313.dll`, 시작 스크립트 `toss_wrapper`가 확인되었다. 내부 UI 문자열은 제품을 “Planet-투명도형 v2”라고 표시하지만 파일 배포 버전과 인증 클라이언트 버전은 `1.0.5` 및 `1.0.5-tushape_dm`이다.

PyQt5가 창, 라이선스 대화상자, 로그, GPU/CPU 옵션, 텔레그램 설정을 담당한다. F1은 매크로 시작·정지 토글로 등록된다.

### 4.2 인증과 세션

HWID는 CPU ID, 메인보드 시리얼, BIOS 시리얼, MAC 주소를 결합한 뒤 SHA-256 앞 40자를 사용하는 방식이다. 라이선스 키는 `%APPDATA%\PlanetTushape\license.dat`에 저장한다.

기본 서버 주소는 `https://us-central1-lona-22892.cloudfunctions.net`이며 확인된 요청은 `checkAuth`, `heartbeat`, `checkUpdate`, `getMacroCode`다. 제품 식별자는 `tushape_dm`이다. 인증 성공 후 `session_token`을 받고, 3분마다 heartbeat를 전송한다. 만료·차단 응답이 오면 세션 무효 처리를 한다.

### 4.3 게임 창 검색과 화면 캡처

게임 창은 Windows 창 클래스와 제목을 순회해 찾는다. 확인된 클래스에는 `MapleStoryClass`, `UnityWndClass`, `NEXON Plug-in Window`가 있고 제목 키워드에는 maplestory, planet, worlds 등이 있다.

캡처는 다음 순서다.

1. MSS를 이용해 지정 화면 영역을 캡처한다.
2. 캡처가 검거나 비어 있으면 Win32 `PrintWindow(PW_RENDERFULLCONTENT)`로 게임 창을 직접 캡처한다.
3. 시작 시 두 방식의 캡처 자가진단을 수행하며 둘 다 실패하면 경고를 낸다.

내부 설명은 MSS를 DXGI 계열 경로로 표현하고 있다. 핵심 의도는 하이브리드 GPU·전체화면·일부 드라이버 환경에서 발생하는 검은 화면을 PrintWindow로 우회하는 것이다.

### 4.4 투명 도형 트리거

`xz.bmp`, `xz1.bmp`, `xz2.bmp`, `xz3.bmp`, `xz4.bmp`는 “투명…” 문구의 작은 변형 템플릿이다. 화면 전체에서 이 템플릿을 찾아 투명 도형 퍼즐 시작을 감지하는 구조다.

트리거 매칭의 정확한 임계값과 좌표는 서버에서 내려오는 `secure_code.py`에 있으며 실행 파일에는 완전한 값이 없다.

### 4.5 ncnn YOLO 모델

모델은 ncnn 형식의 `.param`과 `.bin` 조합이다. `hyung_m1.param`은 공통 네트워크 구조이고 `hyung_m1_a.bin`부터 `hyung_m1_d.bin`까지 4개의 가중치를 사용한다. `hyung_m2.param`과 `hyung_m2.bin`은 도형 분류 모델이다.

M1과 M2의 역할은 다음과 같다.

- M1 1클래스 탐지기. 네 모델 결과를 합친 후 NMS를 적용해 도형 후보 위치를 안정적으로 찾는다.
- M2 4클래스 탐지·분류기. 원·사각형·삼각형·별 중 목표 도형 종류를 판별하고, M1이 찾은 후보를 재분류한다.
- 첫 프레임에서 M2로 흰 마커의 목표 클래스를 결정하고 이후 프레임에서 같은 클래스만 추적하는 설계다.

입력 이미지는 320×320 레터박스로 변환하고 BGR을 RGB로 바꿔 정규화한다. 세 출력 `out0`, `out1`, `out2`를 디코딩해 `[x1, y1, x2, y2, score, class]` 형식으로 합치고 IoU 기반 NMS를 적용한다.

CPU가 기본 권장 경로다. Vulkan GPU 옵션도 있으나 내부 설명은 FP16에 따른 정확도 저하 가능성과 게임 GPU 경합을 이유로 CPU를 권장한다.

### 4.6 마우스 제어

두 입력 모드가 확인된다.

- 백그라운드 방식. `PostMessage`로 게임 창에 마우스 이동·클릭 메시지를 보내 실제 시스템 포인터를 움직이지 않는다.
- 전경 방식. `SetCursorPos`와 실제 좌클릭을 사용해 시스템 포인터를 움직인다.

실제 도형 추적 좌표 생성, 클릭 타이밍, 실패 복구의 핵심은 서버 제공 코드에 있다.

### 4.7 핵심 코드의 서버 동적 로딩

이 부분이 Planet Solver의 구조상 가장 중요하다.

1. 클라이언트가 HWID와 라이선스로 인증한다.
2. 인증 서버가 `session_token`을 발급한다.
3. 클라이언트가 `getMacroCode`를 호출한다.
4. 서버는 nonce 12바이트, 인증 태그 16바이트, 암호문으로 구성된 응답을 보낸다.
5. 클라이언트는 `SHA-256(session_token)`을 키로 사용해 AES-256-GCM 복호화한다.
6. 복호화된 Python 코드를 `exec()`로 실행한다.
7. 생성된 `_track_once`, `_match_xz`, `_on_trigger_start`와 상수·좌표·임계값을 `Macro` 인스턴스에 주입한다.

HWID 워터마크가 현재 PC와 맞지 않거나 디버거가 부착되었다고 판단하면 주입을 거부한다. 서버가 응답하지 않으면 매크로가 시작되지 않는다.

이 설계는 판매자의 핵심 로직 보호에는 유리하지만 사용자는 실행 시점에 서버가 보내는 코드를 사전에 감사할 수 없다. 서버 또는 계정이 침해되면 실행 파일을 교체하지 않고도 다른 코드가 전달될 수 있다는 신뢰 위험이 있다.

### 4.8 업데이트

`checkUpdate`가 버전, 다운로드 URL, 변경 내역, 강제 여부, 예상 SHA-256을 반환한다. 새 실행 파일을 임시 폴더에 내려받고 해시를 확인한 뒤 배치 파일로 기존 실행 파일을 교체하고 재시작한다.

해시 검증은 전송 오류나 단순 변조 탐지에는 도움이 된다. 다만 URL과 예상 해시가 동일 서버에서 오므로 서버 자체가 침해된 경우를 막는 코드 서명 대체 수단은 아니다.

## 5. MapleHunter의 작동 방식

### 5.1 전체 역할

MapleHunter도 Python 3.13 + PyInstaller + PyQt5 앱이다. 시작 스크립트는 `main`이다. Planet Solver보다 약 두 배 큰 이유는 OpenCV, Tesseract 전체 배포본, 다수의 게임 화면 템플릿, 맵 가이드, 입력 라이브러리와 드라이버 설치기를 함께 포함하기 때문이다.

### 5.2 일반 거짓말 탐지기 풀이

포함된 `detectors\planet\detector.py.serveronly`와 디버그 캡처에서 다음 흐름이 확인된다.

1. 0.4초마다 게임 영역을 MSS로 캡처한다.
2. `title.png`와 `title2.png`를 회색조 템플릿 매칭해 거짓말 탐지기 창을 찾는다.
3. 팝업 기준 고정 좌표로 정답 4문자 영역과 보기 6개 영역을 잘라낸다.
4. 각 영역을 5배 확대하고 회색조, Otsu 이진화, CLAHE 변형을 만든다.
5. Tesseract를 PSM 7·8과 영문 대문자·숫자 화이트리스트로 여러 번 실행해 다수결 결과를 얻는다.
6. B/8, 6/G, 2/Z, 5/S, D/O, 0/Q, U/V, I/1 혼동은 0.5점, 다른 불일치는 1점으로 계산한다.
7. 정답과 거리가 가장 가까운 보기를 클릭하고 확인 버튼을 누른다.
8. 새 문제가 뜨면 최대 3번 반복하고 성공 메시지 창을 템플릿 매칭해 닫는다.
9. 설정된 경우 캡처와 결과를 텔레그램 Bot API로 보낸다.

이는 투명 도형 YOLO 풀이와 별도의 OCR 기반 거짓말 탐지기 처리다.

### 5.3 입력 드라이버와 자동 설치

MapleHunter에는 `interception_python 1.13.6`, `drivers\install-interception.exe`, PyAutoGUI, keyboard가 포함되어 있다. 시작 문자열은 Interception 드라이버가 없으면 설치기를 한 번 실행하고 재부팅 전까지 PyAutoGUI로 폴백한다고 설명한다.

설치기 SHA-256은 `E137863A79DA797F08E7A137280FF2A123809044A888FD75CE9C973198915ABE`이며 전자서명이 없다. 파일 설명은 “Interception command line installation tool”, 회사 표시는 Francisco Lopes다. 내부 문자열은 `keyboard.sys`와 `mouse.sys`를 `System32\drivers`에 설치하고 키보드·마우스 상위 필터 레지스트리를 구성함을 나타낸다.

상위 필터 드라이버는 일반 앱보다 낮은 수준에서 입력을 가로채거나 생성할 수 있다. 설치 실패 또는 호환성 문제는 키보드·마우스 입력 장애와 부팅 문제로 이어질 수 있으므로 주 PC 설치는 신중해야 한다.

### 5.4 BlackCat64.sys 처리

MapleHunter 시작 코드 문자열에는 `BlackCat64.sys`가 매크로 동작을 막는다는 설명과 함께 다음 경로를 우선 삭제하고, 찾지 못하면 C 드라이브 전체 검색을 수행한다는 로직이 명시되어 있다.

- `C:\Windows\System32\drivers\BlackCat64.sys`.
- `C:\Windows\SysWOW64\drivers\BlackCat64.sys`.

이 동작은 실행하지 않았으므로 실제 삭제 성공 여부는 확인하지 않았다. 그러나 보안 또는 게임 보호 구성요소일 수 있는 드라이버 파일을 자동 삭제하려는 기능 자체가 시스템 안정성과 보안 측면에서 고위험이다.

## 7. 데이터·네트워크·시스템 변경

확인된 외부 통신은 Firebase Cloud Functions 계열 인증 서버, Telegram Bot API, 업데이트 다운로드 URL이다. 원본 안내의 Microsoft·GitHub URL은 런타임 설치 안내다. 정적 문자열 조사에서 별도 원시 IP나 추가 제3자 제어 서버는 발견하지 못했다.

Planet Solver가 수집·전송할 수 있는 정보는 HWID 구성에 사용되는 하드웨어 식별자, 라이선스 키, 현재 버전, 실행 파일 해시, 세션 토큰이다. 텔레그램 기능을 켜면 화면 캡처 이미지가 Bot API로 전송될 수 있다.

Planet Solver는 같은 폴더의 `config.json`, `%APPDATA%\PlanetTushape\license.dat`, 임시 업데이트 EXE와 배치 파일을 사용할 수 있다. MapleHunter의 분석 가능한 Planet 모듈은 `C:\Users\Public`에 로드·Tesseract·처리 단계 진단 로그를 기록한다.

## 8. 보안 및 신뢰 위험 평가

| 위험 | 수준 | 근거와 의미 |
|---|---|---|
| 전자서명 부재 | 높음 | 두 주요 EXE와 Interception 설치기가 미서명이라 배포자와 변조 여부를 운영체제가 검증하기 어렵다. |
| Windows 보안 전체 비활성화 요구 | 매우 높음 | 감염 시 방어선이 사라지며 정상 프로그램 배포 관행으로 보기 어렵다. |
| 서버 코드 다운로드 후 `exec()` | 매우 높음 | 실행 시점의 실제 코드는 서버가 바꿀 수 있고 정적 감사 결과와 달라질 수 있다. |
| 커널 입력 필터 드라이버 | 높음 | 입력 장치 경로에 개입하며 장애·호환성·권한 위험이 있다. |
| BlackCat64.sys 삭제 시도 | 매우 높음 | 보안·게임 보호 드라이버일 수 있는 시스템 파일을 제거하려 한다. |
| 자동 업데이트 | 중간~높음 | 해시 확인은 있으나 코드 서명이 없고 URL·해시 신뢰점이 같은 서버다. |
| HWID 수집과 지속 heartbeat | 중간 | 하드웨어 식별 정보를 서버 계정과 연결한다. |
| 화면 캡처 텔레그램 전송 | 중간 | 설정 시 게임 화면과 주변 정보가 외부로 전송될 수 있다. |

정적 분석만으로 “악성” 또는 “안전”을 확정할 수 없다. 특히 서버 제공 코드는 이번 파일 안에 없으므로 실행 시점의 행위를 검증하지 못했다. 현재 구조만 놓고 보면 기능적 핵심과 보안상 핵심이 모두 서버 신뢰에 집중되어 있다.

## 9. 프로그램에서 가장 핵심적인 부분

Planet Solver의 핵심은 세 층이다.

1. 지각 층. MSS·PrintWindow로 화면을 얻고 ncnn YOLO M1/M2로 목표 도형을 찾고 분류한다.
2. 제어 층. 서버에서 받은 추적 로직이 프레임별 목표 위치, 트리거, 좌표와 클릭 타이밍을 결정하고 PostMessage 또는 전경 마우스로 입력한다.
3. 통제 층. Firebase 인증·heartbeat·HWID·업데이트·동적 코드 배포가 사용 권한과 실제 실행 로직을 통제한다.

기술적으로 가장 독창적인 부분은 M1 4모델 앙상블과 M2 4클래스 분류를 조합한 투명 도형 추적이다. 운영상 가장 중요한 부분은 서버 동적 코드 로딩이다. 서버가 없거나 인증이 깨지면 로컬 YOLO 모델이 있어도 매크로 전체가 작동하지 않는다.

## 10. 확정할 수 없는 항목

- 서버가 현재 실제로 반환하는 `secure_code.py`의 전체 내용.
- 도형 추적의 정확한 좌표·임계값·캐스케이드·재시도 로직.
- 실행 시 추가 다운로드되는 파일 또는 서버 응답의 현재 내용.
- 관리자 권한 요청 방식과 실제 드라이버 설치 성공 여부.
- 백신 탐지 결과와 네트워크 패킷의 실제 송수신 내용.
- 실행 후 생성되는 모든 파일·레지스트리·서비스 변경.

이 항목을 확인하려면 인터넷과 호스트를 분리한 일회용 Windows 가상 머신에서 프로세스·파일·레지스트리·네트워크를 기록하는 동적 분석이 필요하다. 주 PC에서 Windows 보안을 끄고 시험해서는 안 된다.

## 11. 최종 판단

`Planet_solver_v1.0.5`는 단순 이미지 매칭 매크로가 아니라 로컬 딥러닝 추론과 원격 동적 코드를 결합한 라이선스 기반 자동화 프로그램이다. MapleHunter는 여기에 OCR·사냥 자동화·커널 입력 드라이버를 추가한 통합 도구다.

작동 원리는 상당 부분 복원되었지만, Planet Solver의 최종 추적·클릭 판단은 서버에서 실행 시 내려오므로 실행 파일만으로 완전 재현할 수 없다. 보안 관점에서는 미서명 파일, 보안 비활성화 요구, 원격 코드 실행, 커널 입력 필터, 보호 드라이버 삭제 기능의 조합 때문에 고위험으로 취급하는 것이 타당하다.

권고사항은 다음과 같다.

- 주 PC에서는 실행하지 않는다.
- Windows 보안을 비활성화하지 않는다.
- 꼭 검증해야 한다면 스냅샷 가능한 격리 VM과 별도 계정을 사용한다.
- 개인 텔레그램 토큰·게임 계정·중요 파일이 없는 환경을 사용한다.
- 네트워크는 허용 목록 방식으로 제한하고 서버 응답과 생성 파일을 기록한다.
- 실행 전후에 드라이버, 서비스, 시작 프로그램, 작업 스케줄러와 시스템 파일 변화를 비교한다.
