# MapleHunter 빨코 루틴 분석 계획

> **작업 지침.** 이 계획은 현재 세션에서 `superpowers:executing-plans` 절차로 순서대로 수행한다.

**목표.** MapleHunter v3.1.17의 일반 `빨코2`, 플래닛 `빨코2(플래닛)`, `v2·v3·v4·v5`, `빨코new`를 찾아 동선, 이동 수단, 반복 구조와 실패 가능 지점을 비교한다.

**분석 방식.** 원본 EXE는 실행하지 않고 기존 PyInstaller 추출물과 번들 설정만 읽는다. 설정 블록을 실행 순서대로 정규화하고, 각 블록의 의미는 앞서 분석한 `RoutineRunner` 동작과 대조한다.

**도구.** PowerShell, ripgrep, Python JSON 파서, python-docx, Word 또는 LibreOffice 렌더링.
