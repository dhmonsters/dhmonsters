# 병합-분리 배경 상대좌표 맥락 기록 v2

## 2026-07-24 결정

- 현재 규칙은 GT를 입력으로 받지 않는 opt-in shadow다.
- 부분 겹침에서는 타겟과 배경 박스가 둘 다 보이므로 관계 지문과 타겟 운동 이력을 갱신한다.
- 완전 병합에서는 중심으로 신분을 갱신하지 않고 기존 상태를 보존한다.
- 배경 기준점은 충돌 도형과 가까운 안정 도형을 사용하되, 병합 참여 도형 자체는 제외한다.
- 현재 신분 후보가 배경으로 판정되지 않으면 다른 후보로 갈아타지 않는다.
- 대표 1판은 101/150으로 기준과 동률이고 순수 개선 0, 순수 손실 0이다.
- 후보 중심 oracle은 128/150이므로 검출 후보 부족보다 분리 자식 계보와 최종 선택이 남은 병목이다.
- 통과 수가 늘지 않았으므로 seed 10과 라이브 연결로 확대하지 않는다.
- 다음 구현은 신분이 확실할 때만 사건을 열고, 병합 전 두 참여 도형과 분리 후 두 자식을 시간축으로 연결하는 계보다.
