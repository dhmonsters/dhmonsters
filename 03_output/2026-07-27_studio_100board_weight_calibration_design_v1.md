# Studio 100판 공통 가중치 보정 설계

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

이번 단계의 1차 목표는 전체 경로 평균 오차가 아니라, 타겟과 배경 도형이 겹친 뒤 다시 분리되는 순간에 두 도형의 신분을 정확히 구분하는 것이다. 전체 판을 끝까지 추적했는지는 2차 목표로 측정한다.

## 핵심 이론

준비시간에는 흰색 타겟이 중앙에 머무르는 동안 배경 도형들의 흐름을 관찰한다. 겹침 후 두 도형이 분리되면, 준비시간에 학습한 배경 움직임으로 더 잘 설명되는 도형을 배경으로 판정한다. 남은 도형을 타겟으로 복원한다.

타겟의 움직임은 매 판 무작위이므로 타겟 경로를 적극적으로 예측하지 않는다. 최근 속도와 도형 크기로 보아 순간이동처럼 물리적으로 불가능한 후보만 제거하는 약한 제한으로 사용한다.

## 안전 원칙

- 실행 중 GT, 정답 좌표, seed 이름을 솔버 입력으로 사용하지 않는다.
- 특정 좌표, 특정 방향, 특정 프레임 번호, 특정 사건 번호를 규칙에 넣지 않는다.
- 각 판에서 구한 최적 가중치는 연구 자료로만 사용하며 런타임에 직접 적용하지 않는다.
- 모든 판에 적용되는 하나의 공통 세팅을 최종 산출물로 만든다.
- `SAFE_HOLD`는 잘못된 전환과 별도로 기록하지만, 100% 추적 성공 기준에서는 실패로 계산한다.

## 기존 구조 활용

Lie Captcha Studio는 seed 기반 랜덤판 생성, 판별 GT 내보내기, 배치 실행을 이미 지원한다. `puzzle.py --studio-auto-validate`는 Studio와 lockstep으로 같은 프레임을 처리하고, 마우스 출력을 끈 상태에서 solver trace와 GT를 사후 비교한다.

따라서 새 시스템은 기존 Studio 하네스를 대체하지 않는다. 기존 수집과 replay 구조 위에 다음 세 계층을 추가한다.

1. 겹침 분리 사건 데이터셋 생성기.
2. 판별 심판 특징과 판별 결과 보정기.
3. 교차검증 및 잠금 검증 실행기.

## 사건 단위 데이터

분석 단위는 프레임 하나가 아니라 하나의 겹침 사건이다. 각 사건은 다음 구간을 가진다.

- 겹침 전 마지막으로 신뢰한 타겟과 배경 도형.
- 접촉 시작과 병합 상태.
- 분리 후보가 처음 나타난 시점.
- 두 후보의 신분이 충분히 구분되는 후속 관찰 구간.

각 사건에는 다음 결과를 기록한다.

- 사건 감지 성공 여부.
- 동일 병합 계보의 두 분리 후보 확보 여부.
- GT 타겟 후보가 후보군에 포함됐는지.
- 각 심판의 원시값, 정규화값, 측정 가능 여부.
- 최종 선택, `SAFE_HOLD`, 잘못된 전환 여부.
- 전체 판의 최종 추적 성공 여부.

## 단계별 실패 분리

가중치 보정 전에 다음 상한을 따로 측정한다.

1. 사건 감지율.
2. 병합 계보 생성률.
3. 분리 후보 두 개 확보율.
4. 정답 후보 포함률.
5. 심판 입력 신호 가용률.
6. 후보가 모두 있을 때의 selector 정확도.

정답 후보가 후보군에 없는 사건은 가중치 탐색으로 해결할 수 없다. 이런 사건은 `후보 생성 실패`로 분류하며 selector 실패에 섞지 않는다.

## 배경 판별 심판

각 후보가 배경으로 얼마나 잘 설명되는지를 다음 심판들이 판단한다.

- 전체 배경 흐름 일치도.
- 한 바퀴 동안 유지된 배경 계보와의 일치도.
- 주변 배경 도형과의 상대거리 유지도.
- 강체 움직임 일치도.
- 배경 주기와 질감 신분 일치도.
- 병합 전후의 배경 역할 연속성.

YOLO 점수는 후보 존재와 매우 낮은 품질 감점에만 사용한다. 충분히 신뢰할 수 있는 기준 이상에서는 추가 보너스를 주지 않는다.

각 심판은 충분한 기준을 넘으면 만점으로 포화한다. 측정할 수 없는 심판은 0점으로 처리하지 않고 `측정 불가`로 남긴다. 최종 지분은 측정 가능한 심판끼리 다시 정규화한다.

## 판별 규칙

분리 후보 A와 B에 대해 배경 일치도를 각각 계산한다.

- A만 배경으로 충분히 설명되면 B를 타겟으로 복원한다.
- B만 배경으로 충분히 설명되면 A를 타겟으로 복원한다.
- 둘 다 배경처럼 보이거나 둘 다 설명되지 않으면 `SAFE_HOLD`한다.
- 물리적으로 불가능한 후보는 배경 점수와 무관하게 제외한다.
- HOLD 상태에서는 잘못된 신분으로 갱신하지 않고 후속 관찰을 누적한다.

## 1~100판 개별 보정

고정된 보정 seed 묶음으로 랜덤 100판을 생성한다. 각 판의 GT는 솔버 판단이 끝난 뒤에만 사용한다.

각 판에서 단일 최적점만 찾지 않고, 해당 판의 모든 유효한 겹침 사건을 정확히 구분할 수 있는 가중치 범위를 구한다. 함께 기록할 항목은 다음과 같다.

- 판별 가능한 가중치 범위.
- 각 심판의 필수 여부.
- 심판 하나를 제거했을 때의 정확도 변화.
- 정답 역할 배정과 오답 역할 배정 사이의 최소 점수 차이.
- 사건별 성공, 오답 전환, `SAFE_HOLD`.

어떤 가중치로도 맞힐 수 없는 사건은 임계값을 무리하게 조정하지 않는다. 후보 누락, 계보 오류, 관찰 신호 부족 중 하나로 분류한다.

## 세 가지 공통 세팅

### 평균형

개별 최적값의 산술평균이 아니라, 여러 판의 성공 가능한 가중치 영역 중앙에 가장 가까운 값을 선택한다. 특정 판의 극단값 영향을 줄이는 것이 목적이다.

### 효율형

정확도 손실이 허용 범위 안인 심판 중 기여도가 낮거나 다른 심판과 중복되는 신호를 줄인다. 사용 심판 수, 계산 시간, 측정 불가 상황의 안정성을 함께 평가한다.

### 고확률형

평균 정확도보다 가장 어려운 겹침 사건에서 정답과 오답의 최소 점수 차이를 크게 만드는 값을 선택한다. 잘못된 신분 전환에 가장 큰 손실을 부여하고, `SAFE_HOLD`는 그보다 작은 손실을 부여한다.

모든 가중치는 0 이상이고 합계는 1이다. 한 심판에 과도하게 몰린 경계값보다 비슷한 정확도에서 여유 폭이 넓은 값을 우선한다.

## 100판 교차검증

같은 판을 학습과 평가에 동시에 사용하지 않도록 10겹 교차검증을 사용한다.

1. seed 기준으로 랜덤 10판을 대조용으로 숨긴다.
2. 남은 90판만 사용해 평균형, 효율형, 고확률형을 만든다.
3. 숨긴 10판에 세 세팅을 각각 적용한다.
4. 대조판을 바꾸며 10번 반복한다.
5. 모든 판이 정확히 한 번씩 GT를 보지 않은 대조판 역할을 한다.

세 세팅은 같은 대조판, 같은 후보, 같은 사건 입력으로 비교한다. 실행 순서에 따른 상태 누수를 막기 위해 세팅을 바꿀 때 solver 상태를 초기화한다.

## 평가 우선순위

1. 겹침 후 분리 사건의 타겟 복원 성공률.
2. 잘못된 후보로의 신분 전환 수.
3. `SAFE_HOLD` 수와 회복률.
4. 정답 역할 배정과 오답 역할 배정의 최소 점수 차이.
5. 후보 생성과 사건 계보의 상한.
6. 전체 판의 끝까지 추적 성공률.
7. 처리 시간과 사용 심판 수.

같은 사건에서 프레임별 정답을 여러 번 세어 결과를 부풀리지 않는다. 겹침 사건 하나는 역할 복원 성공 또는 실패 한 건으로 집계한다.

## 최종값 선택과 잠금

교차검증 결과를 바탕으로 공통 세팅 하나를 선택한다. 선택된 가중치, 포화 기준, 물리 제한, 사용 심판 목록을 버전이 포함된 설정 파일에 저장한다.

잠금 이후에는 보정 seed, GT, 개별판 최적값을 런타임에서 읽을 수 없게 인터페이스를 분리한다. 설정 파일의 해시와 실험 버전을 최종 보고서에 기록한다.

## 새 100판 GT 비공개 검증

보정에 사용하지 않은 새로운 seed 묶음으로 100판을 생성한다. 솔버는 잠긴 공통 세팅과 화면 입력만 사용한다. GT는 각 판의 모든 판단이 끝난 뒤 별도 채점기에서만 연다.

최종 성공 기준은 다음과 같다.

- 겹침 후 타겟 역할 복원 성공률 100%.
- 잘못된 신분 전환 0건.
- `SAFE_HOLD`가 발생한 판은 전체 추적 통과에서 실패.
- 전체 판 끝까지 추적 성공 100/100.
- 후보 생성 실패와 selector 실패가 각각 0건.

100%를 달성하지 못하면 가중치를 바로 다시 조절하지 않는다. 먼저 실패가 후보 생성, 사건 계보, 관찰 신호, 공통 세팅 중 어디에 속하는지 분류하고 새로운 일반화 신호가 필요한지 판단한다.

## 산출물

- 판별 사건 단위 원시 데이터.
- 판별 단계별 상한 보고서.
- 100판 개별 성공 영역 요약.
- 10겹 교차검증 결과.
- 평균형, 효율형, 고확률형 비교표.
- 잠긴 최종 설정과 해시.
- 새 100판 GT 비공개 최종 검증 보고서.

영상과 전체 프레임 이미지는 기본적으로 저장하지 않는다. 실패 사건의 대표 이미지와 수치 근거만 제한적으로 보존한다.
