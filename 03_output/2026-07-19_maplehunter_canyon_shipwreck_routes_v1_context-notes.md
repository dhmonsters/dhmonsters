# MapleHunter 깊바협·난파선·위바협 분석 컨텍스트 노트

## 결정 사항

- 분석 대상 실행파일은 `C:\Users\PC\Downloads\Telegram Desktop\sssa\플래닛 (2)\MapleHunter_v3.1.17.exe`이다.
- 안전을 위해 실행파일과 포함 드라이버는 실행하지 않고 정적 추출만 수행한다.
- 사용자 표현 `깊바혐2_2킬`은 실제 파일명 확인 전까지 `깊바협2_2킬`의 오타 후보로 취급한다.
- 사용자 표현 `위바협2_2`는 실제 파일명 확인 전까지 `_2` 또는 `_2킬` 변형 후보로 취급한다.
- 문서 디자인은 `compact_reference_guide`, 첫 페이지는 `memo_masthead`를 사용한다.

## 검증 기준

- 경로 설명은 코드 또는 바이트코드에서 확인된 조건과 입력을 근거로 한다.
- 해석상 추론은 명시적으로 표시한다.
- 요청한 모든 실제 변형이 비교표와 상세 절에 포함되어야 한다.

## 확인된 핵심 결과

- 실제 정식 모듈은 `깊바협2`, `깊바협2_2킬`, `난파선의무덤`, `위바협2`, `위바협2_2킬`이다.
- `깊바협2_2킬`은 일반판과 이동·복구가 같고 A/B에서 공격을 2회가 아닌 3회 수행한다.
- `난파선의무덤`은 첫 사이클 최대 6회, 반복 사이클 최대 4회의 제네시스를 수행한다.
- `위바협2`는 x64 중심의 넓은 순환과 3회 블리자드, `위바협2_2킬`은 x63~65 세로축과 6회 블리자드 구조다.
- `위바협2_2킬` 범위 이탈 설명문은 4초지만 실제 조건식은 9초다.
- 세부 동선은 `config.json`이 아니라 맵 모듈에 하드코딩되어 있다.

- Microsoft Word PDF 변환과 Poppler PNG 변환을 사용했다.
- 총 11페이지를 확인했으며 표 잘림, 텍스트 겹침, 머리글·바닥글 이상은 발견되지 않았다.
- 첫 렌더 검수에서 난파선 반복 사이클 광역기 수를 5회로 잘못 계산한 항목을 발견해 테스트를 추가하고 4회로 수정했다.
