# 2026-07-08 섹션 집중형 레이아웃 보정 계획 v1

## 목표

키워드 단계에서 편집 미리보기와 타임라인이 과하게 노출되는 문제를 줄이고, 각 제작 단계가 자기 작업에 집중되도록 화면 배치를 조정한다.

## 범위

1. 키워드, 대본, 음성/자막, 출력 단계는 현재 단계 작업 패널을 넓게 보여준다.
2. 편집 단계에서만 쇼츠 미리보기와 타임라인을 크게 보여준다.
3. 성장 메모리는 출력 단계에서만 보조 패널로 표시한다.
4. 기존 검색, 후보 선택, 대본 생성 흐름은 유지한다.

## 성공 기준

- 키워드 단계에서 `쇼츠 미리보기`, `장면 타임라인`, `성장 메모리`가 보이지 않는다.
- 편집 단계에서는 `쇼츠 미리보기`와 `장면 타임라인`이 보인다.
- 프론트 테스트와 빌드가 통과한다.
