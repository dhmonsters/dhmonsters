# 2026-07-08 실사용 MVP 트렌드 검색 보정 계획 v1

## 목표

현재 개발용 MVP를 사용자가 바로 눌러볼 수 있는 상태로 보정한다.

## 범위

1. 한국 인기 영상 후보 검색 API를 유튜브 API 키 없이도 샘플 데이터로 동작하게 만든다.
2. 첫 화면에 카테고리, 키워드, 검색 버튼, 후보 카드 목록을 배치한다.
3. 후보를 선택하면 프로젝트 생성과 대본 생성 흐름으로 이어지게 한다.
4. 각 제작 섹션에서 주요 설정을 접히는 커스터마이징 패널로 조정할 수 있게 한다.
5. 테스트와 빌드로 실제 사용 가능 상태를 확인한다.

## 성공 기준

- `/api/trends`가 한국 샘플 후보를 반환한다.
- 키워드 검색 시 관련 후보가 필터링된다.
- 프론트 첫 화면에서 후보를 검색하고 선택할 수 있다.
- 섹션 커스터마이징 설정이 상태에 저장되고 화면에 반영된다.
- 백엔드 테스트, 프론트 테스트, 프론트 빌드가 통과한다.
