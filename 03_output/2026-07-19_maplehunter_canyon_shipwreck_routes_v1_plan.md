# MapleHunter 깊바협·난파선·위바협 동선 비교 분석 계획

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this plan task-by-task.

**목표:** MapleHunter_v3.1.17.exe에 포함된 깊바협2, 깊바협2_2킬, 난파선의무덤, 위바협2 계열 맵 모듈을 정적 분석하여 실제 이동 루틴과 변형별 차이를 근거 중심으로 정리한다.

**분석 방식:** 실행파일은 실행하지 않고 PyInstaller 아카이브에서 맵 소스 및 바이트코드 메타데이터를 추출한다. 각 맵의 좌표 판정, 키 입력, 점프·텔레포트·사다리, 공격·버프, 복구 분기를 순서도로 재구성하고 공통 비교표를 만든다.

**산출물:** `03_output/2026-07-19_maplehunter_canyon_shipwreck_routes_v1.docx`

---

### 작업 1. 실제 맵 파일명과 변형 확인

- PE/PyInstaller 메타데이터에서 `깊바협`, `난파선`, `위바협` 항목을 검색한다.
- 일반/플래닛/2킬 변형의 정확한 파일명을 확정한다.
- 사용자 표현과 실제 파일명이 다르면 대응 관계를 기록한다.

### 작업 2. 맵 모듈 정적 추출 및 근거 확보

- 기존 안전 추출 도구로 해당 맵 모듈만 별도 증거 폴더에 추출한다.
- 소스가 있으면 줄 번호를 붙여 읽고, 바이트코드만 있으면 메타데이터를 추출한다.
- 원본 EXE와 드라이버는 실행하지 않는다.

### 작업 3. 동선과 복구 루틴 재구성

- 각 맵의 기준 좌표, 층 판정, 좌우 이동, 상승·하강, 공격 지점을 정리한다.
- 텔레포트·점프·사다리·로프·낙하·버프·재시도 조건을 구분한다.
- 추론은 직접 확인된 사실과 분리해 표시한다.

### 작업 4. 변형별 비교 보고서 작성

- `compact_reference_guide` 프리셋과 `memo_masthead` 첫 페이지 패턴을 적용한다.
- 맵별 상세 루틴, 공통점, 차이점, 핵심 제어 방식, 주의사항을 표와 단계 목록으로 구성한다.
- 모든 표는 9360 DXA 고정 폭을 사용한다.

### 작업 5. 구조·렌더·내용 검증

- 생성기 테스트와 문서 XML 구조 검사를 수행한다.
- DOCX를 PDF 및 페이지 PNG로 렌더링하고 모든 페이지를 육안 검수한다.
- 최종 해시, 페이지 수, 테스트 결과를 기록한다.
