# 2026-07-08 트렌드 상세 분석과 대본 편집 흐름 계획 v1

## 목표

1~4번 진행 범위인 트렌드 검색 고도화, 후보 상세 분석, 대본 하네스 실제 반영, 장면 대본 편집 화면을 하나의 제작 흐름으로 연결한다.

## 범위

1. 트렌드 후보를 선택하면 제목 키워드, 상승 속도, 제작 각도, 저작권 주의도, 추천 하네스를 분석한다.
2. 대본 생성 API가 프론트에서 설정한 하네스와 후보 분석 데이터를 받는다.
3. 대본 하네스 편집 화면에 말투, 훅 강도, 목표 길이, 금지어, 추가 지시를 넣는다.
4. 생성된 장면 대본을 직접 수정, 장면 재생성, 위/아래 순서 변경할 수 있게 한다.

## 제외 범위

- 실제 LLM 호출.
- 실제 YouTube API 키 발급 또는 외부 계정 연결.
- 실제 mp4 렌더링.
- TTS 음성 파일 생성.

## 성공 기준

- 후보 분석 API가 제작 각도 3개와 주의도를 반환한다.
- 대본 생성 API가 하네스 설정을 반영한다.
- 프론트에서 후보 상세 분석을 볼 수 있다.
- 프론트에서 대본 하네스와 장면 대본을 편집할 수 있다.
- 백엔드 테스트, 프론트 테스트, 프론트 빌드가 통과한다.
