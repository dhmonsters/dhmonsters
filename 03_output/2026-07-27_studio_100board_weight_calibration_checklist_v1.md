# Studio 100판 공통 가중치 보정 체크리스트

- [ ] 기존 Studio lockstep 하네스에서 사건 단위 특징을 추출한다.
- [ ] GT가 solver 판단 뒤에만 사용되는 경계를 테스트로 고정한다.
- [ ] 겹침 사건 감지, 계보, 후보 포함, 심판 가용률을 분리 집계한다.
- [ ] 배경 심판별 원시값, 포화값, 측정 불가 상태를 기록한다.
- [ ] 타겟 움직임을 물리적 불가능 후보 제거에만 사용한다.
- [ ] 각 판의 성공 가능한 가중치 범위를 구한다.
- [ ] 평균형, 효율형, 고확률형 공통 세팅 생성기를 만든다.
- [ ] 10겹 교차검증에서 매번 90판 보정과 10판 대조를 분리한다.
- [ ] 겹침 후 타겟 복원을 사건 단위 1차 지표로 채점한다.
- [ ] 잘못된 전환, SAFE_HOLD, 후보 생성 실패를 별도 집계한다.
- [ ] 최종 공통 세팅을 잠그고 설정 해시를 기록한다.
- [ ] 새 seed 100판에서 GT 비공개 실행 후 사후 채점한다.
- [ ] 성공 영상은 남기지 않고 대표 실패 근거만 제한적으로 보존한다.
- [ ] 관련 단위 테스트와 기존 회귀 테스트를 통과한다.
- [ ] 문서와 구현을 논리 단위로 커밋한다.
