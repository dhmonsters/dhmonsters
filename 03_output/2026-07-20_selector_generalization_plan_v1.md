# 시간축 Selector 일반화 계획

## 목적

랜덤판에 공통으로 적용되는 정규화된 현직·도전자 판별 규칙을 만들고, 이론과 일치할 때만 검증 범위를 확대한다.

## 순서

1. 기존 selector의 고정 픽셀, 단일 심판 우선, 무조건 보호 규칙을 목록화한다.
2. 정규화 거리와 독립 증거 합의를 계산하는 shadow 판별기를 테스트 우선으로 추가한다.
3. 실제 선택은 바꾸지 않고 대표판의 현직·도전자 판단 이유만 기록한다.
4. 이론상 예상과 기록이 일치할 때만 대표판 한 번의 A/B를 실행한다.
5. 대표판이 실패하면 가설을 보류하고 추가 실행과 가중치 탐색을 중단한다.
6. 대표판이 통과하면 성공 보존판 1개부터 단계적으로 확대한다.

## 첫 검증 성공 기준

- 대상은 `codex-rigid-v1-06` 한 판이다.
- 기존 성공 손실은 0이어야 한다.
- selector 오류가 최소 1프레임 개선돼야 한다.
- 모든 변경 프레임은 정규화 연속성과 복수 독립 증거로 설명돼야 한다.
- 박스 내부 중심 오류는 이번 실험의 성공으로 계산하지 않는다.

## 비용 제한

- detector와 기존 evidence는 가능하면 저장된 결과를 재사용한다.
- 전체 영상과 이미지는 첫 가설 통과 전 새로 생성하지 않는다.
- 보고서는 변경 프레임, 심판 근거, 통과 여부만 남긴다.
- 실패 가설은 한 번만 기록하고 같은 숫자 조정 실험을 반복하지 않는다.
