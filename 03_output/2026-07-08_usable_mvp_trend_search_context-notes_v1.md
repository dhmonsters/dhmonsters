# 2026-07-08 실사용 MVP 트렌드 검색 결정 노트 v1

## 결정

- 유튜브 API 키가 없거나 API 호출이 실패해도 사용자가 바로 체험할 수 있도록 한국 샘플 트렌드 후보를 반환한다.
- 첫 화면은 랜딩 페이지가 아니라 실제 작업 화면으로 유지한다.
- 섹션 커스터마이징은 전역 설정 상태로 관리하고, 각 단계에서 필요한 설정만 노출한다.
- 이번 범위에서는 실제 mp4 렌더링이나 실제 TTS 파일 생성은 다루지 않는다.

## 이유

- 사용 MVP의 첫 가치는 “추천 후보를 보고 하나를 골라 대본 흐름으로 이어지는 경험”이다.
- 외부 API 키가 없으면 기능이 비어 보이므로 샘플 fallback이 필요하다.
- 모든 섹션 설정을 한꺼번에 노출하면 복잡해져서 단계별 접힘 패널이 더 적합하다.

## 구현 메모

- `/api/trends`는 `SHORTS_YOUTUBE_API_KEY`가 없으면 `source: sample`로 한국 샘플 후보를 반환한다.
- 프론트 첫 화면은 카테고리, 키워드, 후보 검색, 후보 선택 버튼을 제공한다.
- 후보 선택 시 프로젝트 생성 후 대본 생성 API를 호출하고 대본 단계로 이동한다.
- 로컬 프론트에서 백엔드 API를 호출할 수 있도록 `127.0.0.1:5173`과 `localhost:5173` CORS를 허용했다.
