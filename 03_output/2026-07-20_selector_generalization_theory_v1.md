# 시간축 Selector 일반화 이론

## 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

GT는 실행 중 입력으로 사용하지 않고, 실행이 끝난 뒤 채점과 실패 분류에만 사용한다.

## 현재 확인된 사실

- 고정 seed 10개의 기준은 1,110/1,500이다.
- 가설 보관 개선 뒤 같은 재생기에서 1,109에서 1,123으로 올랐고 기존 성공 손실은 0이었다.
- 남은 실패의 큰 항목은 selector 133프레임, 박스 내부 중심 43프레임, 후보 부재 67프레임이다.
- 후보 다양성 개선으로 가설 생성 오류는 147프레임에서 10프레임까지 줄일 수 있었다.
- 따라서 다음 병목은 후보를 더 만드는 문제가 아니라, 살아 있는 후보 중 신분을 이어받을 후보를 고르는 문제다.

## 첫 번째 일반화 가설

현직 경로와 도전자 경로를 절대 좌표와 고정 픽셀로 비교하지 않는다. 현재 도형 크기, 최근 타겟 운동, 프레임 간 경과시간, 현재 판의 배경 흐름을 기준으로 정규화한 뒤 두 경로를 비교한다.

### 관찰값

1. 최근 안정 구간에서 측정한 타겟의 이동량과 변화 폭.
2. 현재 후보의 크기와 겹침 정도.
3. 현재 판에서 측정한 국소 배경 흐름과 후보 운동의 차이.
4. 강체 배경으로 설명되지 않는 국소 잔차.
5. 현재 후보 집단에서의 상대 YOLO 신뢰도.
6. 흰색 타겟과 배경 밝기의 차이로 측정한 페이드 상태.

### 상태

- 정상 추적.
- 겹침 진입.
- 겹침 유지.
- 분리 관찰.
- 신분 보류.
- 재획득.

상태는 특정 프레임 번호나 좌표가 아니라 관찰값의 변화로 판정한다. 모든 판에서 흰색이 사라지는 시간이 확실히 고정돼 있다면 해당 시간은 흰색 심판을 종료하는 보조 안전장치로만 사용한다.

### 신분 전환 규칙

1. 도전자의 예상 위치 오차를 최근 운동 범위와 도형 크기로 나눈 정규화 거리로 계산한다.
2. 물리적으로 설명하기 어려운 도전자는 YOLO 점수가 높아도 거부한다.
3. 배경 흐름과 명확히 같은 운동은 배경 가능성을 높인다.
4. 배경과 다른 운동, 강체 위반, 분리 연속성은 서로 독립된 타겟 증거로 본다.
5. YOLO는 현재 후보 집단에서 지나치게 낮은 후보를 감점하지만, 높은 점수만으로 신분을 교체하지 않는다.
6. 사용 가능한 독립 증거가 부족하거나 서로 충돌하면 현직 신분을 보류한다.
7. 도전자의 누적 우위가 불확실성보다 커질 때만 신분을 교체한다.

## 과적합 방지 조건

- 특정 좌표, 정답 방향, seed 이름을 규칙에 넣지 않는다.
- `오른쪽`, `시계 방향이 아님` 같은 방향 자체를 정답으로 사용하지 않는다.
- 고정 60px 대신 도형 크기, 최근 속도, 경과시간으로 정규화한 이동 한계를 사용한다.
- 특정 실패 프레임의 결과를 맞추기 위한 사후 가중치 조정은 하지 않는다.
- 근거가 부족하면 잘못된 후보를 고르는 대신 보류한다.

## 첫 검증판 선정

첫 검증은 `codex-rigid-v1-06` 한 판만 사용한다.

선정 이유는 후보 보관 상한이 139/150인데 동일 재생기의 현직·도전자 결과는 약 97/150이어서, 후보 생성보다 selector 판별의 여지가 큰 대표판이기 때문이다.

## 실행 전 예측

- 이전에 맞던 프레임을 잃지 않아야 한다.
- 후보가 이미 존재했던 selector 오류에서 최소 1프레임 이상을 올바르게 바꿔야 한다.
- 변경된 선택은 정규화 연속성 통과와 두 개 이상의 독립 관찰 증거로 설명돼야 한다.
- 정규화 이동 한계를 넘는 장거리 전환은 없어야 한다.
- 점수만 올랐지만 예상한 원리로 바뀌지 않았다면 실패로 판정한다.

## 폐기 조건

다음 중 하나라도 발생하면 첫 가설을 보류하고 숫자 재조정 없이 이론 단계로 돌아간다.

- 통과 프레임이 늘지 않는다.
- 기존 정답 프레임이 하나라도 손실된다.
- 도전자 선택 이유가 단일 YOLO 점수 또는 특정 방향에 의존한다.
- 장거리 갈아타기가 남는다.
- 예상한 selector 오류가 아니라 우연한 박스 중심 변화로 점수만 오른다.

## 확대 조건

첫 판을 통과한 경우에만 이미 잘 풀던 성공 보존판 1개, 혼합 3판, 고정 seed 10판, 16GT, 새 seed 순서로 확대한다. 각 단계에서 실패하면 다음 단계는 실행하지 않는다.
