# MapleHunter 사다리 정적 분석 계획

**목표.** `MapleHunter_v3.1.17.exe`가 사다리를 인식하고 캐릭터를 정렬·등반시키며 실패를 줄이는 방식을 정적 증거로 복원한다.

**범위.** 기존 PyInstaller 추출물, 모듈 메타데이터, 문자열, 코드 객체와 이미지 자산을 사용한다. 실행 파일과 포함 드라이버는 실행하지 않는다.

## 작업 단계

- [x] 기존 추출물에서 사다리·로프·등반 관련 모듈과 문자열을 검색한다.
- [x] 사다리 위치 취득 방식과 캐릭터 좌표의 출처를 확인한다.
- [x] 접근 정렬, 키 입력, 등반 완료 판정과 재시도 흐름을 복원한다.
- [x] 성공 가능성을 높이는 보정 조건과 정적으로 확인할 수 없는 부분을 구분한다.
- [x] 근거 파일·함수·상수를 포함한 결과 보고서를 작성하고 검증한다.

## 완료 기준

- 인식, 접근, 등반, 완료 판정, 실패 복구의 순서를 설명할 수 있다.
- 성공 가능성 보정 요소마다 직접 근거 또는 추정 수준이 표시되어 있다.
- 원본 실행 파일을 실행하거나 수정하지 않는다.
