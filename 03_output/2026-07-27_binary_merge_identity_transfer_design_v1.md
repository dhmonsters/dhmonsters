# 이진 병합 신분 전달 판별기 설계

## 1. 고정 목표

처음 흰색 타겟의 신분을 잃지 않고 끝까지 따라가는 시간축 판별기를 만든다.

이번 단계의 최우선 목표는 전체 프레임 정확도가 아니다. 타겟과 배경 도형이 겹쳤다가 다시 분리되는 순간, 타겟 신분을 올바른 분리 후보에게 전달하고 배경 후보로 잘못 갈아타지 않는 것이다.

## 2. 고정된 물리 조건

- 배경 도형끼리는 서로 겹치지 않는다.
- 타겟만 배경 흐름과 별도로 움직인다.
- 하나의 병합 사건에는 타겟 1개와 배경 도형 1개만 참여한다.
- 물리적으로 세 개 이상의 분리 자식은 존재하지 않는다.
- 검출기가 세 개 이상을 출력하면 중복 박스 또는 오검출로 취급한다.
- GT는 사건 종료 후 채점에만 사용하며 실행 중 후보 선택에는 사용하지 않는다.
- 고정 좌표, 고정 방향, 절대 프레임 번호는 규칙에 사용하지 않는다.
- 증거가 부족하면 다른 후보로 갈아타지 않고 HOLD한다.

## 3. 검증 범위

준비 구간 전체를 매 프레임 채점하지 않는다. 준비 구간은 배경 흐름과 충돌 배경의 움직임을 설명하는 압축 데이터 생성에만 사용한다.

실제 채점 범위는 다음 사건 구간으로 제한한다.

1. 병합 직전 타겟과 충돌 배경이 분리돼 있는 구간.
2. 부분 겹침 또는 하나의 병합 박스로 보이는 구간.
3. 두 후보가 다시 갈라지는 구간.
4. 분리 후보의 역할이 안정적으로 판별되거나 HOLD가 확정되는 구간.

## 4. 상태 모델

### SEPARATE

타겟과 충돌 배경이 각각 검출된다. 두 객체의 상태를 독립적으로 갱신한다.

### OVERLAP

두 박스가 일부 겹친다. 타겟과 배경의 마지막 신뢰 상태를 동결하고 병합 박스 중심으로 타겟 궤적을 갱신하지 않는다.

### MERGED

하나의 큰 박스만 남는다. 이 박스는 타겟 위치가 아니라 타겟과 배경을 포함하는 부모 영역으로만 사용한다. 타겟과 배경의 예상 위치는 병합 직전 상태와 관측된 배경 흐름으로 따로 전파한다.

### SPLITTING

두 자식 후보가 다시 검출된다. 후보를 즉시 선택하지 않고 두 개의 역할 가설을 동시에 평가한다.

### RESOLVED 또는 HOLD

두 독립 심판이 같은 역할 배정을 지지하고 가설 차이가 충분하면 타겟 신분을 전달한다. 증거가 충돌하거나 차이가 작으면 HOLD한다.

## 5. 준비 구간 압축 데이터

준비 구간에서는 영상 전체를 장기 보관하지 않고 다음 숫자 서명만 저장한다.

- 배경 후보의 정규화 위치와 속도.
- 화면 전체에서 측정한 지역 배경 흐름.
- 후보 크기와 종횡비의 안정 범위.
- 가까운 배경 도형들과의 정규화 상대거리 변화.
- 검출 공백과 재등장 이력.
- 전체 주기가 신뢰 가능할 때만 사용하는 주기 위상 보조 정보.

전체 주기가 확정되지 않아도 병합 사건 검증은 계속한다. 주기 정보는 확실할 때 배경 판정을 강화하는 보조 신호이며 사건 판별을 여는 필수 조건이 아니다.

## 6. 병합 직전 동결 상태

병합이 시작되면 다음 정보를 고정한다.

### 타겟 상태

- 마지막 신뢰 중심과 박스 크기.
- 최근 위치들로 계산한 속도와 가속도 범위.
- 최근 궤적의 방향 변화.
- 병합 부모 영역 안에서 가능한 예상 위치 범위.

### 충돌 배경 상태

- 마지막 신뢰 중심과 박스 크기.
- 준비 구간에서 관측된 배경 흐름에 따른 예상 이동.
- 가까운 배경 도형들과의 상대거리 서명.
- 신뢰 가능한 경우 전체 주기 위상과 안정 트랙 정보.

## 7. 병합 중 규칙

- 병합 박스 중심을 타겟 중심으로 사용하지 않는다.
- 타겟 예상 상태와 충돌 배경 예상 상태를 독립적으로 유지한다.
- 하나의 병합 부모 영역이 두 예상 상태를 합리적으로 포함하는지만 확인한다.
- 병합 중 검출 중심이 한쪽으로 밀려도 타겟 속도와 위치 기록을 덮어쓰지 않는다.
- 부모 영역이 두 예상 상태를 설명하지 못하면 사건을 확정하지 않고 진단 사유를 남긴다.

## 8. 분리 후 이진 가설

분리 자식 후보를 A와 B라고 할 때 두 가설만 만든다.

- 가설 H1은 A가 타겟이고 B가 배경이다.
- 가설 H2는 B가 타겟이고 A가 배경이다.

각 가설은 타겟 점수와 배경 점수를 따로 계산한다. 절대점수 하나로 후보를 고르지 않고 H1과 H2의 상대 우위를 비교한다.

## 9. 판별 심판

### 배경 연속성 심판

분리 후보가 병합 직전 충돌 배경의 예상 위치, 속도와 자연스럽게 연결되는지 평가한다. 준비 구간에서 측정한 지역 배경 흐름과 같은 움직임을 보일수록 배경 증거가 강하다.

### 주변 상대거리 심판

분리 후보와 가까운 배경 도형들의 상대거리 변화가 병합 전후로 자연스럽게 이어지는지 평가한다. 절대 위치가 아니라 도형 크기와 최근 배경 이동량으로 정규화한다.

### 타겟 운동 연속성 심판

분리 후보가 병합 직전 타겟의 위치, 속도, 가속도 허용 범위와 연결되는지 평가한다. 병합 중 부모 박스 중심 때문에 만들어진 가짜 속도는 사용하지 않는다.

### 부모-자식 계보 심판

분리 후보가 실제 병합 부모 영역에서 갈라져 나왔는지 평가한다. 병합 영역과 관계없는 외부 후보는 역할 가설에서 제외한다.

### 모양 안정성 심판

후보의 크기와 종횡비가 병합 전 해당 역할의 안정 범위와 맞는지 평가한다. 투명도와 검출 박스 변화가 있으므로 단독 결정권은 주지 않는다.

### YOLO 신뢰도 심판

검출 신뢰도는 낮은 후보를 감점하는 보조 신호로만 사용한다. 일정 신뢰 수준 이상에서는 추가 보너스를 주지 않으며 높은 YOLO 점수만으로 역할을 바꾸지 않는다.

### 전체 주기 계보 심판

전체 주기와 정확한 안정 트랙 ID가 신뢰 가능한 경우에만 후보가 배경이라는 강한 보조 증거를 제공한다. 정보가 없거나 모호하면 0점이 아니라 미사용 상태로 남기며 다른 사건 증거를 막지 않는다.

## 10. 역할 결정

H1과 H2 각각에 다음 합의를 요구한다.

- 배경 역할 후보가 배경 연속성과 상대거리 심판에서 우세하다.
- 타겟 역할 후보가 타겟 운동 연속성에서 우세하다.
- 두 후보가 모두 병합 부모의 실제 자식이다.
- 배경 판정과 타겟 판정이 서로 반대 후보를 가리킨다.
- 가설 차이가 현재 후보 분포와 도형 크기로 정규화한 최소 여유를 넘는다.

합의하면 `CORRECT_TRANSFER` 후보로 신분을 전달한다. 합의하지 못하면 `HOLD`한다. HOLD 중에는 두 가설을 계속 유지하고 병합 부모 또는 마지막 안전 위치를 기준으로 추적한다.

## 11. 중복 검출 정리

세 개 이상의 검출이 들어오면 물리 자식이 늘어난 것으로 해석하지 않는다.

- 같은 중심과 높은 박스 겹침을 가진 검출은 하나의 물리 후보로 묶는다.
- 병합 부모 영역 밖의 검출은 제거한다.
- 정리 후 물리 후보가 정확히 두 개가 아니면 역할을 확정하지 않고 HOLD한다.

## 12. 사건 단위 결과

- `CORRECT_TRANSFER`는 올바른 자식 후보에게 타겟 신분을 전달한 경우다.
- `WRONG_SWITCH`는 배경 자식에게 타겟 신분을 전달한 경우다.
- `SAFE_HOLD`는 불충분한 증거에서 잘못 선택하지 않은 경우다.
- `LATE_RECOVERY`는 올바른 자식을 찾았지만 허용 가능한 분리 구간보다 늦은 경우다.
- `TARGET_NOT_IN_CANDIDATES`는 정답 자식이 검출 후보에 없는 경우다.
- `EVENT_DETECTION_FAILURE`는 겹침이나 분리 사건 자체를 놓친 경우다.
- `DUPLICATE_DETECTION_UNRESOLVED`는 중복 정리 후 두 물리 자식으로 확정하지 못한 경우다.

## 13. 채점 지표

이번 단계의 주 지표는 프레임 정확도가 아니라 사건 정확도다.

- 올바른 신분 전달 사건 수.
- 잘못된 배경 갈아타기 사건 수.
- 안전한 HOLD 사건 수.
- 분리 시작부터 신분 전달까지의 정규화된 재획득 지연.
- 사건 감지 실패 수.
- 정답 후보 미검출 수.
- 각 심판이 H1과 H2에 제공한 상대 기여도.

## 14. 단계별 검증 게이트

### 게이트 1

기존 대표 판에서 실제 병합 사건 1개만 추출한다. 준비 구간 압축 데이터와 사건 구간만 사용해 실행한다.

통과 조건은 병합 사건 감지 성공, 병합 중 잘못된 확정 0회, 올바른 신분 전달 1회, 잘못된 갈아타기 0회다.

### 게이트 2

같은 세션의 모든 병합 사건으로 확장한다. 잘못된 갈아타기 0회를 유지해야 한다.

### 게이트 3

Studio 랜덤 seed 3개에서 사건 단위 검증을 수행한다. 물리 조건이 같은 사건에 동일 규칙이 적용돼야 한다.

### 게이트 4

Studio 랜덤 seed 10개와 보존 세션으로 확장한다. 임계값은 특정 좌표나 특정 사건에 맞춰 조정하지 않는다.

### 게이트 5

사건 전용 shadow가 통과한 뒤에만 전체 replay와 `puzzle.py`의 마우스 OFF 검증 모드에 연결한다.

## 15. 진단 출력

각 사건에 다음 정보만 남긴다.

- 사건 ID와 상태 전환.
- 병합 직전 타겟과 충돌 배경 상태.
- 분리 자식 A와 B의 위치 및 박스.
- H1과 H2의 심판별 상대 기여도.
- 최종 결정과 HOLD 이유.
- 실패 사건의 대표 이미지 소수.

성공 사건의 원본 영상과 전체 프레임 이미지는 장기 보관하지 않는다. 숫자 요약과 간단한 보고서만 유지한다.

## 16. 비목표

- 이번 단계에서 전체 솔버 점수를 최적화하지 않는다.
- 전체 주기 판별기를 억지로 활성화하기 위해 임계값을 낮추지 않는다.
- 세 개 이상의 물리 자식에 대한 다중 할당 문제를 구현하지 않는다.
- 학습형 분류 모델을 새로 만들지 않는다.
- 마우스를 실제로 움직이지 않는다.

## 17. 구현 경계

첫 구현은 기존 live 선택기를 직접 바꾸지 않는 opt-in 사건 shadow로 만든다. 준비 데이터 압축, 사건 추출, 이진 가설 판별, 사건 채점을 분리된 단위로 검증한다. 게이트를 통과하기 전에는 `puzzle.py`의 실제 선택 경로에 연결하지 않는다.
